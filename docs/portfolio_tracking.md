### 4.5 买点规则（通用）

> 买点 = **价格 + 时间 + 仓位 + 取消条件** 四要素同时满足

#### A) 核心槽买点（最严格）

```
首次建仓:
  价格  = 当日(扫描日)收盘 ± 1%
  时间  = 第二日 9:45-10:30 (避开集合竞价)
  仓位  = 1/2 仓 (4-5%) 试探
  取消  = 开盘 > 收盘×1.05 或 当日跌 > 3% 或 close < MA20

补到满仓:
  浮盈 < 5%  + 价格回踩入场价 ±2% + 仍 > MA20  → 补另 1/2 仓
  浮盈 5-10% + 收盘踩 5 日均线获支撑           → 补另 1/2 仓
  浮盈 ≥ 15%                                   → 不再加仓 (追高破纪律)
```

#### B) 候补转正买点（持续性已过, 等形态）

```
转正阈值穿越 (具体阈值见 §2 候补名单):
  例如 vs60 ≤ 50% / close > MA20

收盘确认: 连续 2 个交易日满足转正阈值
  ↓
第 3 日买点:
  限价 = MIN(前日收盘×1.01, 当日开盘×1.005)
  仓位 = 直接 4-5% (持续性已确认, 不需 1/2 仓试探)
```

#### C) 机动槽买点（当日触发即买）

| 信号类型 | 买入时机 | 限价 | 仓位 | 前置条件 |
|---|---|---|---:|---|
| Super NEW + 形态过 SOP | 第二日 9:45-10:30 | 当日收盘 ±1% | 5-6% | close>MA20, vs60≤50%, ret20≤50% |
| Huoche FIRST_W | **当日尾盘 14:50-14:55** | 当日收盘 ±1% | 5% | 同上 |
| Early∩L1 | 持续 ≥ 3 天后第 4 天 9:45 | 当日收盘 ±1% | 5% | 同上 |

#### D) 通用取消信号（任一触发, 当日不买）

| 信号 | 处理 |
|---|---|
| 开盘 > 扫描日收盘 × 1.05 | 取消 |
| 9:30-9:35 跌幅 > -3% | 取消 |
| 沪深 300 指数 9:30-10:00 跌 > -1% | 全部暂缓 |
| portfolio_check 显示 close < MA20 | 该票取消 |
| 一字涨停 / 一字跌停 | 取消 |

#### E) 优先级（资金不够同时全建时）

```
按 vs60 升序 (位置好的优先), 同 vs60 按 super_rate 降序
```
