# 朝天椒战法 — 通达信本地选股 + 主图叠加

> 与 [strategy_hong_zhanfa.md](strategy_hong_zhanfa.md)「一、朝天椒战法」及 [tdx_formulas_hong_zhanfa.md](tdx_formulas_hong_zhanfa.md) 逻辑一致。本文**自包含**：选股与主图各一份完整公式，无需再复制「公共块」。
> **RPS**：完整版依赖扩展数据 `EXTDATA_USER(6)`、`EXTDATA_USER(7)`，配置方式见 [tdx_rps_extension_zhutu.md](tdx_rps_extension_zhutu.md)。无扩展数据请用下文「精简版选股」。

---

## 一、策略摘要（量化条件一览）

| 维度 | 条件 |
|------|------|
| K 线 | 涨幅 ≥ 5%；实体占振幅 > 60%；上影线 ≤ 实体 × 1/2 |
| 量能 | 当日量 ≥ 昨日 × **2** 且 ≥ 5 日均量 × **1.5**，且 ≤ 5 日均量 × **5** |
| 穿线 | 收盘同时高于 MA5/10/20/30 中**至少 3 条** |
| 粘合 | 四线 `(MAX−MIN)/收盘价 ≤ 3%`（MA5/10/20/30） |
| 趋势位 | 收盘 > MA60，且（MA60 > MA120 **或** MA60 较 5 日前抬高） |
| 风控（完整版） | 未翻倍：`收盘 < 近250日最低价×2`；**RPS120≥80 或 RPS250≥80** |

**主图视觉约定（入场信号）**：信号日 K 线 **黄色粗柱** + **图标** + **「朝天椒」文字**（见第三节）。

## 二、本地选股公式（通达信条件选股）

### 2.1 操作路径

1. 打开通达信 → **功能** → **选股器** → **条件选股**  
2. **其它类型** → **新建条件**（或 **导入公式**）  
3. 公式名称建议：`朝天椒选股` 或 `HK_CTJ`  
4. 将下面 **2.2 完整版** 整段粘贴 → **确定** → 执行选股  
5. 选股结束后：**选股结果** → 右键 → **批量操作** → **加入到板块** → 新建如 `朝天椒_20260416`（或 `RPS_CTJ_日期`）

### 2.2 完整版（含 RPS + 未翻倍）

与 [tdx_formulas_hong_zhanfa.md](tdx_formulas_hong_zhanfa.md) 第二节一致，末行 **`朝天椒;`** 为选股输出。

```text
{======== 朝天椒选股 · 完整版（需 RPS 扩展数据 6/7）========}
HC120:=EXTDATA_USER(6,0);
HC250:=EXTDATA_USER(7,0);
RPS120:=HC120/10;
RPS250:=HC250/10;
未翻倍:=C<LLV(L,250)*2;
RPS强:=RPS120>=80 OR RPS250>=80;

MA5:=MA(C,5);
MA10:=MA(C,10);
MA20:=MA(C,20);
MA30:=MA(C,30);
MA60:=MA(C,60);
MA120:=MA(C,120);

涨幅:=(C-REF(C,1))/REF(C,1);
实体:=ABS(C-O);
振幅:=H-L;
实体比:=实体/(振幅+0.001);
上影:=H-MAX(C,O);

倍量:=V>=REF(V,1)*2 AND V>=MA(V,5)*1.5 AND V<=MA(V,5)*5;

N1:=IF(C>MA5,1,0);
N2:=IF(C>MA10,1,0);
N3:=IF(C>MA20,1,0);
N4:=IF(C>MA30,1,0);
穿线数:=N1+N2+N3+N4;

MMAX:=MAX(MAX(MA5,MA10),MAX(MA20,MA30));
MMIN:=MIN(MIN(MA5,MA10),MIN(MA20,MA30));
粘合:=(MMAX-MMIN)/C<=0.03;

趋势位:=C>MA60 AND (MA60>MA120 OR MA60>REF(MA60,5));

K形:=涨幅>=0.05 AND 实体比>0.6 AND 上影<=实体*0.5;

朝天椒:=K形 AND 倍量 AND 穿线数>=3 AND 粘合 AND 趋势位 AND 未翻倍 AND RPS强;

朝天椒;
```

## 三、主图叠加公式（图标 + 文字 + K 线高亮）

### 3.1 操作路径

1. **功能** → **公式系统** → **公式管理器**（或 **Ctrl + F**）  
2. **技术指标公式** → **其它类型** → **新建**  
3. 画线方法选 **主图叠加**（不要选副图）  
4. 公式名称建议：`朝天椒主图` 或 `HK_CTJ_MAIN`  
5. 粘贴 **3.3 完整主图公式** → **确定** → 在 K 线图界面 **主图指标** 里勾选该指标  

### 3.2 视觉效果说明（文字示意）

- **信号日**：整根 K 线（最高到最低）用 **黄色竖条**（`STICKLINE`）加粗显示。  
- **图标**：在当日最低价略下方画 **小图标**（默认 13 号，见下表）。  
- **文字**：在图标下方显示红色 **「朝天椒」** 四字。  
- **均线**：白/黄/洋红/绿/红 分别为 MA5/10/20/30/60，便于肉眼判断粘合与穿线。  
- **副显示**：可选显示「近 60 日内信号次数」「距上次信号 K 线数」，便于复盘。

### 3.3 图标编号对照（任选其一改 `DRAWICON` 第三参数）

不同通达信版本图标略有差异，下列为常见编号的大致含义，**以你本机显示为准**：

| 编号 | 常见视觉效果（参考） |
|------|----------------------|
| **1** | 小圆点 / 标记点 |
| **11** | 向上箭头类标记 |
| **13** | 向上箭头 / 买入类图标（**默认推荐**） |
| **29** | 旗帜 / 提示类图标 |
| **34** | 星形 / 醒目标记 |

修改方式：将下面公式中的 `DRAWICON(朝天椒,L*0.97,13)` 最后一个数字改为 **1、11、13、29、34** 之一即可。

### 3.4 完整主图叠加公式

逻辑与 **2.2 完整版** 完全一致（含 RPS + 未翻倍）。若未配置 RPS，请将 `HC120`～`RPS强` 及 `朝天椒` 最后一行改为与 **2.3 精简版** 相同的 `朝天椒精简` 定义（文档 2.3 已给出，主图里把 `朝天椒` 换成 `朝天椒精简` 即可）。

```text
{======== 朝天椒 · 主图叠加（完整版）========}
{均线}
MA5:MA(C,5),COLORWHITE;
MA10:MA(C,10),COLORYELLOW;
MA20:MA(C,20),COLORMAGENTA;
MA30:MA(C,30),COLORGREEN;
MA60:MA(C,60),COLORRED;

{与选股相同的核心条件}
HC120:=EXTDATA_USER(6,0);
HC250:=EXTDATA_USER(7,0);
RPS120:=HC120/10;
RPS250:=HC250/10;
未翻倍:=C<LLV(L,250)*2;
RPS强:=RPS120>=80 OR RPS250>=80;

MA5V:=MA(C,5);
MA10V:=MA(C,10);
MA20V:=MA(C,20);
MA30V:=MA(C,30);
MA60V:=MA(C,60);
MA120V:=MA(C,120);

涨幅:=(C-REF(C,1))/REF(C,1);
实体:=ABS(C-O);
振幅:=H-L;
实体比:=实体/(振幅+0.001);
上影:=H-MAX(C,O);
倍量:=V>=REF(V,1)*2 AND V>=MA(V,5)*1.5 AND V<=MA(V,5)*5;

N1:=IF(C>MA5V,1,0);
N2:=IF(C>MA10V,1,0);
N3:=IF(C>MA20V,1,0);
N4:=IF(C>MA30V,1,0);
穿线数:=N1+N2+N3+N4;

MMAX:=MAX(MAX(MA5V,MA10V),MAX(MA20V,MA30V));
MMIN:=MIN(MIN(MA5V,MA10V),MIN(MA20V,MA30V));
粘合:=(MMAX-MMIN)/C<=0.03;

趋势位:=C>MA60V AND (MA60V>MA120V OR MA60V>REF(MA60V,5));
K形:=涨幅>=0.05 AND 实体比>0.6 AND 上影<=实体*0.5;

朝天椒:=K形 AND 倍量 AND 穿线数>=3 AND 粘合 AND 趋势位 AND 未翻倍 AND RPS强;

{信号K线高亮：整根黄色宽柱}
STICKLINE(朝天椒,H,L,0.8,0),COLORYELLOW;
STICKLINE(朝天椒,O,C,3,0),COLORYELLOW;

{图标 + 文字：图标在低价下方，文字再略低}
DRAWICON(朝天椒,L*0.97,13);
DRAWTEXT(朝天椒,L*0.93,'朝天椒'),COLORRED;

{辅助：距上次信号 K 线数；近60日出现次数}
距上次:BARSLAST(朝天椒),NODRAW;
近60次数:COUNT(朝天椒,60),NODRAW;
```

**说明**

- `STICKLINE` 画两次：一次 **影线**（H–L），一次 **实体**（O–C），实体线宽 `3` 可按屏幕再调大/小。  
- `NODRAW` 的两行默认不在主图显示数值；若要在图上看到数字，可把某一行的 `NODRAW` 去掉，或改用 `DRAWNUMBER_FIX`（视版本而定）。  
- 若文字与 K 线重叠，可把 `L*0.93` 改为 `L*0.88` 或 `L*0.85`。

## 四、参数速查与严松两档

| 参数 | 默认（文档） | 严格档 | 宽松档 |
|------|----------------|--------|--------|
| 涨幅 | ≥ 5% (`0.05`) | ≥ 6% (`0.06`) | ≥ 4% (`0.04`) |
| 昨量倍数 | ≥ 2 | ≥ 2.5 | ≥ 1.8 |
| 5 日均量下限倍数 | ≥ 1.5 | ≥ 2.0 | ≥ 1.3 |
| 粘合 `(MMAX-MMIN)/C` | ≤ 3% | ≤ 2.5% (`0.025`) | ≤ 4% (`0.04`) |
| 实体/振幅 | > 60% | > 65% | > 55% |
| RPS | ≥ 80 | ≥ 85 | ≥ 75 |

在公式中直接改对应数字即可；严松两档不要同时混用，建议复制两份公式分别命名 `朝天椒_严` / `朝天椒_宽`。

## 五、常见报错与排查

| 现象 | 可能原因 | 处理 |
|------|-----------|------|
| 提示 **未知函数 EXTDATA_USER** | 未配置或未刷新 RPS 扩展数据 | 按 [tdx_rps_extension_zhutu.md](tdx_rps_extension_zhutu.md) 配置；或改用 **2.3 精简版** |
| 选股结果 **为空** | 条件过严（粘合+RPS+倍量同时满足较少） | 先改用精简版；或放宽「粘合」「RPS」阈值 |
| 主图 **无图标/无文字** | 未选「主图叠加」；或当前周期不是 **日线** | 切到日线；检查公式画线方法 |
| 主图 **满屏黄色** | `STICKLINE` 条件恒真 | 检查 `朝天椒` 是否误写成无条件的 1 |
| **剔除 ST** | 公式未写 | 选股界面勾选「剔除 ST」；或加 `NOT(NAMELIKE('ST'))`（视版本语法） |
