# 左边高点突破 / 即将突破策略 (Pivot Breakout)

> A 股 RPS 系统 — 捕捉"经过回踩、正在突破或即将突破左边关键高点(pivot)"的票。
> 对应欧奈尔 / Minervini 的**平台突破买点**。Python 实现：`rps_analyzer/breakout_pivot_screener.py`；通达信公式见第 5 节。

---

## 1. 策略定位

| 维度 | 说明 |
|---|---|
| 选股节奏 | **同步**（突破当日 / 突破前 1~N 日） |
| 信号性质 | 趋势中继 + 关键阻力突破，**右侧**为主、留一档"即将突破"做左侧埋伏 |
| 与现有层级关系 | 建议与 **L1**（`RPS_sum≥180`）取交集；本策略提供"突破触发"时点，L1 提供"强度门槛" |
| 典型当日数量 | 全市场约 30~120 只（突破 + 即将突破合计） |

**和"早期启涨"的区别**：早期启涨抓的是*刚离开底部、上 MA20 的启动段*；本策略抓的是*已经走出一段、回踩成形后再度挑战左侧前高*的二次突破点（更接近经典杯柄/平台突破）。

---

## 2. 核心概念：什么是"左边高点 (左高 / pivot)"

在 **\[今天 − `recent_gap` − `peak_lookback`, 今天 − `recent_gap`\]** 这段"靠左"的窗口里取**最高价**，作为待突破的关键阻力。

```
        左高(pivot)
          ┌─●─┐                         ← 关键阻力 = 待突破/即将突破的高点
         /     \         ╱▍ ← 今天(突破 or 贴近)
        /       \___    ╱
   ____/            \__╱      ← 基底(base): 左高之后的回踩
   |<-- peak_lookback -->|<gap>|
                              ↑ 排除最近 recent_gap 天, 避免把"当前这波拉升"误当成左高
```

**为什么排除最近 `recent_gap` 天**：如果直接用 `HHV(H,120)`，当股票今天创新高时，"左高"会等于今天本身，永远无法判断"突破"。排除最近 N 天，才能让"左高"始终是一个**真正在左侧、已经成形**的前高。

## 3. 选股逻辑

两档信号，**二选一即入选**（都要先过"通用风控"）。

### 3.1 通用风控（两档都要满足）

| 代号 | 含义 | 默认阈值 |
|---|---|---|
| G1 | RPS_120 强度 | ≥ 80 |
| G2 | 趋势向上 | `close > MA20` 且 `close > MA50` 且 `MA20` 5 日不走低 |
| G3 | 基底回撤可控 | 左高 → 基底最低 回撤 ≤ 30% |
| G4 | 未翻倍（可关） | `close < LLV(low,250) × 2`，与洪战法风控一致 |
| G5 | 成交活跃 | `amount ≥ 5000万` |

### 3.2 \[突破\] BREAKOUT — 已经站上左高

| 代号 | 含义 | 默认阈值 |
|---|---|---|
| BO1 | 收盘突破左高 | `close > 左高 × (1 + 0)` |
| BO2 | **新鲜突破** | 最近 `≤3` 日才首次站上，且近 8 日站上天数 ≤ 4（排除"突破已久"） |
| BO3 | 放量确认 | 突破段内最大量 ≥ `1.5 ×` 60 日均量 |
| BO4 | 不过度追高 | `close` 距左高涨幅 ≤ 12% |

### 3.3 \[即将突破\] PRE_BREAKOUT — 贴在左高下方蓄势

| 代号 | 含义 | 默认阈值 |
|---|---|---|
| PB1 | 逼近左高 | `close` 在左高下方 0 ~ 7% 区间内 |
| PB2 | 平台收敛 | 近 15 日振幅 `(HHV−LLV)/close ≤ 12%` |
| PB3 | 缩量盘整 | 平台 10 日均量 ≤ 60 日均量（量能干涸） |

> **设计取舍**：
> - "即将突破"是**左侧埋伏**，胜率低于"突破"，建议小仓试探、突破当日再加仓。
> - 默认 `not_doubled=True`（未翻倍）。若专做强势翻倍股的二波，可在配置里关掉它。

## 4. 实战使用（Python）

```bash
# 用项目缓存的带 RPS 日线数据
py -3 -m rps_analyzer.breakout_pivot_screener \
    --data output/cache_tdx_with_rps.parquet \
    --date 20260601 \
    --output output/tdx_screener_20260601_breakout.csv
```

代码内调用（推荐与 L1 取交集）：

```python
from rps_analyzer.breakout_pivot_screener import (
    screen_breakout_pivot, BreakoutConfig, print_breakout_summary,
)

res = screen_breakout_pivot(
    df_daily,                       # 含 RPS_120 的全市场日线
    target_date="20260601",
    candidate_codes=l1_codes,       # 传 L1 代码 → 突破 ∩ L1 (推荐)
    config=BreakoutConfig(rps_min=80),
)
print_breakout_summary(res)
# res["SIGNAL"] ∈ {"突破", "即将突破"}; 含 pivot / ext_pct / base_depth_pct / seg_max_vol_x 等明细
```

### 4.1 输出列

| 列 | 含义 |
|---|---|
| `SIGNAL` | `突破` / `即将突破` |
| `pivot` / `pivot_date` | 左高价位 / 形成日期 |
| `ext_pct` | 收盘距左高的涨幅%（>0 已破，<0 在下方） |
| `base_depth_pct` | 左高 → 基底最低 的回撤% |
| `above_streak` | 连续站上左高的天数（突破档新鲜度） |
| `seg_max_vol_x` | 突破段内最大量 / 60 日均量 |
| `tight_amp_pct` / `pb_vol_x` | 平台振幅% / 平台量比（即将突破档） |

### 4.2 仓位与纪律（建议）

| 维度 | 突破档 | 即将突破档 |
|---|---|---|
| 首仓 | 2~3% | 0.5~1%（试探） |
| 加仓 | 放量站稳 3 日加 | **转为"突破档"后**再加 |
| 止损 | 跌回左高下方 −3~5% / 或 −8% 固定 | 跌破平台低点 |
| 止盈 | +20% 减半，剩余跟 MA10/MA20 | 同左 |

## 5. 通达信条件选股公式

> 用法：**功能 → 选股器 → 条件选股 → 其它类型 → 新建**，粘贴下列公式。
> `RPS120` 依赖扩展数据 `EXTDATA_USER(6)`（与 `tdx_rps_extension_zhutu.md` 一致，数值 /10 得 0~100）。
> 若未配置 RPS 扩展数据，可把 `RPS强` 一行删掉或改用其它强度条件。

```text
{======== 左边高点 突破 / 即将突破 ========}
HC120:=EXTDATA_USER(6,0);
RPS120:=HC120/10;

MA20:=MA(C,20);
MA50:=MA(C,50);
量基:=MA(V,60);

{--- 左边高点(pivot): 排除最近 MM 日, 向左 NN 日的最高价 ---}
NN:=120;
MM:=10;
左高:=REF(HHV(H,NN),MM);
距高:=C/左高-1;                         {>0 已突破, <0 仍在下方}

{--- 通用风控 ---}
RPS强:=RPS120>=80;
未翻倍:=C<LLV(L,250)*2;
趋势:=C>MA20 AND C>MA50 AND MA20>=REF(MA20,5);
基底深:=(左高-LLV(L,40))/左高<=0.30;     {基底回撤可控(近40日低点近似)}
风控:=RPS强 AND 未翻倍 AND 趋势 AND 基底深;

{--- [突破] 已站上左高 ---}
首破:=C>左高 AND REF(C,1)<=左高;          {今日首次站上左高}
新鲜:=COUNT(C>左高,3)>=1 AND COUNT(C>左高,8)<=4;  {突破不超过数日}
放量:=HHV(V,3)>=量基*1.5;                 {近 3 日有放量}
不追高:=距高<=0.12;
突破:=(首破 OR 新鲜) AND 放量 AND 不追高;

{--- [即将突破] 贴在左高下方蓄势 ---}
逼近:=距高>=-0.07 AND 距高<=0;
平台:=(HHV(H,15)-LLV(L,15))/C<=0.12;
缩量:=MA(V,10)<=量基;
即将:=逼近 AND 平台 AND 缩量;

选股:=风控 AND (突破 OR 即将);
选股;
```

### 5.1 只要"突破"（更挑剔、偏右侧）

把最后两行改为：

```text
选股:=风控 AND 突破;
选股;
```

### 5.2 主图标记信号（看盘用，不选股）

```text
{同上定义 风控/突破/即将 后}
信号突破:=风控 AND 突破;
信号即将:=风控 AND 即将;
DRAWICON(信号突破,L*0.98,1);     {突破: 图标1}
DRAWICON(信号即将,L*0.98,2);     {即将突破: 图标2}
DRAWLINE(1,左高,1,左高,0),COLORYELLOW;   {黄线标出左边高点}
```

### 5.3 更精确的"基底回撤"（可选）

主公式用 `LLV(L,40)` 近似基底低点。若想严格取"自左高以来"的最低，可用：

```text
峰距:=REF(HHVBARS(H,NN),MM)+MM;          {左高距今的交易日数}
基底深:=(左高-LLV(L,峰距+1))/左高<=0.30;  {自左高以来的回撤}
```

部分通达信版本支持变量作为 `LLV` 的周期参数；若报错，沿用主公式的固定窗口即可。

## 6. 参数速查

| 参数 | 默认 | 收紧（更少更挑剔） | 放宽（更多） |
|---|---|---|---|
| `rps_min` | 80 | 90 | 70 |
| `peak_lookback` | 120 | 250（更长期前高） | 60 |
| `recent_gap` | 10 | 15 | 5 |
| `bo_fresh_days` | 3 | 1（只要突破首日） | 5 |
| `bo_vol_x` | 1.5 | 2.0 | 1.3 |
| `bo_ext_max` | 12% | 6% | 18% |
| `pb_near_max` | 7% | 4% | 10% |
| `pb_tight_max` | 12% | 8% | 15% |
| `base_depth_max` | 30% | 25% | 35% |

## 7. 已知局限

1. **左高定义对参数敏感**：`peak_lookback` / `recent_gap` 决定"哪个高点算左高"。趋势票宜用 120，长期平台票可调 250。
2. **"即将突破"是左侧信号**：胜率与盈亏比都弱于"突破"，务必小仓、且以"突破确认"为加仓条件。
3. **未做行业分散**：突破常成簇出现于同一题材，需配合行业分散纪律。
4. **未单独做成本回测**：阈值为经验默认值，建议接入项目回测脚本（参考 `verify_early_forward*.py` 的前瞻验证框架）做校准后再实盘。
