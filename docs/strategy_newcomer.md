# 次新股策略（独立框架，与 RPS 系统并行）

> 适用范围：上市 < 120 天的票（RPS_120 算不出来），不进 SOP 核心/机动槽。

---

## 0. 为什么 RPS 系统不适用

| 指标 | 计算窗口 | 次新股影响 |
|---|---|---|
| RPS_120 | 120 个交易日 | 算不出 / 用首日填充失真 |
| RPS_250 | 250 个交易日 | 算不出 |
| MA60 / MA120 | 60-120 日 | 算不出 / 头部还是首日均价 |
| Super 持续性 | 21 日窗口里"双 98"满足天数 | 永远 0（RPS 算不出来） |
| Huoche（周线火车轨） | ≥ 8 周历史 | 算不出 |

强行用 SOP 纪律去交易次新股，**会被以下规则误伤**：
- 「硬止损 -8%」对一字跌停太宽（一字板就 -10%）
- 「持仓 30 天浮盈 < 5% 时间止损」对次新太长（5-10 天就要决断）
- 「核心槽 8-10% 仓位」对次新太重（流动性溢价容易快速反转）

→ 次新股**必须用独立的策略和仓位规则**。

## 1. 次新股的本质

**驱动因素**：流动性溢价 + 游资接力 + 题材想象力，**不是基本面或趋势**。

**典型节奏**：

```
开板首日 → 高换手 (≥流通盘 50%) → 震荡缩量 (3-10 天) → 首阳启动 → 量价突破前高 → 加速 → 顶背离/缩量 → 回落
   D0          D1-D2           D3-D10                 D11-D15      D15-D20    D20-D30   D30+
```

**4/16 上市的 [301666.SZ](../tools/diagnose_newcomer.py)**：D0-D2 高位震荡 → D5-D8 缩量企稳 → D9-D10 放量启动（教科书节奏）。
**4/24 上市的 688808.SH**：D0 巨量开板（114 亿）→ D1-D4 阶梯上行（首日成交即接近流通盘全换手）。

## 2. 4 阶段操作框架

### 2.1 D0-D2「开板期」— 只观察，不参与

| 观察项 | 含义 | 阈值 |
|---|---|---|
| 首日换手率 | 流动性强度 | ≥ 50%（流通盘小可放宽到 30%） |
| 首日成交额 | 资金兴趣 | ≥ 30 亿（≥ 100 亿是巨量典型）|
| 首日收盘 / 开盘 | 当日资金态度 | > 1.0 = 高开低走的反向，< 1.0 = 收阴 |

**不买**。原因：开板情绪混乱，振幅 30-50% 是常态。

### 2.2 D3-D10「震荡企稳期」— 等首阳

观察"缩量"信号：

| 信号 | 阈值 | 含义 |
|---|---|---|
| 成交额连续递减 | 连续 3 日 ≤ 上日 80% | 抛压释放，进入沉默期 |
| 5 日均量 < 首日量 30% | | 主动卖盘衰竭 |
| 收盘站上 5 日均线 | 连续 2 日 | 短线趋势止跌 |

满足以上 2 条 → 进入"准备建仓"窗口。

### 2.3 D10-D20「首阳启动期」— 试仓 1/3

**入场触发（必须全部满足）**：

| 条件 | 阈值 |
|---|---|
| 量能 | 当日成交额 > 5 日均量 1.5 倍 |
| 价格 | 收盘 > 5 日均线 + 收盘 > 当日开盘（实体阳） |
| 涨幅 | +3% ≤ 涨幅 ≤ +10%（避免追涨停一字）|

**仓位**：单票 ≤ **3%**（远小于 SOP 核心槽 8-10%）。

### 2.4 D20+「加速 / 退出期」— 严格止盈

**加仓条件**：突破首日高点 + 当日成交额 > 前 3 日均量 1.2 倍 → 加到 5%。

**退出触发（任一）**：

| 触发 | 动作 |
|---|---|
| 跌破 5 日均线 | **立即清仓**（不等次日，不讨论）|
| 单日跌停 | 收盘前 30 分钟未拉回 → 清仓 |
| 量价背离 | 价创新高 + 量明显萎缩（< 前高量 60%）→ 减半 |
| 浮盈 ≥ 30% | 减半（次新涨速快，30% 已经是合理目标）|
| 浮盈 ≥ 50% | 全清 |
| 持仓满 30 天浮盈 < 5% | 时间止损（次新失去溢价） |

## 3. 与 RPS 系统的衔接

**触发"毕业"条件**：上市满 120 天后，重新进入 RPS 系统：

1. 重跑 `run_tdx_screener.py`，看是否进入 L1
2. 跑 `run_persistence_scan.py`，看是否进入 Super 持续性榜
3. 满足 SOP §2.1 阈值 → 转入核心槽（持仓比例同时上调 3% → 8%）

**不毕业则继续按次新规则管理**，最长持有 90 天后强制清仓（避免次新红利窗口过期）。

---

## 4. 仓位上限

| 维度 | 上限 |
|---|---:|
| 单只次新股 | 3% (D10-D20 试仓) → 5% (突破加仓) |
| 同时持有次新股数 | ≤ 3 只 |
| 总次新股仓位 | ≤ 12% |
| **次新仓位 + SOP 核心仓位** | ≤ 80%（强市）/ 60%（中性）/ 30%（弱市）|

弱市/冰点期**完全不参与次新**——流动性溢价首先消失。

## 6. 已知教训（持续迭代）

| 教训 | 出处 |
|---|---|
| **首日 +200% 不要追** | 多年游资规律：开板日首日涨幅高的，D5 前回撤超 20% 概率 > 70% |
| **缩量企稳必须 ≥ 3 天** | 仅 1 天缩量就启动 → 假突破概率高 |
| **次新最大对手不是技术，而是注册制大批新票上市** | 同期 5+ 只新股共上市，资金会分流，单只难走出独立行情 |

## 7. 与 SOP 主文档的边界

| 议题 | SOP 主文档 | 本文档 |
|---|---|---|
| 持仓周期 | 月度级（核心）/ 1-2 周（机动）| 5-30 天 |
| 信号来源 | RPS / Super / Huoche / Early | 量价 / 换手率 / 题材 |
| 止损阈值 | -8% 硬止损 + MA60 失守 | -5% 硬止损 + 5 日均线失守 |
| 单票仓位 | 8-10% (核心) / 5-7% (机动) | 3-5% |
| 数据基础 | 250 日历史 | 5-30 日历史 |

**两个体系不交叉**——次新毕业（上市满 120 天）后才进入 SOP 主体系。
