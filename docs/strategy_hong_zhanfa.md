# 洪战法三大选股体系（量化实现版）

> 三套战法分别对应不同市场阶段：朝天椒抓**启动拐点**、大阳共振抓**趋势加速**、中线趋势做**波段持有**。

---

## 一、朝天椒战法（均线粘合突破）

**适用场景**：长期横盘/下跌后均线收敛，资金突然介入的第一根信号K线。

### K线形态
- 涨幅 ≥ 5%（涨停最优）
- 实体占当日振幅 > 60%（实体 = |收盘-开盘|，振幅 = 最高-最低）
- 上影线 ≤ 实体 × 1/2（允许略有试探，因首次穿越均线阻力正常）

### 量能异动（双重确认）
- 条件A：当日成交量 ≥ 前一日的 **2倍**（捕捉突变性）
- 条件B：当日成交量 ≥ 近5日均量的 **1.5倍**（排除前日异常缩量的干扰）
- 上限：当日成交量 ≤ 近5日均量的 **5倍**（超出则为异常抛盘换手，谨慎对待）
- **A和B同时满足**

### 均线突破与粘合
- 当日收盘价同时 > MA5、MA10、MA20、MA30 中的至少3条（即"一阳穿多线"）
- **均线粘合度量化**：取参与判断的均线中最大值与最小值，要求 (MAX - MIN) / 收盘价 ≤ **3%**
  - 含义：多条均线挤压在3%的狭窄区间内，说明多空成本趋同，蓄势充分

### 趋势位置
- 收盘价 > MA60（站上60日均线）
- MA60 > MA120 或 MA60 拐头向上（60日线斜率近5日为正）

## 二、大阳共振一飞冲天（趋势加速突破）

**适用场景**：均线已多头排列，趋势确立后放量突破关键压力位的加速信号。

### 大阳标准
- 涨幅 ≥ 5%
- 实体占当日振幅 > 50%
- 上影线 ≤ 实体 × 1/3（比朝天椒更严格，要求突破后抛压极小，收盘确定性高）

### 量能确认
- 当日成交量 ≥ 近5日均量的 **1.5倍**
- 当日成交量 ≤ 近5日均量的 **3倍**（超出3倍视为天量诱多，主力可能借机出货）

### 趋势共振（多头排列）
- MA5 > MA10 > MA20 > MA60（严格多头排列）
- 收盘价 > MA60

### 突破有效性（满足以下至少一项）
- **突破前高**：收盘价 > 近20日最高价（突破20日新高）
- **突破小平台**：近5~15个交易日内存在一段振幅 ≤ 8%的横盘区间（至少5日），当日收盘价 > 该区间最高价
  - 小平台定义：连续N日（5 ≤ N ≤ 15），期间 (最高价MAX - 最低价MIN) / MIN ≤ 8%
- **突破关键均线**：前一日收盘价 < MA60 或 MA120，当日收盘价 > 该均线

### 主升信号（MACD确认）
- MACD的DIFF > 0 且 DEA > 0（零轴上方运行）
- DIFF > DEA（金叉状态）
- 当日MACD柱 > 前一日MACD柱（红柱放大）

## 三、中线趋势战法（顺势回踩低吸）

**适用场景**：大趋势向上确立后，利用回调至20日线附近的机会低吸。

### 趋势锚定
- MA20 > MA60 > MA250（多头排列）
- MA250 斜率 ≥ 0（年线走平或上行，用近20日MA250差值判断）
- 收盘价 > MA20

### 动量确认（至少满足2项）
- RSI(14) > 50 且 RSI(14) > 前一日RSI(14)（上行趋势中）
- ROC(12) > 0（12日变动率为正）
- MACD：DIFF > DEA 且 当日MACD柱 > 0

### 量价健康
- 上涨放量：近3个上涨日的平均成交量 > 近3个下跌日的平均成交量 × 1.2
- 回调缩量：若当日为回调日（收阴），成交量 < 近5日均量 × 0.8
- 二次放量上攻确认：阳线日成交量 ≥ 近5日均量 × 1.5

### 节奏买卖
- **买入条件**：收盘价回踩至 MA20 × 1.02 以内（贴近20日线），且当日收阳
- **止盈参考**：RSI(14) > 80 或 乖离率(收盘价/MA20 - 1) > 15% 时减仓
- **止损条件**：收盘价连续2日 < MA20，或 RSI(14) < 50

## 四、通用风控与实操

### 位置筛选（三大战法共用）
- **回避高位**：当前股价 < 近250日最低价 × 2.0（即距离年内低点涨幅未超过100%）
- **低位启动区间**：当前股价在近120日最低价之上 0~50% 区间（低位）；或股价距近期高点回撤 ≥ 20% 后重新放量（中途蓄势）
- **结合RPS**：个股RPS(50) ≥ 80 或 RPS(120) ≥ 80（具备中期相对强度，排除纯弱势反弹）

### 行业板块过滤
- 个股所属行业的行业RPS排名 ≥ 前30%（行业RPS ≥ 70）
- 含义：A股板块效应显著，个股强+行业强的共振胜率远高于逆势独行侠

### 周期匹配
- 中线方向确认：月线级别MACD金叉（DIFF上穿DEA）或红柱持续放大
- 日线择时：在月线方向向上的前提下，日线回踩20日线时执行买入

### 止损纪律
| 战法 | 止损位 | 判定规则 |
|------|--------|---------|
| 朝天椒 | 信号K线最低价 | 收盘价跌破该低点即止损 |
| 大阳共振 | 大阳线最低价 | 收盘价跌破该低点即止损 |
| 中线趋势 | 20日均线 | 收盘价连续2日低于MA20 |

### 仓位管理建议
- 单票仓位 ≤ 总资金的 20%
- 同时持仓不超过5只
- 朝天椒/大阳共振为短线，建议半仓试探，突破确认后加仓
- 中线趋势可一次性建仓，但须严守止损

## 五、三大战法鉴别要点

| 维度 | 朝天椒 | 大阳共振 | 中线趋势 |
|------|--------|---------|---------|
| **均线状态** | 粘合收敛（无趋势） | 多头排列（趋势已成） | 多头排列+年线上行 |
| **核心动作** | 一阳穿多线 | 放量过压力位 | 回踩20日线低吸 |
| **量能特征** | 爆量（≥前日2倍） | 温和放量（1.5-3倍均量） | 缩量回调后放量 |
| **持仓周期** | 3-8日 | 5-15日 | 20-60日 |
| **止损幅度** | 约5-8% | 约5-8% | 约3-5%（贴MA20） |
| **优先级** | 若与大阳共振同时触发，以大阳共振为准（趋势已确认，确定性更高） |
