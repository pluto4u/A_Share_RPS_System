# A股情绪策略 — 到底怎么用

> 最后更新: 2026-02-20 | 基于 2024-01 ~ 2026-02 回测数据

---

## 一句话结论

**情绪因子不是用来预测涨跌的，是用来控制仓位的。**

回测证明：情绪分数对"明天涨不涨"的预测力很弱 (AUC=0.54)，但用它来连续调节仓位，可以在几乎不损失收益的前提下，**把最大回撤压缩一半**。

---

## 核心规则 (S5 LinearThrottle)

```
情绪分          目标仓位
 0 ~ 12.5       0%     极冷: 空仓
12.5 ~ 37.5    25%     偏冷: 轻仓
37.5 ~ 62.5    50%     正常: 半仓
62.5 ~ 87.5    75%     偏热: 重仓
87.5 ~ 100    100%     过热: 满仓
```

**防抖规则 (防止频繁操作):**
- 距上次调仓 **≥ 5个交易日**
- 目标仓位与当前仓位差距 **≥ 15%**
- 两个条件**同时满足**才执行调仓

**为什么不是"极恐时清仓"(S2)?**

| 策略 | 年化 | 最大回撤 | Sharpe |
|------|------|---------|--------|
| S2 极恐清仓 | 13.2% | -15.7% | 0.734 |
| **S5 连续调仓** | **13.9%** | **-9.2%** | **1.340** |

S2 只在极端情况才动，错过了情绪因子在"日常波动区间"内的信息。S5 把情绪分数的连续变化转化为连续的仓位调节，风险调整后收益全面胜出。

## 两种实盘方案

### 方案一: 懒人版 — S5 + 沪深300ETF (策略C)

**适合**: 没时间研究、不想换标的、只想控制风险的人

**操作流程**: 每天收盘后跑一次 (30秒)
```bash
python daily_signal.py
```

**你只需要做一件事**: 看仪表盘上的"当前持仓"和"目标仓位"，如果显示 `ADJUST`，就按提示操作。如果显示 `HOLD` 或 `PENDING`，什么都不做。

**持仓标的**: 永远只持有 510300 (沪深300ETF)，仓位跟着情绪走。

| 指标 | 结果 |
|------|------|
| 年化收益 | 19.9% |
| 最大回撤 | **-7.7%** (买持是 -17.1%) |
| Sharpe | **1.688** |
| 换仓次数 | 0 (不换标的，只调仓位) |

**优点**: 极简、零决策负担、回撤极低
**缺点**: 不追求超额收益

---

### 方案二: 进阶版 — S5 + ETF月度轮动 (策略D)

**适合**: 每月愿意花30分钟看一次、追求更高收益的人

**操作流程**: 两步

**步骤1 (每天)**: 看仓位
```bash
python daily_signal.py
```

**步骤2 (每月最后一个交易日)**: 看标的
```bash
python -m emotion_validation.etf_rotation.rotation_strategy
```

**换仓规则**:
- 每月底系统输出建议持有的 2 只 ETF
- 如果建议标的跟当前一样 → 不动
- 如果不一样 → 下月第一个交易日开盘换仓
- 情绪偏冷/极冷时，系统自动收窄候选池到防御类 ETF

| 指标 | 结果 |
|------|------|
| 年化收益 | **32.7%** |
| 最大回撤 | **-10.2%** (买持是 -17.1%) |
| Sharpe | **1.729** |
| 月均换仓 | ~1次/月 |

**优点**: 年化几乎翻倍，Sharpe 最高
**缺点**: 需要每月换仓一次，有少量交易摩擦

## 常见问题

**Q: 情绪分数从哪来？**
从全市场 5269 只股票的日线数据中逐日计算：涨停家数、跌停家数、涨跌比、炸板率、连板高度等 16 个因子，加权得到 0~100 的综合分数。

**Q: 数据怎么更新？**
```bash
# 更新全市场数据 (日常增量, 约 2-3 分钟)
python -m emotion_validation.data_layer.data_warehouse --update

# 重新计算情绪评分
python -m emotion_validation.pipeline

# 更新 ETF 数据
python -m emotion_validation.etf_rotation.etf_data
```

**Q: 为什么不直接用情绪分预测明天涨跌？**
回测 Rank IC 全部不显著 (p>0.05)，AUC 仅 0.54。情绪分是同步/滞后指标，不是领先指标。但它对风险暴露的度量是有效的（high-low 日均收益差 0.29%），所以用来调仓位而不是择时。

**Q: 回测时间太短 (2年)，结果可靠吗？**
坦率说，2024-2025 以牛市为主，S5 的"保险价值"（熊市中减少损失）在数据中体现得不够充分。需要延长到 2022-2023 熊市区间验证后才能有更高置信度。当前结论是"有效但需谨慎"。

**Q: 方案一和方案二怎么选？**
- 如果你每月只愿意花 5 分钟 → 方案一 (C)
- 如果你每月愿意花 30 分钟 → 方案二 (D)
- 两者的风控效果接近，差别在于 D 的 ETF 轮动提供了额外的板块动量 alpha
