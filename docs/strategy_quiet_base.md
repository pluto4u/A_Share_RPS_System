# 静默筑底 · 低位再启动 (Quiet Base Relaunch)

> A 股 RPS 系统 — 捕捉"经历科技抱团 A 杀后**已经跌透、横盘充分、筹码干净**，现在刚站上 MA20 可以买入"的低位票。
> Python 实现：`rps_analyzer/quiet_base_screener.py`；每日入口 `scripts/screening/run_quiet_base.py`；通达信公式见第 5 节。

---

## 0. 市场背景（本策略的成因）

| # | 观察 | 对选股逻辑的含义 |
|---|---|---|
| 1 | A 股经历一轮**科技极致抱团**后的 A 杀，造成流动性问题 | 抱团票筹码极乱、上方套牢盘厚重；且流动性收缩，选股必须设**较高的成交额门槛**（默认 20 日均额 ≥ 8000 万） |
| 2 | A 股科技下跌与**美股、韩股同步** | 这轮科技下跌是全球性的，不是个别公司问题，靠"跌多了就反弹"去抄科技底不可靠 |
| 3 | 抱团过程中对**其他板块大量吸血** | 被吸血的板块在 5-6 月被动阴跌后横盘、成交枯竭，但基本面并未恶化；抱团瓦解后资金回流，这里才是**筹码最干净**的地方 |

因此本策略**反向**去找被吸血板块中已经充分调整的低位票，而不是去抄科技的底。

> **与仓内其它策略的方向差异（重要）**
> `breakout_pivot_screener` / `early_launch_screener` / `super_strong` / `huoche_screener` 都以 `RPS_120 >= 80` 的**高位强势股**为前提。本策略专找低位横盘票，这类票 `RPS_120` 通常很低，绝对强度门槛在这里会把目标全部筛掉。
> 所以本策略用 **RPS 拐头**（`RPS_120` 近 20 日抬升幅度）替代绝对强度门槛，只保留一个很低的地板值防止持续阴跌的垃圾股。

## 1. 策略定位

| 维度 | 说明 |
|---|---|
| 选股节奏 | **左侧偏中性**：基底形态是左侧（提前埋伏），站上 MA20 + 放量确认是右侧触发 |
| 信号性质 | 深跌后的**底部第一波启动**，不是趋势中继 |
| 与现有层级关系 | **不要与 L1 / RPS≥180 取交集**，两者互斥。本策略是 L1 体系之外的独立低位池 |
| 典型当日数量 | 实测 2026-07-27 全市场入选 **12 只**（可买入 0 / 观察 12）；4~6 月各观察日为 14~24 只。**底部区域"可买入"档天然稀疏**（多数日 0~6 只），观察池才是主要产出，可买入是从观察池逐日"毕业"出来的 |

**和「早期启涨」的区别**：`early_launch` 要求 `RPS_120` 已经很高、只是刚离开底部；本策略要求 `RPS_120` 仍在低位但**正在抬升**，位置比早期启涨还要靠前一档，代价是胜率更依赖大盘环境。

**和「左边高点突破」的区别**：`breakout_pivot` 突破的是**左侧前高**（已走出一段后的二次突破）；本策略突破的是**横盘箱体上沿**，且明确要求距离前期高点还有 25% 以上空间。

## 2. 核心概念：三段式滚动窗口

```
   [ 下跌段 drop ]          [ 基底期 base ]              [ 近期段 recent ]
   前期高点 ↘ A杀           窄幅横盘 / 地量 / 筹码干净     跌破后回升, 站上MA20 放量
   ══════════════           ══════════════════           ═══════════════
   T-(gap+base+250)  ..  T-(gap+base)  ..  T-gap  ..  T(今天)
   └─ pre_high 在这里取 ─┘  └─ box_high/box_low ─┘   └─ 买点在这里确认 ─┘

   默认 base_window=42, recent_gap=20, drop_lookback=250
```

三个窗口都是**滚动**的（按交易日倒数），策略长期可复用。以 **2026-07-29** 为目标日时：

| 窗口 | 交易日区间 | 约对应日期 |
|---|---|---|
| 下跌段 drop | T-312 ~ T-62 | 2025-04 ~ 2026-05-05 |
| 基底期 base | T-62 ~ T-20 | **2026-05-06 ~ 2026-06-30**（即 5-6 月的调整横盘段） |
| 近期段 recent | T-19 ~ T | 2026-07-01 ~ 2026-07-29 |

**为什么要留出 `recent_gap`**：箱体上下沿必须在**当前这波拉升之前**就已经成形。若直接用 `HHV(H,62)`，今天的拉升本身会把箱顶抬上去，"突破箱体"就永远无法判定。

**为什么"筹码干净"要用三个指标一起代理**：通达信 `.day` 文件既没有换手率也没有流通股本，拿不到真实筹码分布。可用的替代是——**地量**（B4，抛压枯竭）+ **窄箱体**（B1，成交价区间集中）+ **收盘价低离散度**（B5，长期在同一价位换手，成本高度集中）。深跌 30% 以上意味着上方套牢盘已经在下跌段割掉，三者叠加即可近似"筹码干净"。

### 2.1 箱体上下沿为什么用分位数，不用最高/最低价

箱体 = **基底期收盘价的 q90 / q10**，而不是 `max(high)` / `min(low)`。

实测（2026-07-27，A 组通过的 3617 只）：用极值口径的 42 日振幅中位数高达 **48%**，p10 都有 30.8%；22% 的门槛下只有 **1.9%** 的票能通过，策略等于死掉。换成收盘价分位数后中位数降到 **27%**，通过率约 29%。

原因是 A 股 42 个交易日里出现一两根长影线、一字板或单日跌停是常态，极值口径会被这些插针主导，量出来的不是"箱体"而是"极端波动范围"。分位数口径对应的才是实盘肉眼画箱体的方式。

> 真实极值仍保留在输出列 `base_high_raw` / `base_low_raw` 里；A1 的回撤深度用的是 `base_low_raw`（回撤要按真实最低点算）。

### 2.2 "无趋势漂移"为什么用线性回归

B3 的漂移 = **基底期收盘价对时间做最小二乘回归，回归线首尾落差 / 均价**。

早期版本用"后 5 日均值 / 前 5 日均值 - 1"，实测漏掉了**缓慢单向下台阶**的形态。例如 `688621.SH` 在 2026-04-27 ~ 06-29 的收盘序列：

```
57.92 58.33 58.56 57.68 57.11 58.02 57.50 60.44 58.71 57.07 56.82 56.18 57.37 56.76
56.50 56.76 56.25 57.30 56.83 55.91 55.27 54.00 52.50 51.97 54.00 52.67 50.51 47.96
51.14 50.02 48.07 52.26 52.65 51.80 51.38 52.40 51.28 52.66 52.76 53.32 50.58 55.03
```

这是从 58 一路滑到 51，根本不是横盘。但首尾 5 日均值只差 **-8.72%**（过关），分位数箱体振幅也只有 **14.56%**（过关）——因为只用了两端的点，中间 32 根 K 线的信息完全没进入判断。改成回归口径后该票漂移 **-15.46%**，被正确剔除。

这一条改动把 B 组通过数从 133 收到 84，剔除的 49 只全部是这类"伪横盘"。

## 3. 选股逻辑

五组条件，`BUY` 需 A+B+C+D+E 全过。

### 3.1 \[A\] 调整充分 —— A 杀已经发生

| 代号 | 含义 | 默认阈值 |
|---|---|---|
| A1 | 深度回撤 | `1 - base_low / pre_high >= 30%`，`pre_high` = 基底期开始前 250 日最高价 |
| A2 | 仍在低位 | `close <= pre_high × (1 - 25%)`，排除已经涨回去的 |

### 3.2 \[B\] 横盘充分 / 筹码干净 —— 基底期内

| 代号 | 含义 | 默认阈值 | 实测独立通过率 |
|---|---|---|---|
| B1 | 箱体收窄 | `(box_high - box_low) / box_low <= 22%`，箱体 = 收盘价 q90/q10（见 2.1） | 29% |
| B2 | 横盘连续 | 基底期自然日跨度 ≤ `base_window × 2.0`，且期间**无零成交**（排除长期停牌） | 100% |
| B3 | 无趋势漂移 | 回归线首尾落差/均价 `|drift| <= 10%`（见 2.2，真横盘而非缓慢下台阶） | 12% |
| B4 | **地量** | 基底期均量 / 下跌段均量 `<= 0.85`，抛压枯竭 | 50% |
| B5 | **成交价高度集中** | 基底期收盘价 `std / mean <= 0.09` | 51% |

> 实测通过率为 2026-07-27、A 组通过的 3617 只样本上各条**单独**的通过率。B3 是最强的筛子——这批深跌股里只有约 12% 在 5-6 月是真横盘，其余**仍在阴跌**（基底期漂移的 p10/p50/p90 分别是 -33%/-22%/-4%，全为负）。四条叠加后 A+B 剩 84 只。

### 3.3 \[C\] 量价关系 / 可买入 —— 近期段

| 代号 | 含义 | 默认阈值 | 实测独立通过率 |
|---|---|---|---|
| C1 | 刚站上 MA20 | `close > MA20`，且连续站上天数 ∈ \[2, 25\]（不是刚探头，也不是站上很久已经飞了） | 26% |
| C2 | MA20 转平走升 | `MA20 >= MA20[T-5]` | 71% |
| C3 | 贴近箱体上沿 | `close / box_high - 1 ∈ [-3%, +12%]` | 20% |
| C4 | **放量确认** | 近 10 日最大量 `>= 1.8 ×` 基底期均量，**且** 涨日均量 / 跌日均量 `>= 1.1`（量价同向） | 40% |
| C5 | 不追高 | `ret5 <= 15%` 且 `ret20 <= 35%` | 94% |
| C6 | 买点位置 | `close / MA20 - 1 <= 10%` | 97% |

> C4 的两条必须同时满足。只有"放量"没有"涨日量大于跌日量"，往往是出货而不是进货。

**C1 和 C3 是"可买入"档稀疏的根源，而且这是市场事实、不是阈值定得太严。** 实测 2026-07-27 的 35 只候选池里，连续站上 MA20 天数的中位数是 **0**（一半的票还在 MA20 之下），距箱顶的中位数是 **-5.9%**。把放量倍数从 1.8x 一路放松到 1.2x，"可买入"依然只有 1 只——因为 `C1+C2+C3+C5+C6`（完全不看放量）本身就只有 2 只。5-6 月筹码干净的票，到 7 月底绝大多数**还趴在箱子里没启动**。

### 3.4 \[D\] RPS 拐头

| 代号 | 含义 | 默认阈值 |
|---|---|---|
| D1 | 相对强度改善 | `RPS_120 - RPS_120[T-20] >= 10`（百分位点） |
| D2 | 强度地板（可关） | `RPS_120 >= 40`，仅用于排除持续阴跌的垃圾股；`use_rps_floor=False` / `--no-rps-floor` 可关闭 |

### 3.5 \[E\] 风控

| 代号 | 含义 | 默认阈值 |
|---|---|---|
| E1 | 流动性 | 近 20 日均额 `>= 8000 万`（对应背景 1 的流动性问题，这个门槛不宜放松） |
| E2 | 非次新 | K 线数 `>= 300` |
| E3 | 未停牌 | 最后一根 K 线必须是目标日，且当日 `vol > 0` |

### 3.6 分档

| 档位 | 条件 | 含义 |
|---|---|---|
| `可买入` BUY | A + B + C + D + E 全过 | 已放量站上 MA20 且贴近箱顶，买点成立 |
| `观察` WATCH | A + B + D + E 过，`box_pos >= 0` 且 `box_ext <= 12%`，并满足 C5/C6，但 C1/C2/C4 未全过 | 基底与强度都对，只是**还没放量启动**，仍在箱体内蓄势 |

**`box_pos` 是箱体内相对位置**：`(close - box_low) / (box_high - box_low)`。0 = 贴箱底，1 = 贴箱顶，>1 = 已站上箱顶。

观察档**不能**沿用 BUY 档的"距箱顶 -3% 以内"——那要求还在箱内蓄势的票贴着箱顶，自相矛盾。但换成"距箱顶 -10% 以内"这种绝对百分比同样是错的：对宽窄不同的箱体含义完全不一致。实例：`600211.SH` 箱底 36.39 / 箱顶 42.19（振幅 16%），收盘 37.98，距箱顶 -9.98% 能过关，可它实际只在**箱体 27% 的位置**，属于下半部。

所以观察档改用 `box_pos >= 0`，语义是**箱体结构没被跌破**——只要横盘结构完好、没追高，且 RPS 已在拐头，就值得挂进观察池；具体在箱内哪个高度不重要。真正的筛选力量在 A/B/D/E（5097 → 35），这里不需要再加一道位置筛。

`WATCH` 档的 C2 允许 1% 的走平容差（`ma20_flat_tol`）—— 横盘票的 MA20 本来就是平的，不给容差会把它们随机筛掉一半。

## 4. 实战使用（Python）

```bash
# 每日扫描（读通达信本地日线 + 现算 RPS）
py -3 scripts/screening/run_quiet_base.py --date 20260729

# 顺手把带 RPS 的日线缓存下来，之后调参免读盘
py -3 scripts/screening/run_quiet_base.py --save-cache output/cache_tdx_with_rps.parquet

# 用缓存反复调参（秒级）
py -3 scripts/screening/run_quiet_base.py --cache output/cache_tdx_with_rps.parquet --date 20260729

# 排除科创板 / 创业板 + 人工维护的 ST 清单
py -3 scripts/screening/run_quiet_base.py --exclude-boards 688,300 --exclude-codes output/st_list.csv
```

代码内调用：

```python
from rps_analyzer.quiet_base_screener import (
    screen_quiet_base, QuietBaseConfig, print_quiet_base_summary,
)

res = screen_quiet_base(
    df_daily,                                   # 含 RPS_120 历史序列的全市场日线
    target_date="20260729",
    config=QuietBaseConfig(vol_dry_max=0.60),   # 收紧地量要求
    exclude_prefixes=["688", "300"],
)
print_quiet_base_summary(res)
# res["SIGNAL"] ∈ {"可买入", "观察"}
```

> `rps_analyzer.rps_calculator.calculate_rps` 默认就是逐行生成的，直接可用。

### 4.1 输出列

| 列 | 含义 |
|---|---|
| `SIGNAL` | `可买入` / `观察` |
| `base_start` / `base_end` | 基底期起止日期（便于回看 K 线核对） |
| `box_low` / `box_high` | 箱体下沿 / 上沿（收盘价 q10 / q90） |
| `base_low_raw` / `base_high_raw` | 基底期真实最低 / 最高价（含影线） |
| `box_range_pct` | 箱体振幅% |
| `base_drift_pct` | 基底期回归漂移%（见 2.2） |
| `close_cv` | 基底期收盘价离散度（越小筹码越集中） |
| `vol_dry_x` | **地量比** = 基底均量 / 下跌段均量 |
| `drawdown_pct` | 前期高点 → 基底真实最低 的回撤% |
| `vs_pre_high_pct` | 今收距前期高点% |
| `ma20_streak` | 连续站上 MA20 天数 |
| `box_pos` | **箱体内相对位置**（0=箱底，1=箱顶，>1=已站上箱顶） |
| `box_ext_pct` | 今收距箱体上沿%（>0 已破箱，<0 仍在箱内） |
| `vol_expand_x` | 近 10 日最大量 / 基底均量 |
| `up_down_vol_ratio` | 涨日均量 / 跌日均量 |
| `rps_chg20` | `RPS_120` 近 20 日抬升的百分位点数 |
| `base_score` | 综合评分 0~100（排序用） |

`base_score` 权重：地量 25% + 箱体窄度 20% + RPS 抬升 25% + 量价配合 20% + 回撤深度 10%。

### 4.2 仓位与纪律（建议）

| 维度 | 可买入档 | 观察档 |
|---|---|---|
| 首仓 | 2~3% | 0（只加自选，不动仓） |
| 加仓 | 站稳箱顶 3 日不破 加至 5% | **转为"可买入"后**再建仓 |
| 止损 | 跌回箱体中位（`(box_high+box_low)/2`，即 `box_pos < 0.5`）或 −8% 固定 | — |
| 止盈 | 反弹至 `pre_high` 下方 30% 处减半，剩余跟 MA20 | — |
| 环境否决 | 背景 2 提示这轮科技下跌是全球同步的。若美股 / 韩股科技仍在破位下行，**整体降一半仓位**，本策略的低位股同样会被流动性拖累 | 同左 |

## 5. 通达信条件选股公式

> 用法：**功能 → 选股器 → 条件选股 → 其它类型 → 新建**，粘贴下列公式。
> `RPS120` 依赖扩展数据 `EXTDATA_USER(6)`（与 `tdx_rps_extension_zhutu.md` 一致，数值 /10 得 0~100）。
> 若未配置 RPS 扩展数据，把 `RPS拐头` / `RPS地板` 两行删掉即可（会多出一些形态对但强度未改善的票）。

```text
{======== 静默筑底 · 低位再启动 ========}
HC120:=EXTDATA_USER(6,0);
RPS120:=HC120/10;

GAP:=20;                                 {近期段长度}
BASEN:=42;                               {基底期长度}
DROPN:=250;                              {下跌段长度}

MA20:=MA(C,20);

{--- 三段式窗口: 箱体与前期高点都要排除最近 GAP 日 ---}
{ 箱体用收盘价极值(近似 Python 版的 q90/q10, 比 H/L 极值窄得多; 阈值相应放宽到 30%) }
箱顶:=REF(HHV(C,BASEN),GAP);
箱底:=REF(LLV(C,BASEN),GAP);
基低:=REF(LLV(L,BASEN),GAP);             {真实最低, 算回撤用}
前高:=REF(HHV(H,DROPN),GAP+BASEN);
基量:=REF(MA(V,BASEN),GAP);              {基底期均量}
跌量:=REF(MA(V,DROPN),GAP+BASEN);        {下跌段均量}
基均价:=REF(MA(C,BASEN),GAP);

{--- [A] 调整充分 ---}
深跌:=(前高-基低)/前高>=0.30;
低位:=C<=前高*0.75;
A档:=深跌 AND 低位;

{--- [B] 横盘充分 / 筹码干净 ---}
箱窄:=(箱顶-箱底)/箱底<=0.30;
{ 漂移用线性回归斜率: SLOPE 的 N 期回归线首尾落差 / 均价 (对应 Python 版 B3) }
漂移:=REF(SLOPE(C,BASEN),GAP)*(BASEN-1)/基均价;
无漂移:=ABS(漂移)<=0.10;
地量:=基量<=跌量*0.85;
B档:=箱窄 AND 无漂移 AND 地量;

{--- [C] 量价关系 / 可买入 ---}
上MA20:=C>MA20;
新鲜:=COUNT(C>MA20,25)>=2 AND COUNT(C>MA20,26)<=25;
均线升:=MA20>=REF(MA20,5);
距箱顶:=C/箱顶-1;
贴上沿:=距箱顶>=-0.03 AND 距箱顶<=0.12;
放量:=HHV(V,10)>=基量*1.8;
不追高:=C/REF(C,5)-1<=0.15 AND C/REF(C,20)-1<=0.35;
买点位:=C/MA20-1<=0.10;
C档:=上MA20 AND 新鲜 AND 均线升 AND 贴上沿 AND 放量 AND 不追高 AND 买点位;

{--- [D] RPS 拐头 ---}
RPS拐头:=RPS120-REF(RPS120,20)>=10;
RPS地板:=RPS120>=40;

{--- [E] 风控 ---}
流动性:=MA(AMOUNT,20)>=80000000;
非次新:=BARSCOUNT(C)>=300;

选股:=A档 AND B档 AND C档 AND RPS拐头 AND RPS地板 AND 流动性 AND 非次新;
选股;
```

### 5.1 只要"观察档"（箱内蓄势，提前埋伏）

观察档看的是箱体结构是否完好（`box_pos >= 0`），不要求贴箱顶。把 `C档` 与最后两行替换为：

```text
箱内位置:=(C-箱底)/(箱顶-箱底);
C档观察:=箱内位置>=0 AND 距箱顶<=0.12 AND 不追高 AND 买点位 AND MA20>=REF(MA20,5)*0.99;
选股:=A档 AND B档 AND C档观察 AND NOT(上MA20 AND 放量) AND RPS拐头 AND 流动性;
选股;
```

### 5.2 主图标记信号（看盘用，不选股）

```text
{同上定义 A档/B档/C档 后}
信号买入:=A档 AND B档 AND C档 AND RPS拐头 AND 流动性;
DRAWICON(信号买入,L*0.98,1);
DRAWLINE(1,箱顶,1,箱顶,0),COLORYELLOW;      {黄线: 箱体上沿}
DRAWLINE(1,箱底,1,箱底,0),COLORGREEN;       {绿线: 箱体下沿}
DRAWLINE(1,前高,1,前高,0),COLORRED;         {红线: 前期高点}
```

> **与 Python 版的差异**：
> - 箱体上下沿：通达信没有现成的分位数函数，改用**收盘价**的 `HHV/LLV`（而不是 `H/L` 的极值），阈值相应从 22% 放宽到 30%。选出的箱体会比 Python 版略宽。
> - "横盘连续（B2）"、"收盘价离散度（B5）"、"涨日量/跌日量（C4 后半条）"较难简洁表达，已省略。
>
> 综合下来通达信选出的票会比 Python 版**略多**。建议用通达信盯盘画线，用 Python 定选股清单。

## 7. 已知局限

1. **ST / 退市股未排除**。`rps_analyzer/tdx_reader.py` 的 `load_tdx_market` 不做名称过滤，`.day` 文件里也没有股票名称。"深跌 + 地量 + 横盘"恰恰是 ST 股的典型形态，**必须**自行维护排除清单并通过 `--exclude-codes` 传入，否则结果里会混入一批不可交易的票。
2. **无真实筹码分布数据**。`.day` 无换手率、无流通股本，"筹码干净"只能用地量 + 窄箱体 + 收盘价低离散度三者组合代理，不等于真实的筹码集中度。
3. **左侧策略，强依赖大盘环境**。低位股在流动性收缩期会被无差别拖累。背景 2 提到的美股 / 韩股科技同步性没有被量化进来（项目目前不接外部指数数据），需要人工作为环境否决项。
4. **未做行业分散**。同一被吸血板块的票会成簇出现，需配合人工行业分散纪律；`rps_analyzer/industry_rps.py` 可读通达信 `tdxhy.cfg` 做行业归属，但只有 T 编码没有中文名，暂未接入本策略。
5. **首轮前瞻验证结果为负，尚不足以支撑实盘。** 这是最重要的一条，详见下节。

## 8. 首轮前瞻验证结果（2026-07-29 实测）

```bash
py -3 scripts/validation/verify_quiet_base.py --cache output/tdx_stock_daily_with_rps.parquet \
    --dates 20260415,20260515,20260615 --windows 10,20
```

| 观察日 | 入选(买入/观察) | +20 日 可买入 | +20 日 观察 | +20 日 全市场基准 |
|---|---|---|---|---|
| 2026-04-15 | 5 / 9 | -4.70% | **+12.21%**（win 88.9%） | +5.01% |
| 2026-05-15 | 6 / 13 | -9.05% | -12.35% | -9.86% |
| 2026-06-15 | 5 / 19 | -12.23% | -14.18% | -7.84% |
| **三期汇总** | **16 / 41** | **-8.68%**（win 18.8%） | **-7.81%**（win 26.8%） | — |

**结论：目前跑输基准，不要直接实盘。** 需要注意几点：

1. **样本极小**：可买入档三期合计仅 16 只，统计上完全不显著。
2. **全是熊市样本**：三期基准的 +20 日收益是 +5.0% / -9.9% / -7.8%，5 月之后市场单边下跌。这正好实证了局限 3——低位股在流动性收缩期会被无差别拖累，本策略没有任何抗跌属性。
3. **唯一有效的一期是 4 月**：观察档 +12.21% vs 基准 +5.01%，超额 +7.2%、胜率 88.9%。那期基准是上涨的。
4. **可买入档反而比观察档还差**（-8.68% vs -7.81%）。合理的解释是：可买入档要求"贴近箱顶"，意味着已经从箱底涨了一段，在下跌市里回撤空间更大。但 16 个样本不足以定论。

**下一步该做什么**：把观察日扩到覆盖至少一轮完整牛熊（建议 2024-2025 逐月），再判断超额收益是否存在。在此之前请只把输出当**自选池候选**用，配合人工看图和大盘环境判断，不要机械执行。

> 本节数字未经调参优化——校准过程中只修正了两处**度量口径缺陷**（箱体极值→分位数、漂移首尾→回归，见 2.1 / 2.2），没有为了让回测好看去反复搜索阈值。
