# 简化日线趋势观察池

入口：`scripts/screening/run_simple_trend_pool.py`。仅识别当前趋势与量价状态；不生成可执行买卖结论，不与产业证据数据库互相写回，不改动旧启动策略。

## 两层而非一串否决条件

入池只要求收盘高于MA20，且MA20高于5根股票交易日线前的MA20。MA20高于MA60只作为“结构较强”分组，RPS50/120/250只作为诊断字段，量价阶段和成交额都不否决入池。另有数据资格要求：至少251根交易日线、最新日有有效成交，剔除当前ST或退市名称。

默认按代码排列，不给“最值得买”的分数。用阶段筛选或搜索缩小复核范围，并查看真实历史收盘、MA20/60与成交量。观察池、筛选后的条数、图表所选股票和导出范围分别标明。

## 透明的量价标记

所有参考高低点与当日量比分母均不包含今日；均线斜率按股票自己的交易日线计算。

| 标记 | 描述规则 |
|---|---|
| 转弱警示 | 收盘低于此前5根最低价，且当日量高于此前5根均量 |
| 突破扩展 | 收盘超过此前10根最高价；是否放量由量比单独呈现，不硬性否决 |
| 回踩观察 | 较昨日收盘下降，且当日量低于此前5根均量 |
| 缩量整理 | 最近5根均量与高低价宽度，均小于紧邻此前5根 |
| 趋势延续 | 入池但没有更优先的阶段标签 |

同时满足多个标签时，展示顺序为转弱警示、突破扩展、回踩观察、缩量整理、趋势延续；原始布尔标记仍随导出保留。阶段不改变入池资格。回踩观察仅意味着趋势内缩量回落，并未证明回踩某个冻结支点成功。突破参考为滚动10根日线高点，不宣称已精准识别真实平台。它们是描述假设，不是预测或最优参数。

## 本地运行

```powershell
py -3.12 run_simple_trend_pool.py --output output/simple_trend_pool_20260930
py -3.12 validate_simple_trend_pool.py output/simple_trend_pool_20260930
py -3.12 -m pytest tests/test_simple_trend.py -q
```

输出观察池、全部有效股票、排除清单、当前入池股票的最近80根日线、审核快照与审计信息。已有目录不覆盖。必须先通过通达信原文件和冻结快照哈希核对；更新原日K后，应重新构建快照，不能用旧缓存冒充最新数据。

通达信日线条件选股的趋势主体可表达为：

```text
M20:=MA(C,20);
趋势观察:C>M20 AND M20>REF(M20,5) AND BARSCOUNT(C)>=251;
```

上述仅是条件语法表达，未经过本机通达信编译；股票范围与ST排除仍需另行设置。复权方式也需与研究价格保持一致，不承诺两端结果完全一致。
