# 日线量价启动研究

本模块只输出历史研究与观察状态，不提供订单接口或可执行买卖结论。旧 RPS 模型保留为对照；新模型的准入和排序不读取 RPS，RPS 仅随观察记录展示。

## 固定研究假设

范围是已有上涨背景后的整理再启动，不是底部反转。默认以截至昨日的20根股票日线作为平台：前后各10根真实波幅均值和成交量均值分别比较，后半段不超过前半段的85%；平台深度不超过18%，后半段低点不低于前半段低点的98%。整理前存在至少15%的上涨，昨日价格在MA60之上且MA60不下降，昨日20日平均成交额至少1亿元。参数可在配置中调整，但本次固定对照不根据结果调参。

平台上沿为此前20根最高价，试错口袋为此前5根最低价。收盘突破上沿、成交量至少为此前20根均量的1.3倍、收盘位置至少处于当日振幅的65%，产生一个启动事件。同一事件未失效或过期前不重复产生事件，突破当天冻结上沿、口袋、突破成交量和质量分。

位置约束另作对照：收盘超过支点不多于4%、超过支点不多于0.8倍ATR，至冻结口袋的距离不多于8%。回踩及再转强事件判定使用突破时冻结ATR；受约束模型在次日实际模拟成交价再次核验时使用信号日前20根波幅的ATR。因此事件通过仍可能在成交模拟阶段被拒绝，两层条件均无未来数据。

质量分只反映波幅收缩、成交量收缩、低点抬升和口袋距离；权重预设，不是拟合分数。回踩模型要求突破至少两根日线后接近冻结支点且缩量，之后另一日收盘越过前日最高价、站回支点并增加成交量。回踩当日不能直接视为再转强。

## 对照设计

比较旧RPS启动、量价事件代码顺序、同事件质量排序、增加位置约束、独立缩量回踩再转强。新模型分别比较MA20退出、MA60退出和分阶段退出。

分阶段模拟中，初始阶段以冻结口袋失守、连续两根收盘低于冻结支点、超过20根股票日线未确认、7%收盘保护条件作为失效研究规则。连续至少5根收盘站在支点以上且MA20较5根股票日线前上升，转为趋势阶段，改观察MA60失守；7%保护仍保留。这些是历史模拟规则，不是当前标的操作指令。

信号在收盘形成，最早下一市场日开盘模拟成交；停牌、涨跌停代理、跳空和T+1约束显式记录。期末未完成持仓按收盘估值，不虚构平仓。使用固定十等份资金，不是等风险配置。

## 本地复现

在本文件所在目录运行：

```powershell
py -3.12 run_price_volume_launch.py --output output/price_volume_launch_20260930_v1
py -3.12 validate_daily_research.py output/price_volume_launch_20260930_v1
py -3.12 -m pytest tests/test_price_volume_launch.py tests/test_daily_research.py tests/test_trend_start.py -q
```

配置：`config/price_volume_launch.json`。程序核对冻结缓存和通达信源文件哈希；源文件变动时拒绝沿用旧快照。已有输出不覆盖。

可从指定日期全现金独立起算，保持原参数和旧结果不变：

```powershell
py -3.12 run_price_volume_launch.py --start-date 2024-09-24 --output output/price_volume_launch_from_20240924
py -3.12 validate_daily_research.py output/price_volume_launch_from_20240924
```

这不是截取原组合净值。期初无持仓，区间开始前的历史仅用于指标预热和事件状态维护；首次模拟成交晚于区间内的收盘信号，2024-09-24收盘产生的信号最早2024-09-25开盘模拟成交。指定区间结果不能证明跨行情有效，也不能与旧组合期间收益直接拼接。

本区间结果支持“表现依赖行情区间”这一观察：量价版本由此前长区间负收益转为正收益，但约24%的回撤仍高，尚不能证明捕捉主升具有稳定优势。质量排序与分阶段版本收益接近，后者资金敞口更高，不能据小幅收益差异判定更优。严格位置约束降低回撤，也压低信号数和资金利用率。等待回踩版本只有2笔完成交易，结论仍不足。

没有在本次比较中计算同期基准超额收益，不能把正收益称为跑赢市场。历史数据质量和股票池偏差仍见下文。审计漏斗统计是完整预热快照的事件数，不是该区间的成交数。

14组逐日账本均核验了2024-09-24期初全现金、2026-09-30终点；独立现金与净值重算覆盖6860个组合交易日，最大误差均小于2×10^-9元。39项相关离线测试通过，包括日期合法性和不继承区间外持仓；修改范围的Ruff与mypy通过。报告未完成浏览器视觉验收。

产物包括HTML报告、所有年份与模型的比较表、冻结事件链、当前观察状态、逐日账本、模拟交易和拒绝原因、配置与源代码哈希。独立验证器从导出账本重新核对现金、份额和净值，而不是直接信任汇总收益。

## 已知边界

本地数据缺完整历史ST和退市覆盖，存在幸存者偏差。不能处理的复权事件会整股排除，这也可能造成未来条件化的股票池偏差。成交量尚未做股本变动校正，涨跌停为代理，复权合成份额不等同真实整手交易、现金分红。年度分折是已经看过的历史数据，不是独立样本外检验。不能因此宣称可实盘盈利。

下一步研究优先检查失败突破的事件路径：突破后的扩展是否不足、平台内部是否存在放量下跌、是否与市场趋势共振。先定义能被证伪的量价差异，再做固定对照；不以增加RPS门槛或反复调参数代替检验。保留原始事件与拒绝记录，尚不把任何版本定为实盘方案。
