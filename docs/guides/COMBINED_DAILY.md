# 两套日线策略合并：刚启动 / 进行中

入口：`scripts/daily/run_combined_daily.py`。输出的是可复核的观察名单、日线观察方案和形态失效条件，不是自动交易或可执行买卖结论。

## 如何运行

在本文件所在目录打开 PowerShell，先生成当天全有效集合RPS：

```powershell
py -3.12 run_daily_rps.py --tdx-root C:/new_tdx
```

再把上一条命令打印的结果目录传给合并入口：

```powershell
py -3.12 run_combined_daily.py --source-run "output/上一条命令打印的结果目录名"
```

合并过程检查原始快照的日期、价格口径、全有效集合分母、排名、筛选结果以及全部有效股票的日K文件哈希。若通达信数据在此期间更新，明确阻断，要求重跑第一步；不混用更新前后数据。
依赖与原策略包一致：Python 3.11+、pandas、numpy、pydantic 2、pytdx。无需外部RPS文件、网络行情、分钟数据。

## 合并规则

两套规则承担不同任务，**不是取两套规则的交集，也不是先截取强股再排名**。
两池都沿用 `scripts/daily/run_daily_rps.py` 对全有效本地沪深集合计算的同日RPS；旧策略的EXDATA历史数值不参与本次合并。

### A：趋势刚启动（含趋势中的再启动）

复用 `rps_analyzer/right_confirmation_v2.py` 的 `LayeredConfig`、`evaluate`、`shape_series`：

- 当前RPS120≥90、RPS250≥85、两者之和>180。
- 当前长短趋势、近高位置、流动性、换手率、偏离度均满足原V2门槛；至少280根日K。
- 最近5根日K内出现原V2“波动收缩、量能收缩、窄幅整理之后放量突破”的事件。所有整理窗口截止事件前一天，突破参照此前20日最高价，突破日量比1.3—3、收盘位置≥0.65。
- 事件发生后每一根收盘都不低于冻结的突破位。先失守再收复不继续沿用已经失败的旧事件；若出现新的有效突破，按新事件判断。

这个定义只证明“近期发生量价突破，当前基础资格通过”，**不声称历史事件当天的全市场RPS和换手率也已通过**，也不声称处于整轮牛市行情底部。
仅有整理、当前趋势良好、或刚进入筛选名单，都不冒充“刚启动”。

### B：趋势进行中

完整保留 `scripts/daily/run_daily_rps.py` 的上一轮门槛：

- 收盘>MA20>MA60>MA120、MA60高于5根K线前。
- 距250根日K最高收盘≤25%、高于最低收盘≥30%。
- 近20日收盘最大回撤≤15%，下跌日均量低于上涨日均量。
- RPS120≥87且RPS250≥87。

从中剔除A池，确保两份名单没有重复。这表示当前结构符合门槛，不代表已经识别整轮趋势的起点。
偏离MA20过大的标的不被假称为“趋势已失效”，仍保留在B池并显著标注偏离风险。

## 每只标的的方案如何阅读

输出两个Markdown报告和两个CSV：

- `trend_starting.md` / `trend_starting.csv`：刚启动；若为零，明确给出空名单及筛选解释，不放宽门槛凑数。
- `trend_ongoing.md` / `trend_ongoing.csv`：进行中；逐只列出观察状态、关键价格、下一交易日核对与失效条件。
- `diagnostics.csv`：全部需要复核的候选，含两个策略通过情况、缺失项及未通过原因。
- `audit.json` / `errors.csv`：参数、数据/代码哈希、日期、分母、覆盖缺口与错误。

### 日线观察方案

- 刚启动关注冻结突破位与事件前5日整理低点；观察后续回落是否缩量、收盘是否保持突破位及动态MA20。
- 进行中以MA20为观察轴，观察带定义为MA20至其上方2%。需要回落触及区域、收盘保留在MA20上方、量能不高于此前20日均量，随后日线转强；不是“价格碰到均线就确认”。
- “本日日线转强”定义：此前5根日K出现上述缩量回踩，本日收盘高于前一日最高价且仍在MA20上方。
- 当前均线和观察带为报告日快照，之后必须随日线更新。特别提供下一交易日MA20穿越临界价：最近19根收盘的均值。它是求解下一日 `C=MA20` 的代数边界，**不是预测下一日MA20或挂单价格**。出现除权、停牌或未新增日K时不可机械沿用。

### 失效条件

- 刚启动：任一后续日收盘跌破冻结突破位，本轮突破形态失效；跌破事件整理低点，底部结构进一步失守。
- 趋势结构：连续2个交易日收盘低于各自当日MA20，或收盘低于动态MA60，视作本观察假设失效；不是对永久趋势结束的预测。
- 回调结构：收盘跌破报告中冻结的回调低点，该次回调结构失效。
- 单日跌破MA20先作为日线预警，与连续2日确认区分。RPS跌破门槛或缩量门槛不再通过，只说明筛选资格改变，不自动等于价格形态失效。

2%观察带、连续2日确认是本合并版显式研究参数，尚无样本外业绩证明，可在 `CombinedConfig` 中修改。参数不是已证实的最优交易规则。

## 数据与边界

- 本次沿用前一步的原始不复权价格，不与旧报告的前复权数值直接拼接。除权可能扭曲RS及均线；不能把名单视为已完成复权核验的实盘方案。
- 换手率使用本地 `base.dbf` 流通股本（万股换算为股）。检查记录日期之后的股本变化及送配股事件；无法验证时为缺，不把未知当作满足换手门槛。此缓存不是历史时点股本库。
- 文件解析错误直接阻断；已知的RPS目录覆盖缺口随报告展示。行业缺失，不编造行业统计。
- 不输出目标收益、下单指令或仓位；买卖仍需人工复核。失效线不是可保证的成交价。一般风险说明：[Investor.gov](https://www.investor.gov/introduction-investing/investing-basics/glossary/stop-order)，仅用于说明执行风险，不移植美国订单规则到A股。
- 仅以日线技术数据筛选，不含基本面核验、公告风险、交易费用、滑点或样本外回测。
