# 大跌—缩量横盘—放量突破—回踩：日线观察工作流

交付日期：2026-10-01。行情截止：2026-09-30。只使用本地通达信日K及其已核验缓存；没有实时行情、分钟信号、订单或可执行买卖结论。

## 为什么默认缩量回踩，而不是放量回踩

针对“没有分钟数据、无法盘中盯盘”的约束，默认研究顺序是：**大跌已完成 → 横盘量能收缩 → 放量突破 → 缩量回踩 → 后续日线收盘再转强**。每天收盘后核对一次即可确定观察状态，不以盘中触碰价格作为确认。

这是结合使用者时间约束作出的工作方式推断，**不是收益更高的证明，也不是发现了适合所有上班族的最优策略**。本次资料不足以直接比较两种模式在A股的风险调整后收益。

网络参考（2026-10-01查阅）：

- [Fidelity：成交量与走势](https://www.fidelity.com/viewpoints/active-investor/stock-volume)：整理期间量能下降、突破时量能增加是其介绍的形态特征；相对高量的下跌并不能直接当成正面承接。该文没有检验本项目参数。
- [Fidelity：形态识别与局限](https://www.fidelity.com/bin-public/060_www_fidelity_com/documents/learning-center/Idenitfying-Chart-Patterns.pdf)：第11页列出多次收盘、时间、幅度等确认方式；第16页提醒回踩不一定出现，等待回踩也可能影响表现。
- [Schwab：波段交易](https://www.schwab.com/learn/story/swing-trading-strategies)：跨日波段仍有隔夜风险，需要纪律和风险管理，不能理解成完全不需要关注市场。这是美股教育材料，不是A股成交规则。

因此保留“放量回踩守位”作为**独立对照**，不混入默认缩量名单；“放量”本身不能证明吸筹、洗盘或资金承接。

## 固定规则与事件顺序

阈值属于首版探索性设定，不是优化结果；没有为凑数量调整，也没有为思瑞浦单独放宽。

| 环节 | 计算规则 |
| --- | --- |
| 数据资格 | 缓存中的沪深A股，至少251根有效成交日K；截止日必须有成交日K；当前通达信名称不含ST或退市标识 |
| 大跌完成 | 平台之前最多80根中，按运行最高收盘计算最大回撤，至少25%；峰值先于谷值，谷值先于平台，谷值距平台起点不超过40根 |
| 横盘 | 平台10—30根，以突破前一日为终点，选择最长合格段；最高价/最低价−1不超过18%，首尾收盘变化绝对值不超过8% |
| 缩量 | 平台末5根均量/首5根均量≤0.75；平台日均成交额≥1亿元；平台下沿不得低于前述谷值日最低价的98% |
| 放量突破 | 收盘超过平台最高价；当日量≥平台末5根均量的1.3倍；收盘在当日低到高的振幅中位置≥60% |
| 冻结结构 | 突破当天冻结平台起止日、上沿、下沿、平台末5根均量和突破量；不随之后价格上移 |
| 回踩位置 | 必须晚于突破日；最低价≤上沿×1.03且不低于下沿，收盘位于上沿的−2%到+8%之间 |
| 默认缩量回踩 | 回踩位置合格，成交量≤突破日量的85%，且≤此前5根均量 |
| 放量回踩对照 | 回踩位置合格，量≥此前5根均量的1.2倍；收盘不低于上沿，且收盘位置≥当日振幅50% |
| 后续日线再转强 | 先有有效回踩，在另一个交易日，收盘超过前一日最高价且超过冻结上沿，成交量不低于前一日；不能在回踩当日同时确认 |
| 当前可复核 | 事件距今≤15根，最后回踩或再转强距今≤3根，当前收盘仍在冻结上沿−2%到+8%之间 |
| 失效/过期 | 收盘低于冻结下沿，或连续两根收盘低于上沿的98%，标记形态失效；事件超过15根标记过期 |

根数按该股票的有效成交日K计算，不是自然日。一次冻结事件允许再次回踩，但不能把每个上涨日重新拟合成一个新突破。

RPS仅保留为描述字段，**不参与准入、排序或强制过滤**；MA20/MA60只作为计算参考值，MA20在图上显示。不会用“均线向上”补入没有完成事件链的股票。

当前扫描从每只股票最后65根成交日K冷启动，寻找近期事件；大跌和平台仍使用其之前的实际历史。它不是全历史逐笔交易模拟。图上100根历史中，早于本次65根扫描窗口的状态显式标记“未在本次事件窗口评估”；冻结上下沿只从突破日期开始绘制。
