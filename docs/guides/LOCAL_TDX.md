# 本地通达信两日比较

在本目录执行：

```powershell
py -3.12 run_local_tdx_compare.py --tdx-root C:/new_tdx --previous 2026-09-23 --date 2026-09-24
```

依赖：Python 3.12、pandas、numpy、pytdx。执行完全离线，不需要同花顺数据库。

输出位于 `output/local_tdx_20260923_20260924/`。先检查每个沪深A股 `.day`
是否包含目标日期，覆盖不足80%时返回非零状态，只生成数据检查报告，不将缺数据当作零命中。

数据充分时，读取 `T0002/hq_cache/gbbq`，用本地每10股分红、送转及配股资料重建

会排除对应证券并记录原因。该检查不代表已与独立行情源或通达信客户端复权导出核对。

策略A和B分别复用原包的指标函数与日报筛选条件；完整列出候选，不截前30。
