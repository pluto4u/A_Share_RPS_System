# 本地日K → 全有效股票RPS → 右侧趋势观察

本入口为 `scripts/daily/run_daily_rps.py`，独立于此前 EXTDATA RPS、产业筛选和分钟指标。
全部计算离线，不下载行情，不改写通达信数据，不连接或写入产业证据数据库，不执行交易。
这是用户第一步所需的研究筛选；第二步等用户核对运行结果后再讨论。

## 本机运行

在本文件所在文件夹打开 PowerShell：

```powershell
py -3.12 run_daily_rps.py --tdx-root C:/new_tdx
```

默认读取本地上证指数日线中的最新交易日。指定历史日期：

```powershell
py -3.12 run_daily_rps.py --tdx-root C:/new_tdx --as-of 2026-09-24
```

依赖 Python 3.11+、pandas、numpy、pydantic 2。本机 Python 3.12 已具备这些依赖。
其他电脑可执行 `python -m pip install pandas numpy "pydantic>=2"`。
运行不需要手动导出 CSV、同花顺、外部 RPS 数据或分钟行情。

重新搜索其他安装位置：

```powershell
py -3.12 run_daily_rps.py --discover-only --scan-root D:/
```

扫描遇到拒绝访问会列出错误并返回非零退出码，不会声称已完整访问系统保护目录。

## 输出在哪里

每次输出至脚本目录下 `output/daily_rps_交易日期_运行时间/`，运行结束打印绝对路径。

- `selected.csv`：仅入选的观察标的，按 RPS250 降序。含用户要求的全部字段，额外带均线、前高前低、均量、日期、价格口径及分母。
- `all_valid.csv`：**筛选前**的全部有效股票及排名、每项趋势判断、未通过条件，可解释落选原因。
- `inventory.csv`：逐文件来源、哈希、状态、明确排除原因、数据日期。
- `errors.csv`：解析、名称或复权错误；有任一此类错误即停止，不发布残缺排名。
- `audit.json`：参数、数据日期、分母、排除计数、数据口径及限制。

CSV 为 UTF-8 BOM，可用 Excel 打开；缺失值显示“缺”，不补零。筛选确实为零时仍输出有表头的空 `selected.csv`，与数据错误阻断区分。
`--output` 可指定新目录；不会覆盖已有运行。

## 必须看清：不复权与前复权

默认 `--price-basis raw`，严格使用用户所给 `.day` 原始价格，**不是前复权**。
除权除息、送转、拆合股可能扭曲原始涨幅、均线及回撤；因此不复权筛选只是这一价格口径的计算结果，不能当成已校验的复权RS强度。

可选的严格前复权入口：

```powershell
py -3.12 run_daily_rps.py --tdx-root C:/new_tdx --price-basis qfq
```

前复权需要本地 `T0002/hq_cache/gbbq`、pytdx，以及工程已有的 `scripts/research/run_local_tdx_compare.py`。
复用已测的比例复权函数，最新价仍锚定原始现价；成交额、成交量保持原始单位。
遇到未支持的特殊除权类别会明确报错并阻断，**不会悄悄改为不复权、忽略事件或仅对部分股票复权**。
这两种模式各自独立运行和记录，不能混在同一分母中。当地复权资料完整性尚未逐只与通达信图表核对。

## 精确定义与参数

参数位于脚本顶部，RPS 阈值也可由 `--rps120-min`、`--rps250-min` 设置。

1. 股票范围：沪深 A 股常用代码前缀；排除指数、基金、B股、北交所等。先检查二进制记录完整性、日期、价格、成交额和成交量。
2. ST/退市风险：本地 `shs.tnf`、`szs.tnf` 名称中的 ST/退标记。不猜名称；仍可能符合有效性要求而名称缺失时阻断。
3. 长期无交易：距离目标日至少20个本地指数交易日没有成交记录。短期停牌或未更新导致缺目标日记录也单列排除，绝不拿旧报价冒充目标日现价。
4. 上市/历史门槛：至少251根有效成交日K。因为250日涨幅需要 `C[t] / C[t-250] - 1`，250根K线只提供249个间隔。历史不足可能是新股，也可能下载不全；清单不擅自判定原因。
5. RPS：在上述全部有效股票组成的同一集合中，分别计算50/120/250个有效日K间隔涨幅。`RPS = 升序平均名次 / N × 100`，并列取平均名次。**所有趋势、回撤和RPS阈值均在排名后使用**。停牌造成个股有效K线不连续时，区间是个股交易K线而非统一自然日；这一版不补造停牌日成交量。
6. 均线：收盘严格大于 MA20，MA20 严格大于 MA60，MA60 严格大于 MA120；MA60 今值严格大于5根K线前。
7. 52周：操作定义为最近250根有效日K；高低点都取收盘价。距高点为 `(1-C/最高收盘)×100`；距低点为 `(C/最低收盘-1)×100`。
8. 回撤：最近20根日K中的**收盘到收盘**最大回撤，先峰后谷，计算 `max(1-C/此前累计最高C)×100`。不是简单的20日最高减最低，也不是盘中高低价最大回撤。
9. 缩量回调：近20根K线中，收盘低于前收盘的日子视作回调日、高于前收盘视作上涨日，平盘不计。比较两组原始日均成交量。此为明确可复现的代理指标，**不是完整波段分段识别**。任一组不存在则为缺，缩量条件不通过。
10. 口袋低点：上述近20日回调日中的最低价；无回调日为缺。它只是本任务的回调低点字段，不等同于其他交易体系的口袋支点。
11. 跌破 MA20 距今：最近一次 `C<MA20 且前收盘>=前MA20` 的向下穿越距当前的个股交易K线数。不是最后一个站在线下的日子；加载历史中找不到交叉则为缺，不假定从未跌破。

## 覆盖边界与审计

- 分母是本地目录中通过有效性校验的全部沪深股票，不是观察池或先按强度挑出的样本。
- 名称缓存有、日K文件没有的代码会在控制台和审计中列出；不能根据名称猜上市日期，也不能宣称已证明交易所全市场下载完整。
- 若某股票在日K和名称缓存都缺失，仅凭这两个本地来源无法发现。要证明交易所级完整覆盖，仍需独立证券主表；本版不会伪造完整性证明。
- TNF 是当前名称快照，非历史 ST 状态库；历史日期运行不应被视为无幸存者偏差的回测。
- 日K本身不含行业。本版行业一律为“缺”，不能据此编出行业分布前三。
- 当日收盘前运行可能读到未完成日K；脚本不能通过文件日期证明当日已完成下载。请盘后更新完整日线再运行。
- 参数符合技术形态不等于已验证收益，更不保证后续主升；需独立样本外回测、交易成本与风险评估。
