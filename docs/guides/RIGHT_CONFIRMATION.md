# 量价与股价强度：右侧确认V1

目标是从强势股中区分趋势观察、缩量整理、放量突破确认和回踩再确认，输出可核对的
候选及条件，不预测“必成牛股”，不生成交易指令。此版本独立于旧的思瑞浦反弹A/B策略。

## 使用

通达信：`config/right_confirmation_v1.tdx.txt` 是新增条件选股公式正文。
复制到新的条件选股公式，使用日线及前复权口径，确认扩展数据6/7更新后执行。
原式留在 `config/user_rps_reference.tdx.txt`，两者分开保存。
未在本机通达信公式编辑器中实测编译；Python结果不能冒充客户端对账通过。

本地：在策略目录执行：

```powershell
py -3.12 run_right_confirmation.py --tdx-root C:/new_tdx --date 2026-09-24
```

依赖 pandas、numpy、pytdx、pydantic。结果在 `output/right_confirmation_20260924/`：
`report.html`、`all_evaluated.csv`、`baseline.csv`、`confirmed.csv`、`audit.json`。
没有确认信号时CSV保留表头，报告显示0，不用其他观察股补足名单。

展示更新：`report.html`现仅展示观察池，含趋势观察、缩量整理观察、放量突破确认和
回踩再确认；失败、数据待核验及偏离过大不显示。`watchlist.csv`是精简观察清单。
09-24观察池19只；每只列出收盘价、MA20、此前20日最高价和此前10日最低价及观察步骤。
后两项排除当日，均为截至目标日的价格结构参考，不是买入/卖出价。
依据AGENTS.md第2.7条，本轮没有实现用户所要求的可执行价格与下单指令。

## 原式需要明确的口径

| 项目 | 实际生效代码 |
|---|---|
| RPS120+RPS250 | 严格大于180，不是注释中的185 |
| 站上MA250/MA200 | 各30天至少20天，不是25天 |
| 站上MA20 | 10天至少7天，或满足4日短线组合 |
| 站上MA5 | 10天至少6天，不是1天 |
| 接近高点 | 120日最高收盘价，不是一年最高价 |
| 堆量 | 定义了但没有接入最终SXHCG；原式复现不会偷偷加上 |
| 换手率 | 必须有流通股本；缺失不默认通过 |
| 当前创20日新高 | COUNT(X,0)累计全部有效历史，不是零天 |

COUNT的零周期定义见[通达信官方函数列表](https://help.tdx.com.cn/gspt/docs/markdown/redword/functionlist.html)。
Python按完整本地历史计算原式零周期；修正版在高点距今为0时只检查当天回撤，
其余时段保留原式动态窗口。这不是通用的“20日最大回撤”，不能如此命名。
HHVBARS同值高点采用最近一次位置，需要在客户端进一步逐值复核。

## 从图形到可检验条件

截图可见拉升后的横向整理、整理期量能回落、之后再次抬升及较高RPS；截图没有清晰日期轴，
不能确定每根K线对应日期，也不能把后续已发生上涨当作当时可知信息。

V1保留零周期修正后的原式基础池，再使用以下研究阈值：

1. 强度：RPS120≥90、RPS250≥85，同时保留原式两者之和>180。
2. 趋势：C>MA20>MA60，MA20和MA60分别高于5天前；C/近120日最高收盘≥0.90。
3. 偏离：距MA20不超过12%。不把已经大幅偏离均线的延续上涨标成新的启动确认。
4. 放量突破：收盘超过此前20日最高价；当日量/此前20日均量介于1.3和3；
   收盘位于当日振幅上方65%；此前10日振幅≤15%；此前5日均量/此前20日均量≤0.9。
5. 回踩再确认：此前2—10日出现过上述突破形态；低点触及MA20上方3%范围且收盘站回MA20；
   收盘超过此前5日最高价；整理缩量比≤0.9；当天量比≥1.2，收盘位置≥60%。
   此处“此前突破”指量价形态，不声称它在当时已通过全部RPS及股本条件。

所有“此前”价格和量能参考都排除当根K线；不使用未来函数。
上述阈值是初始假设，不是从已知上涨后的截图拟合得到的最优参数。
该组合可能较严格，不能为了凑出股票而按当天结果不断放松。

## 数据边界与验证

- 扩展数据解析对29字节索引、12字节日期值记录进行全文件长度核对；检查代码重复、
  日期严格递增及RPS范围。仅取指定日期，缺值不前填。不重新改变用户RPS排名范围。
- 价格为本地日线+gbbq重建前复权；没有独立行情源复权对账。
- 换手率采用base.dbf中的LTAG（万股转股）与.day成交量（股）。只有缓存记录日期不晚于
  目标日且之后未发现已知股本变化时使用；否则标缺失。当前缓存不是历史时点档案，
  无法保证与客户端CAPITAL或历史真实流通股本完全一致。基准48只是本地复现，非客户端认证结果。
- 证券名称和ST标识也是当前快照。与通达信结果比对时还须统一证券池和历史长度。
- 按数据验证技能检查了严格阈值、缺失值、动态回撤、零周期、同值高点、RPS日期、
  正向确认路径及原RPS内存优化等价性。测试完全离线。
- 右侧确认及本地对比共18项测试通过，含参考价窗口和观察池过滤验证；
  修改的生产代码ruff和隔离旧模块依赖的mypy检查通过。上层工程20项测试通过。
- HTML静态产物已生成；自动浏览器检查工具启动失败，未完成渲染和交互验收。
- 全工程ruff/mypy仍有原打包资料的已有问题；当前目录没有Git仓库，无法开PR。
