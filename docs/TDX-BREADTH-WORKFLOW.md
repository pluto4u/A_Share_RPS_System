# 本地通达信 → 市场宽度 → 小红书图片

## 使用

先在通达信中补齐沪、深、北市场的盘后日线数据，再运行：

```powershell
python tools/workspace.py breadth --tdx-root C:/new_tdx
# 指定历史交易日
python tools/workspace.py breadth --tdx-root C:/new_tdx --as-of 2023-08-04
# 独立入口，可通过TDX_ROOT设置默认源目录
python -m workflows.tdx_breadth --tdx-root C:/new_tdx
```

默认数据源为用户确认的 `C:/new_tdx`，两个入口共用 `project_paths.TDX_ROOT`，均支持环境变量覆盖。
源码入口 `workflows/tdx_breadth.py`。无需运行面板、HTTP桥接或在线行情API。
`--tdx-root` 支持通达信根目录或 `vipdoc` 目录。中文字体默认读取微软雅黑，可用
`A_SHARE_CJK_FONT` 指向其他中文字体。

## 输出

每次创建新的运行ID，路径为 `outputs/workflows/tdx_breadth/<数据日期>/<运行ID>/`：

- `01_cover.png`：宽度封面、有效交易样本、涨跌家数、覆盖率。
- `02_ma_breadth.png`：站上MA5/MA20/MA60的比例和各自分母。
- `03_breadth_trend.png`：最近60个本地观测日的MA20宽度。
- `xiaohongshu_caption.txt`：可编辑的配图文案。
- `summary.json`：日期、口径、数据新鲜度与当日统计。
- `breadth_history.csv`、`constituents.csv`：历史统计及当日样本，便于复核。
- `source_manifest.json`、`failures.json`：源文件SHA256、实际日期和解析错误。
- `manifest.json`：生成产物哈希，用于版本追溯。

图片为1080×1440、3:4、PNG，已经实际渲染检查。工作流止于生成文件，上传时选择这些图片即可。

## 计算口径

按A股代码前缀识别沪深北股票，排除ETF、指数、债券等文件；并不等价于官方当日上市全集。
ST未剔除；当天缺记录或成交量为0不进入当日交易样本；不足N根记录的股票不进入MAN分母。
MA包括当天收盘，严格使用 `close > SMA(N)`；涨跌与前一条记录收盘比较；平盘单列。
没有把涨跌停、次日收益或仓位指令混入宽度判断。

默认报告日期取解析成功股票“最新日期”的众数；孤立更新的股票不会把整批数据伪装成最新。
指定 `--as-of` 时只用该日及之前数据；如果当天无成交样本则直接报错。
历史曲线按当天实际可观测股票计算，未做退市/存活偏差修正。

数据为通达信原始未复权日线，除权会影响涨跌与均线，不作为精准收益或涨跌停统计。
覆盖率是“当天有效交易样本 / 成功解析文件数”，不代表相对官方上市全集的覆盖率。
