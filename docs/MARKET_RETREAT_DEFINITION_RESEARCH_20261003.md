# A股“退潮／退潮期”定义的一手来源研究

研究日期：2026-10-03。适用背景：日线中期波段、上班族；用户给定退潮仓位最多20%、熊市目标不亏。本文是概念研究与待确认提案，不是当前市场诊断、交易指令或收益保证。

## 一、结论

1. **在本次检索范围未找到**中国证监会、上交所或深交所对交易语境“退潮／退潮期”的官方统一定义。公开站点关键词检索不完整，不能据此证明定义不存在，也不能证明券商之间没有其他定义。
2. 找到可引用的券商原始用法，但不是统一判定标准：太平洋证券在同一份报告中把普跌等表现描述为情绪退潮，同时认为中长期上涨趋势尚未打破。这是分析师观点，不是对市场状态的独立事实认证。[R1，2025-09-03，PDF第1页](https://pdf.dfcfw.com/pdf/H3_AP202509041738708707_1.pdf)
3. 短线情绪降温、中期风险收缩、熊市不应直接画等号。原始论文把主要市场状态与状态内部的调整／反弹分开处理；本文据此作概念区分，并不把论文模型等同于A股“退潮”。[R2，2002-10-08首发，§2](https://onlinelibrary.wiley.com/doi/10.1002/jae.664)、[R3，2012-07，PDF第1—2页](https://www-2.rotman.utoronto.ca/facbios/file/MMS-JBES-2012.pdf)
4. 熊市及趋势收缩不是A股专属概念；“情绪退潮”这个中文表达也被用于铜铝期货研究。不过，A股短线连板语境的具体阶段命名，不能据此宣称已成为跨市场统一标准。[R2，§1—2](https://onlinelibrary.wiley.com/doi/10.1002/jae.664)、[R4，2024-06-03，PDF第1页](https://www.cindaqh.com/upload/20240603/%E4%BF%A1%E8%BE%BE%E6%9C%9F%E8%B4%A7%E9%93%9C%E9%93%9D%E6%97%A9%E6%8A%A520240603.pdf)
5. 对本项目，更合适的候选含义是“日线可观测的参与广度、强势结构和量价延续性共同收缩”，而非某只龙头一天走弱即确认全市场退潮。这是本文待用户确认的操作性定义，尚无参数化规则或验证结果。20%是用户给定的仓位上限约束，不是退潮判定阈值；“熊市不亏”是目标，不是本文能够证明的结果。

### 仅日K能够与不能够说明什么

- **广度**：具备观察范围内各股票的日线数据时，可以观察上涨／下跌参与是否集中或扩散，以及个股间的走势分化；只有一条指数日K不能得出全市场广度。观察范围、缺失数据、停牌及上市状态必须清楚，否则应保留未知。
- **强势股结构**：在已有、事前确定的强势股集合上，可以观察收盘走势是否保持、走弱是否成片发生，以及原强势群体与其他股票是否分化。本文不新建强势股筛选周期或标准。没有事前集合时，不能事后挑选幸存强股充当证据。
- **量价持续性**：带成交量／成交额的日K可以比较价格推进与成交活动的共同变化、反弹是否延续、下行是否扩散；缩量本身不等于撤资，放量本身不等于机构进入。若“仅日K”实际只有开高低收，量的判断应为未知，不能补造。
- **盘中信息边界**：日K不能还原完整的触板、开板、回封顺序、封单变化或盘中承接。结合有效的当日涨跌停价及交易规则，至多核对日末是否处于涨跌停价，不能因此声称观测到完整短线情绪链条。
- **资金身份边界**：开高低收与日成交总量不含账户身份，不能唯一识别机构、游资、散户或“主力”。不同账户交易可以形成相同日K，故成交形态不能证明谁流入、谁撤退。这是数据可识别性推论，不是任何研报已证实的资金流结论。

对上班族，候选口径以收盘后的可复核信息为准，不要求盘中盯盘，也不把尚未完成的日K当成已确认状态。短线热点降温与市场中期收缩宜在人工复核中分别说明；本文不新增数据库状态枚举。

用户给定的退潮仓位上限最多20%应与状态定义分开记录；未明确其分母、资产范围、估值时点及熊市目标的评价区间前，不自行补充。仓位上限不是亏损上限，非零风险暴露不能推出不亏；本文没有验证任何配置的保本能力，不给当前股票的买卖建议。
