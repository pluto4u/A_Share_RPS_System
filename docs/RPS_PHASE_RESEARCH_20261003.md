# RPS阶段轨迹研究：不新增交易门槛

用户授权探索退出定义；原冻结版本仍不变。本轮先做RPS解释性研究，
不同时修改入场、退出或排序，不搜索新参数，不读取2022年后结果进行挑选。

## 固定输入与输出

- 面板、RPS：已有output/trend_start_cache_20260930；只把2021-12-31及以前前缀交给消费者。
- 冻结原A参数1276，60日下跌、40日横盘等均从freeze.json读取，禁止新选参。
- A研究699个既有可执行候选及其中实际组合进入事件；B只研究既有组合进入事件，非B全候选。
- RPS50/120/250直接读取全市场缓存。无样本内重排名，无补值，缺数据写“缺”。
- A横盘参考区间为放量前固定40根股票交易K线；放量日、回踩确认日均取原记录。
- B参考区间为原确认前固定3根股票交易K线，无放量字段，不伪造放量日。
- 输出阶段端点RPS、阶段RPS变化（百分位点），不把变化误称为涨幅。
- 仅按“上升/持平或下降/缺失”描述既有事件；0是方向边界，不是新优化门槛。
- 三个预先记录的观察：RPS50横盘变化、RPS50放量到回踩变化、RPS120放量到回踩变化。
- 原引擎净单笔结果用于观察分组；不能称为过滤后新组合收益或账户年化。
- 95%区间沿用原月度区块2000次、种子7；未做多重比较调整，只作探索性描述。
- 验证输入指纹、RPS120信号快照、股历索引、原事件价格及净收益不变；单测必须包含未来数据扰动。
- 不生成当前股票的可执行买卖结论，不写产业数据库，不连接交易接口。

## 下一轮仅为假设

RPS50可能用于短期恢复，RPS120用于中期强度维持，RPS250用于长期背景。
横盘中RPS提升可能源于其他股票更弱或历史比较基点变化，不一定是本股吸筹。
RPS强也不能覆盖结构破坏；RPS走弱也不能独自断言退出有效。
有价格和量的结构条件后再独立检验RPS的增量价值；不能把排序相关性当作因果作用。
若要研究先拉升后深整理的二次启动，须另立形态假设，不能冒充原四段式版本。
