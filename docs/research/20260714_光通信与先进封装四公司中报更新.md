# 光通信与先进封装四公司 2026H1 更新

更新日期：2026-07-15（纳入0714大V日报复核）  
覆盖：长飞光纤、东山精密、通富微电、长电科技  
用途：产业链研究与预期跟踪，不构成投资建议

## 一、结论先行

四家公司中报预告均验证了 AI 基础设施景气，但利润性质并不相同：

1. **长飞光纤**：核心利润加速最强，新型光纤光缆的供需与产品结构逻辑被直接验证；但股价和估值已经给出很高预期。
2. **东山精密**：索尔思整合、新产能和新客户开始兑现，维持 Q2 利润水平即可接近卖方全年一致预期；光芯片自产与客户认证是持续性关键。
3. **通富微电**：主业显著加速，但归母利润被投资收益明显放大。AMD 海外 CoWoS-L 1万片/月属于高弹性、低置信度期权，不能计入基础估值。
4. **长电科技**：增速不及长飞和通富，但扣非与归母最接近，利润质量最好；Q2 已验证利用率、产品结构和降本改善。

## 三、逐家公司更新

### 1. 长飞光纤：业绩最强，估值约束也最强

**中报变化**

- H1归母24–30亿元、扣非20–26亿元；Q2扣非环比约+234%–364%。
- 公司解释指向算力数据中心建设、新型光纤光缆需求、核心客户拓展、产品结构和盈利能力改善，不是单纯投资收益。
- 2025年公司海外收入60.92亿元、占比42.74%，光互联组件收入31.44亿元、同比增长48.6%，为本轮业绩提供了前置基础。

**卖方校验**

- 国泰海通在2026年4月报告中给出2026–2028年归母净利润89.39/109.45/126.62亿元，核心逻辑是光纤涨价、海外高毛利订单与光互联组件放量。
- H1中枢27亿元后，要完成89.39亿元全年预测，H2仍需约62.4亿元，较Q2中枢年化还要继续明显提速。高位预测尚未被完全验证。
- 市场已提前定价：7月14日基于预告的TTM市盈率约94–114倍，研究重点应从“是否增长”转向“高利润能持续几个季度”。

**瓶颈判断**

- 瓶颈所有者置信度：高。
- 核心约束：新型光纤工艺、海外客户认证、有效产能和供需结构。
- 证伪：Q3新型光纤价格/出货回落、海外高毛利订单不持续、竞争扩产导致供需逆转。

卖方参考：[国泰海通年报点评](https://stock.finance.sina.com.cn/stock/go.php/vReport_Show/kind/lastest/rptid/828537838792/index.phtml)、[2025年报](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0327/2026032703338_c.pdf)。

### 2. 东山精密：中报基本验证卖方一致预期

**中报变化**

- H1归母29–30亿元、扣非24–25亿元；Q2归母中枢18.4亿元、扣非中枢13.9亿元。
- 光模块业务整合、新增产能爬坡和新客户导入符合预期；传统消费电子与汽车业务提供基本盘。
- H1归母与扣非相差约4–5亿元，数据中心相关产业投资对利润有增厚，后续仍需单独观察索尔思经营利润。

**卖方校验**

- 7月9日前卖方2026年归母净利润一致预期约67.18亿元，预测范围32.88–80.22亿元。
- 若H2两个季度维持Q2归母中枢，全年约66.3亿元，几乎贴合一致预期。
- 80亿元以上高位预测需要H2约50.5亿元，单季平均约25.3亿元，较Q2中枢仍需提升约38%。

**瓶颈判断**

- 瓶颈所有者置信度：中高。
- 真正卡位不是光模块组装，而是光芯片自产、1.6T/3.2T产品能力、客户认证和良率。
- 证伪：新客户认证推迟、光芯片自产率不及预期、并购整合或汇率侵蚀利润、高端模块价格竞争。

卖方参考：[机构盈利预测明细](https://emweb.eastmoney.com/PC_HSF10/ProfitForecast/Index?code=SZ002384&type=web)、[招商证券公司点评](https://stock.finance.sina.com.cn/stock/go.php/vReport_Show/kind/search/rptid/830277968275/index.phtml)。

### 3. 通富微电：主业强，但必须剥离投资收益

**中报变化**

- H1归母16–18亿元，已经超过预告前卖方2026全年一致预期15.53亿元。
- H1扣非只有7–8亿元，归母与扣非差额约8–11亿元；公司明确表示供应链和上下游产业投资收益增厚利润。
- 扣非口径并不弱：Q2扣非约5.28–6.28亿元，较Q1的1.72亿元增长约208%–266%。
- 若H2扣非维持Q2中枢，2026全年扣非约19亿元，接近转发材料所称15–20亿元利润区间的上沿。

**对转发卖方材料的审计**

已被验证：

- AMD合作关系、CPU/GPU封测受益方向成立。
- AI、存储景气、国产化、利用率和中高端产品增长已经反映在扣非利润中。

尚未验证：

- “AMD让通富海外建设1万片/月CoWoS-L产能”。
- 2027年AMD 53万片CoWoS需求及各客户精确分布。
- 单片8万元、净利率30%的经济性。
- 海内外各1万片/月的最终资本开支、良率、客户认证和稳定交付时间。

量纲校验：1万片/月 × 8万元/片 × 12月 = 96亿元收入；按30%净利率对应28.8亿元净利润，30倍PE约864亿元市值增量。数学接近材料所称“1000亿元”，但30%净利率显著高于通富当前整体净利率，且1万片/月相当于材料所称AMD 2027年总需求的约22.6%，属于需要强证据支持的大项目。

**瓶颈判断**

- 现有OSAT业务卡位置信度：中高。
- CoWoS-L瓶颈所有权置信度：低，当前只按期权处理。
- 升级路径：公司/AMD正式公告 → 厂址和资本开支 → 设备进场 → 工艺和良率 → 客户认证 → 稳定交付。
- 任一前置环节缺失，都不能把CoWoS-L利润计入基础预测。

卖方参考：[通富一致预期](https://basic.10jqka.com.cn/144/002156/worth.html)、[国信证券年报点评](https://pdf.dfcfw.com/pdf/H3_AP202604211821376883_1.pdf?1776785548000.pdf=)、[公司注册稿中的AMD业务风险](https://www.cfi.net.cn/p20260703002012.html)。

### 4. 长电科技：利润质量最好，全年一致预期可跟踪

**中报变化**

- H1归母7.7–9.5亿元、扣非7.4–9.1亿元，扣非/归母中枢约95.9%。
- Q2归母4.80–6.60亿元、扣非4.75–6.45亿元，核心利润环比加速。
- 公司解释集中于AI基础设施需求、订单增长、利用率提升、高附加值产品和降本增效，非经常性因素较小。

**卖方校验**

- 预告前16家机构2026年净利润一致预期约20.26亿元；开源证券预测18.82亿元。
- 按H1中枢8.6亿元、H2维持Q2中枢5.7亿元/季，全年约20亿元，与一致预期基本一致。
- 因此本次中报更多是“验证”，不是大幅上修逻辑；后续增量来自先进封装产能和产品结构继续提升。

**瓶颈判断**

- 瓶颈所有者置信度：中高，平台广度和量产能力优于单一客户弹性。
- 78亿元高端先进封测工厂一期计划2028H2完成，短期不能按满产贡献估值。
- 证伪：成熟业务转弱、原材料涨价无法转嫁、新厂爬坡和客户认证不及预期、资本开支回报下降。

卖方参考：[长电一致预期](https://basic.10jqka.com.cn/144/600584/worth.html)、[开源证券年报点评](https://stock.finance.sina.com.cn/stock/go.php/vReport_Show/kind/lastest/rptid/829477755478/index.phtml)。
