# 整合右侧趋势与月线反转：底部位置 + 安静右侧

日期：2026-10-25　数据截至 2026-10-23（通达信日线，前复权，沪深 A 股）。信号月 2018-01～2026-09，每月合格股票中位数 2,552 只。
规则在运行前登记（`PREREG.md`），运行后未调参。2018–2026 的数据此前已被三项研究看过，结果只是描述，不是样本外证据。不构成投资建议。

## 结论（先说人话）

1. **主假设不成立。** “月线底部 + 日线右侧 + 安静”（H1）的 3 个月超额：2018–2021 年 +1.76%，2022–2024.01 年 −0.59%，2024.02 起 −2.25%。按预先定的标准（三个时期都为正，且至少两个时期好于去掉月线位置的版本）判定为**不支持**，归档。
2. **月线位置没有增量。** 去掉月线位置、只要“右侧 + 安静”（C2），三个时期反而比 H1 好：+1.65% / +1.36% / −0.82%。但近期仍是负数，整体 t 只有 1.1，不显著。
3. **唯一在三个时期都站得住的是“排雷”。** 剔除热股（20 日涨幅前 10%，或近 20 日成交额是近 120 日的 2 倍以上）后，剩下的股票 3 个月超额 +0.21% / +0.33% / +0.21%（全期 t = 3.0）；被剔除的热股是 −0.66% / −1.85% / −0.91%（t = −2.6）。这与右侧趋势、月线反转 v1、趋势延续三项研究的结论一致：**A 股的问题不在选什么，而在什么时候进场——热的时候进就亏。**
4. 幅度很小。排雷每 3 个月只多 0.2 个百分点左右，扣除成本后未必还剩，它是一个“少犯错”的过滤器，不是赚钱的选股策略。

完整的 1 个月 / 3 个月结果见 `results/summary.csv`，逐年数据见 `results/yearly_3m.csv`。

- “底部 + 热启动”（C1）三个时期都为负，再次复现了月线反转 v1 和放量因子的结论。
- 同一组从“热”换成“安静”（C1 → H1），设计期的差距约 3 个百分点，但近期只剩 −0.4 个百分点，安静本身也救不了 2024 年以后的底部股。
- 所有组的**事件中位数超额都是负的**（合格池自己也是 −3.9%），均值为正靠少数大涨股拉动。也就是说，即使是排雷后的组合，单只股票“大概率跑输、少数大赚”的分布不变，必须分散持有才拿得到均值。

## 对选股思路的含义

| 能做的 | 不该做的 |
|---|---|
| 把“热股排除”当成任何选股流程的**最后一道过滤**：20 日涨幅前 10%、或成交额突然放大 2 倍以上的，先不买，等它冷下来 | 用放量、大阳线、突破当买点（三项研究、三个时期都为负） |
| 右侧趋势公式、月线反转留作**扫描器**，缩小人工看的范围 | 把月线底部当成超额来源（单看中性，2024 年后为负） |
| 分散持有（几十只级别），因为正的均值来自少数股票 | 集中 5 只押底部反转（v1 诊断里集中持仓的结果更差） |

## 局限

- 只含本地现存股票（无退市股），按当前名称剔除 ST；底部类结论偏乐观。
- 超额是同流动性组的均值差，不是可交易净值；没有成本、涨跌停和停牌约束；每月事件互相重叠。
- 2024.02 起的 3 个月样本只有 29 个信号月；H1 在 2018 年只有 2 个事件，逐年数字以事件数为准。
- 本研究计算的组与月线反转 v2 的候选集不同（v2 用 MA5 拐头、底部月龄、单月涨幅区间），没有计算 v2 候选的收益；但 C3、H1 与 v2 思路相近，v2 将来的历史检验应把本研究记为“已看过的相关结果”。
