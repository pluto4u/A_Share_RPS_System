{ 右侧趋势发现器：放量因子附加块（通达信公式，可粘贴到 ZZ1234 的 YJ 之前）
  先看 REPORT.md：这些因子在 2018–2026 的同流动性对照里，没有一个证明比不加更好。
  这里只是把研究里测过的因子写成可直接粘贴的形式，方便你自己在通达信里目测/回看。
  使用方法：把 VFx 里选一行，把它 AND 到你的 YJ 上（见最后两行）。 }

VM20:=MA(V,20);
VM60:=MA(V,60);
UPV:=IF(C>REF(C,1),V,0);
DNV:=IF(C<REF(C,1),V,0);

{ vf1 放量：当日量 >= 20日均量 * 1.2 }
VF1:=V>=VM20*1.2;

{ vf2 温和放量：1.2 倍 ~ 3 倍之间（排除天量） }
VF2:=V>=VM20*1.2 AND V<=VM20*3;

{ vf3 缩量后放量：前10日均量 <= 60日均量*0.85，且当日量 >= 前5日均量*1.3 }
VF3:=MA(REF(V,1),10)<=VM60*0.85 AND V>=MA(REF(V,1),5)*1.3;

{ vf4 上涨量占优：近10日上涨日成交量合计 >= 下跌日合计*1.5（研究前预先选定的一个，成绩也只是“没那么差”） }
VF4:=SUM(UPV,10)>=1.5*SUM(DNV,10);

{ vf5 口袋支点：上涨，且当日量 > 前10日内最大的下跌日成交量 }
VF5:=C>REF(C,1) AND V>HHV(REF(DNV,1),10);

{ vf6 = vf3 且 vf5 }
VF6:=VF3 AND VF5;

{ 研究里 V2 版额外加的两条（比单纯 V1 更严，仍未跑赢同流动性对照）：
  结构：近60日高点在近30日低点之前（先跌后起）
  流动性：近20日均成交额 >= 1 亿 }
STRUCT:=HHVBARS(H,60)>LLVBARS(L,30);
LIQ:=MA(AMOUNT,20)>=100000000;

{ 用法：在你原公式里的 YJ 后面这样接（任选一个 VFx）
  YJ_VF:YJ AND VF4;
  YJ_V2:YJ AND STRUCT AND LIQ;
  YJ_V2VF:YJ AND STRUCT AND LIQ AND VF4; }
