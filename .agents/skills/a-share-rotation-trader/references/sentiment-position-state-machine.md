# 情绪仓位状态机 `ST_cycle_v1`

`ST_cycle` 回答一个问题：**当前账户可以承受的最大市场风险是多少**。它不选股票，只给仓位上限与硬否决。

实现：`scripts/build_limit_ecology.py`，产出 `output/limit_ecology.csv`（全历史）与 `output/limit_ecology_latest.json`（最新交易日快照）。

## 数据口径

**唯一数据源是本地通达信日线重建，不使用第三方涨停池。** 原因见[数据可得性矩阵](data-availability.md)：东财涨停池只有约两周历史，炸板池与跌停池接口已失效，无法满足 60 日滚动分位（需 ≥40 个有效观察）与走样本外回测。

重建已对齐第三方真值：2026-08-14 重建 63 / 东财 63；连板高度逐股完全一致（62/62、59/59）；漏判 0 只。差异仅来自东财涨停池排除 ST。

### 涨跌幅限制的判定

**不得靠证券名称推断涨跌幅限制。** 本地名称表滞后于撤销 ST 公告，会把已恢复 10% 的股票按 5% 判定而虚增涨停（实测多出 4 只）。规则：

- 创业板/科创板（300/301/688/689）一律 20%，ST 亦然；
- 主板默认 10%；
- 仅当名称含 ST 标记**且**近 60 日最大绝对涨跌幅未超过 6% 时，才认定为 5%；
- 历史不足无法实测时保守按 10%，宁可漏判也不虚增。

涨停价 `= round(prev_close × (1 + limit_pct), 2)`，判定容差 0.004 元，且要求当日有成交。

### 两套口径必须分别标注

- **广度统计**保留全部涨停（含 ST、含一字板）；
- **接力指标**剔除 ST 与一字板——一字板无法买入，计入晋级率会虚高。

未复权序列在除权日会产生假涨跌停，按"跌幅超过限制 1.5 倍"剔除并计入 `suspect_adjust_n`。

## 每日指标

| 指标 | 定义 |
|---|---|
| `limit_up_n` / `limit_down_n` | 收盘封住涨/跌停家数（广度口径） |
| `touched_up_n` / `broken_n` | 盘中触及涨停家数 / 触板未封家数 |
| `N1`/`N2`/`N3`/`NH` | 连板高度为 1/2/3/≥4 的家数（接力口径） |
| `J1` | 昨日一板中今日晋级二板的比例 |
| `J2` | 昨日二板中今日晋级三板的比例 |
| `JH` | 昨日 ≥4 板中今日继续晋级的比例 |
| `FR` | 炸板率 `= broken_n / touched_up_n` |
| `YLR_close` | 昨日涨停股今日收盘收益均值（%） |
| `YLR_open` | 昨日涨停股今日开盘收益均值（%） |
| `B` | `limit_up_n / (limit_up_n + limit_down_n)` |
| `amount_yi` | 两市成交额（亿元） |

晋级率按**昨日候选集合逐股对齐**，并保存分子分母原始计数（`J2_succ`/`J2_cand`），不只保存比率。

## 晋级率的汇总与收缩

原始晋级率分母常只有 1–5 只，取值极度离散（0 / 0.2 / 0.25 / 0.33 / 0.5 / 1.0）。把最大权重压在抽样误差最大的指标上不合理。处理分两步：

1. **3 日汇总**：分子分母**分别累加**后再相除，不是对日比率求均值；
2. **Beta 收缩**：向 60 日整体晋级率 `p0` 收缩，伪观测数 `α = 3`：

\[
J_{shrunk} = \frac{\sum_{3d} succ + \alpha \cdot p_0}{\sum_{3d} cand + \alpha}
\]

效果：`J2` 缺失率从原设计的潜在陷阱降到 0%，分母为 0 的交易日占比 0.6%（近 500 日实测），`coverage` 稳定在 1.00。

## 合成分

五个因子，各自取 60 日滚动分位（并列值用中位秩，避免大量相同板数被压到 0 分）：

| 因子 | 权重 | 含义 |
|---|---:|---|
| `J2_shrunk` | 0.30 | 中位接力意愿，短周期转折第一确认指标 |
| `YLR_close` | 0.25 | 等权追涨策略的实际收益 |
| `FR_inv` | 0.20 | `100 − pct(FR)`，承接失败率的反向 |
| `AMT` | 0.15 | 两市成交额分位 |
| `J1_shrunk` | 0.10 | 低位承接意愿 |

缺失时**只对可用项重新归一化权重**，不用中性值 50 静默填补；权重和记为 `coverage`。

### 为什么删掉 `B`、加入 `AMT`

实测 Spearman 相关（近 500 日，`--collinearity`）：`B` 与 `YLR` 相关 +0.65、与 `FR_inv` 相关 +0.41，信息冗余，**已删除**。`AMT` 与所有涨停生态因子相关系数在 ±0.15 以内，是唯一近似正交的维度，**已提升为正式入分项**——v0 完全排除了成交额，而"流动性收缩但涨停生态尚可"正是需要识别的结构。收缩后的 `J2` 与其他因子相关性均不超过 +0.26。

### 合成分必须再分位化

分位数的加权平均会向中间压缩并整体抬升。直接用 `ST_raw` 配阈值 60，实测会让"主升"占到 **49%** 的交易日，完全失去风险区分力。因此：

\[
ST\_cycle = pct_{250}(ST\_raw)
\]

再分位化后 20/60/85 真正对应分布位置，主升降至 17%。两个值都要输出：`ST_raw` 供审计，`ST_cycle` 供判定。

## 五状态判定

基础档位**只由分数决定**，保证状态与 `ST_cycle` 不脱节：

- `ST_cycle ≥ 60` → 主升档
- `ST_cycle < 20` 且 3 日斜率 ≤ 0 → 冰点档
- 其余 → 修复档

**这是对 v0 的关键修正。** v0 在"主升条件未确认"时无条件保持前态、没有任何上下界。实测中 `ST_cycle` 一天从 18 跳到 80，状态仍被前一日的冰点锁住、上限停在 10%。

### 覆盖规则（按顺序）

1. **退潮**：`YLR_close` 连续 2 日为负 **且** `FR` ≥ 60 日 70 分位 **且** `J2_shrunk` ≤ 30 分位 → 直接降至最低档；
2. **高潮**：满足 ≥2 项即触发——`ST_cycle ≥ 85` 且不再上升；`FR` 连续 3 日递增；涨停家数达 60 日 95 分位而 `J2_shrunk` 走平或下降；
3. **防抖**：升档需**连续 2 日确认**且**每日最多升一档**；降档与硬覆盖允许直接到位；
4. `coverage < 0.80` 或预热期**禁止升档**；
5. **YLR 硬覆盖**：`YLR_close` 连续 2 日为负时上限不超过 30%，不可被高 `ST_cycle` 或宏观强势覆盖。

## 仓位上限与降仓速率

| 状态 | 上限 |
|---|---:|
| 冰点 | 10% |
| 修复 | 35% |
| 主升 | 80% |
| 高潮 | 45% |
| 退潮 | 15% |

v0 的"主升 100% → 高潮 30%"是一步 70 个百分点，在 T+1 且有跌停的市场里不可执行。现阶梯改缓，并加**每日最大降仓 25 个百分点**：超出部分顺延次日并在 `cap_note` 标记，避免输出无法成交的指令。实测可见 2026-08-11 从主升降档时上限为 55% 而非 35%，正是该限制生效。

上限是**允许的最大仓位，不是目标仓位**。

## 尚未完成的校准

输出中 `st_cycle_formal = false`：阈值（20/60/85）与权重仍是待验证参数，未完成走样本外回测。在验证完成前：

- 只用于风险上限参考，不得作为唯一仓位依据；
- **未验证状态下不得授权高于"修复"档（35%）的仓位**——`run_integrated_decision.py` 已强制这一降级；
- 不得把阈值或权重写成已验证事实；
- 任何权重变更必须重跑 `--collinearity` 并记录版本。

近 500 个交易日状态分布：修复 237、冰点 161、主升 86、高潮 12、退潮 4。

## 使用约束

- 盘后计算次日上限；竞价只允许降档；盘中只允许因硬覆盖降险，不允许提高上限或临时增加候选股。
- `ST_cycle` 与工程现有 `emotion_score` 是不同口径，不得混用。
- 不要用短周期滚动分位替代宏观趋势的绝对锚点，两者分开记录。
- 覆盖边界：沪深 A 股，不含北交所。
