## 复权闸门（硬门）

本地 `.day` 只解码原始 OHLC，**不含复权因子或复权标记**。使用时默认记录 `adjustment=unadjusted`，不得推断为前复权。

MA、ATR、RPS、跨日收益、回撤、形态筛选、回测、日线量价效率必须建立在已验证的前复权基础上。闸门实现为 `scripts/verify_qfq.py`，产出 `output/qfq_verification.json`。

**下游只读该报告，不接受自我声明，也没有命令行覆盖参数。** 改造前 `run_integrated_decision.py` 支持 `--qfq-status verified`，使全框架最强的护栏可被一个参数绕过——该后门已删除。

未通过时上述指标**全部停算**，不允许只降低置信度后继续计算。成交额保持原始元口径，不做价格复权，可继续用于 `ADV20`。

### 关键事实：腾讯 `qfqday` 是等差复权

实测 601330.SH：连续多日 `raw − qfq` 恒为 0.32；2025-11-11 跳为 0.22；2026-07-08 归零。即腾讯用**原价减累计分红**实现前复权，不是原价乘因子。

后果：

- 只按等比（`qfq/raw` 分段恒定）检验会把大批正常复权的股票误判为"未复权"——改造过程中实测 12 只误判 7 只；
- 等差序列**扭曲百分比收益率**，不能直接用于 RPS、跨日收益、回撤；
- 必须用报告中 `details[].actions[].multiplicative_factor` 反解出的等比因子重建序列后再算价格类指标。

### 正式本地运营门

1. 固定种子抽样本地通达信 `.day`，历史 OHLC 与 `v_daily` 原始视图逐日对齐；
2. 全库检查 `v_daily_qfq = v_daily × calc_adjust_factor_daily.forward_factor`；
3. 全库检查 volume/amount 不变、因子为正、最新日因子归一且 qfq 收盘等于原始收盘；
4. 抽样要求 100% 通过，全库错配必须为 0，才输出 `verified_qfq`；
5. 该结论是本地运营一致性验证，不是独立外部复权证明。

### 腾讯诊断方法

1. 抽样若干只股票，取腾讯 `qfqday` 与本地 `.day` 的共同交易日；
2. 同时检验两种约定：等比 `qfq/raw` 与等差 `qfq − raw` 是否**分段恒定**（台阶只出现在除权日，段内不变）；
3. 容差按价格量化缩放——本地收盘价是整数除以 100（绝对精度 0.01），对 1.5 元的股票就是 0.67% 的相对误差，用固定容差会把量化噪声误判为未复权；
4. 前复权以最新交易日归一：等比末值应为 1，等差末值偏移应为 0；
5. 逐除权日检查方向（前复权收益不应低于未复权收益）与因子区间（0.5 < f ≤ 1）；
6. 抽样通过率 ≥90% 且无对账失败样本，腾讯诊断才判定 `verified_qfq`；该诊断不覆盖本地正式门。

运行 `verify_qfq.py --mode tencent --sample 16` 默认写入
`output/qfq_tencent_diagnostic.json`，不会覆盖本地正式门报告。

结论只有三种：`verified_qfq` / `unadjusted` / `unknown`。

## 腾讯分钟的使用约束

- 只在实际返回结构通过校验后使用；累计成交额**只做区间差分**，不直接当作分钟成交额。
- **只有当日数据，没有历史接口。** 不得宣称已取得历史分钟。
- 因此不得用于构造任何需要历史横截面或回测的指标（分钟级 CER 已因此整块删除）。
- 本地 `fzline`/`minline` 已停更（最新 2024-06 / 2024-03），**不得作为分钟历史的替代**。

## 数据质量检查

每个核心结论保存：来源、证券代码、数据截至时间、频率、复权方式、单位、采集时间。保存原始响应或可追溯缓存；分析结果不得只留下无法复算的摘要值。

必查项：

- 本地日线最新日期是否等于目标交易日；不等时明确说明并改用实际最新日；
- 除权日在未复权序列上产生的假涨跌停已按"跌幅超过限制 1.5 倍"剔除，计入 `suspect_adjust_n`；
- 成交量为 0 的停牌日不参与涨跌停判定；
- 行业配置文件的修改时间——落后于分析日的配置不得用于当期归类；
- 上市不足 20 个交易日不计算 `ADV20` 归一化指标。

## 字段口径

- 成交额、主动买入估算与"主力净流入"是不同字段。**本技能不使用任何估算资金流**——相关源已因接口失效与无历史而删除，不得声称识别了真实主力资金。
- 涨停生态的广度口径与接力口径必须分别标注，不可混用。

## 交易日历

不依赖外部日历接口，**以本地日线中实际存在的交易日为准**。理由与前瞻性限制见[日内流程](daily-workflow.md)。

## 覆盖边界

仅沪深 A 股。北交所（8xx、920xxx）不在本地 `vipdoc` 中，一并排除。实测 2026-08-14 东财涨停池含 920083.SZ 而本地无该标的——**不得把本口径称为"全 A 股"**。
