# 门控式整合规范

实现：`scripts/run_integrated_decision.py`。前置产出必须齐备：

```powershell
python skills/a-share-rotation-trader/scripts/verify_qfq.py --mode local --sample 64
python skills/a-share-rotation-trader/scripts/build_limit_ecology.py --history 500
python skills/a-share-rotation-trader/scripts/run_integrated_decision.py --date 20260814 `
  --account-state empty --equity 1000000 --available-cash 1000000 --single-trade-risk-pct 0.50
```

## 每个模块只做一件事

| 模块 | 负责 | 明确不负责 |
|---|---|---|
| 复权验证 | 判定价格类指标能否计算 | 不选股，不给仓位 |
| RPS | 建立盘前冻结的慢周期候选池 | 不决定买入时点，不决定仓位 |
| 涨停生态 / `ST_cycle` | 给次日仓位上限与硬否决 | **不选择股票** |
| 行业共振 | 确定第一主线与次主线 | 不给个股买点 |
| 账户执行 | 由风险预算决定股数 | 不改变上限，不新增候选 |

**不把各模块相加成总分。** 门控是串联的：前一道不过，后一道不执行。

## 六道门控

### G0 复权闸门（硬门）

只读 `output/qfq_verification.json`，要求 `price_adjustment == "verified_qfq"`。默认报告必须来自 `gate_type=local_operational_consistency`：本地通达信原始 OHLC 抽样全部一致、全库前复权公式/量额/最新归一全部零错配。**无自我声明通道，无命令行覆盖参数。**

本地运营门不是独立外部复权证明；`verification_scope` 必须在报告中披露。腾讯模式只用于诊断，不覆盖本地正式报告。

未通过 → RPS、MA、ATR、跨日收益、回撤、形态筛选全部停算，直接零交易。不进入 G1。

### G1 风险许可（硬门）

只读 `output/limit_ecology_latest.json`。要求快照日期等于目标交易日，且 `coverage ≥ 0.80`。

输出账户上限。当 `st_cycle_formal == false`（当前状态）时，**上限强制降至"修复"档 35%**——未完成走样本外回测的模型不得授权更高风险。

未通过 → 零交易。

### G2 RPS 候选

要求 G0 已通过。候选须同时满足：

- 价格型输入来自 `data/hithink/market.duckdb:v_daily_qfq`；成交量与成交额保持原始口径；
- RPS 横截面先保留所有具备对应 N 日历史的股票，候选阶段再要求至少 260 根日 K，避免提前删股改变 RPS50/120 分母；

- 位于前列行业内；
- 收盘站上 MA20 **且**站上 MA60；
- `RPS_120 ≥ 80`；
- 距 MA20 乖离 ≤ 12%（避免追已大幅偏离均价的标的）；
- `ADV20 ≥ 1.5 亿元`（流动性下限，保证 T+1 可退出）。

**逐股标注主线地位**：只有第一主线内的标的 `executable = true`；次主线标的即使 RPS 更高也只进入观察，不得成为唯一主计划。

### G3 主线共振

行业共振分由五项各自的横截面分位平均：5 日中位收益、20 日中位收益、站上 MA20 宽度、`RPS_120` 中位数、成交额 / `ADV20`。行业须有 ≥8 只有效成分股。

**单股驱动降级**：某只股票成交额占行业 >35% 时标记 `single_stock_driven`，该行业不得作为第一主线——这不是板块共振，是单股行情。

### G4 执行质量

检查候选的流动性与乖离。`CER_D1` 作为观测字段输出但**不参与排序**（见[量价效率](capital-efficiency-ratio.md)）。分钟级固定目标 CER 已整块删除。

### G5 账户执行

要求账户状态、权益、可用现金、单笔风险预算齐备，且有唯一主计划含入场价与硬失效位。

有效止损距离取三者最大：计划距离、涨跌幅限制 × 0.6、1 × ATR20。输出中必须标明**哪一项约束起作用**（`binding_constraint`）。

缺任一项 → 不生成伪精确仓位，动作为"零交易＋待补数据清单"。

## 动作判定

| 情况 | 动作 |
|---|---|
| 六门全过 | 条件买入（等待唯一计划触发） |
| G0 或 G1 未过 | **零交易**（硬门） |
| 其余门未过 | 研究观察，不产生可执行买单 |

若没有股票通过全部门控，**正确答案是零交易，不是放宽标准寻找一个名字**。

实跑示例（2026-08-14）：六门中 G0–G4 全过，第一主线为通用机械，但 9 只候选全部落在次主线医药，G5 未通过 → 结论"研究观察，不产生可执行买单"。这正是规则生效而非被绕过的样子。

## 使用约束

- RPS 只建立盘前冻结的候选池；复权未验证时停算，**不得沿用旧 RPS** 产生交易候选。
- 禁止在 G0 通过后重新把通达信 `.day` 未复权 OHLC 送入 MA、ATR、RPS、收益或形态计算；量额可继续使用原始口径。
- `ST_cycle` 只控制次日上限与硬否决；竞价与盘中只能降险，不能提高盘后上限。
- 腾讯当日分钟用于盘中价格路径与总成交额，累计额只做差分；无历史，不得用于回测。
- 覆盖边界为沪深 A 股，不含北交所。
- 空仓也要复盘：记录当日第一主线、若执行会得到什么结果、放弃属于哪一道门。连续零交易而第一主线持续上行时，说明门控偏紧，需回测校准而非临时放宽。
