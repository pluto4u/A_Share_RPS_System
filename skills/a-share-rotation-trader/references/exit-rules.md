# 买点、仓位与退出规则

改造前本技能只有入场逻辑（先手/确认买点）和仓位公式，退出只散落一句"次日 T+1 可执行退出条件"，没有任何可执行规则。这导致同一个账户里两类完全不同的持仓被同一套模糊标准管理。本文件为两类持仓各定义一套完整退出规则。

## 两个持仓账本必须分开

同一账户内的持仓按**买入理由**分账，退出规则不可混用：

| | 情绪单（emotion book） | 趋势单（trend book） |
|---|---|---|
| 买入理由 | 涨停生态接力、主线加速、题材共振 | RPS 强度 + 均线结构 + 主线中军 |
| 预期持有 | 1–3 个交易日 | 2–8 周 |
| 主导变量 | `ST_cycle` 状态、连板晋级率、炸板率 | 行业共振分、MA20/MA60 结构、RPS 分位 |
| 退出触发 | 情绪状态降档即减，不等价格 | 价格与结构失效才减，容忍情绪波动 |
| 单笔风险预算 | 账户权益 0.2%–0.4% | 账户权益 0.4%–0.8% |
| 合计上限 | 不超过账户上限的 1/3 | 其余额度 |

分账的原因：情绪单的失效来自**环境**（情绪退潮），趋势单的失效来自**标的自身结构**。用价格止损管理情绪单会退出太晚，用情绪状态管理趋势单会在正常回调中被震出。

## 两种合法买点

### 先手买点

适用于主线已由竞价与核心结构初步成立、但板块尚未全面扩散：

- 中军或核心股第一次回踩分时均价、开盘区间上沿或关键成交密集区；
- 回踩缩量，龙头未炸板、未跌破关键位；
- 止损距离清晰，预期收益至少为风险的 2 倍；
- 不在高开过度时直接追价。

先手不是猜底。主线未成立、核心结构分裂或处于风险收缩时不使用先手。

### 确认买点

适用于板块首次分歧后重新转强：

- 中军重新站上均价或早盘关键区间；
- 龙头与至少一只同类核心股同步修复；
- 板块宽度与成交未继续恶化；
- 突破位置未明显远离均价与 ATR 合理区间。

不把连续拉升后的二次冲顶机械定义为确认买点。

## 仓位公式

取消所有标的统一 2%–3% 的机械试仓。

\[
风险仓位 = \frac{账户单笔风险预算}{有效止损距离}
\]

\[
有效止损距离 = \max(计划距离,\; 涨跌幅限制 \times 0.6,\; 1 \times ATR20)
\]

后两项下限的原因：硬失效位在一字跌停下**不可成交**，名义止损无法实现；止损窄于 1 个 ATR 会被日常波动直接打掉，名义风险小但实际触发概率极高，会系统性高估可承载仓位。三者取最大后仓位相应下调。

\[
最终单笔仓位 = \min(风险仓位,\; 信号基础仓位,\; 流动性上限,\; 相关性额度,\; 账户剩余额度)
\]

\[
账户总仓位上限 = \min(宏观状态上限,\; 情绪状态上限,\; 波动率/回撤/龙头健康度硬上限)
\]

只有系数已经过样本外验证并写入配置时，才使用 RPS 基础仓位 × 情绪系数；否则不生成伪精确乘数。高度相关标的视为**一笔风险**，不用多只股票伪装分散。

## 情绪单退出规则

按顺序检查，命中即执行，不等更多确认：

| 条件 | 动作 |
|---|---|
| `ST_cycle` 状态降档（主升→修复、任意→退潮/高潮） | 次日开盘减至新状态上限，不等价格 |
| 昨日涨停股收益 `YLR_close` 连续 2 日为负 | 情绪单全部清掉，硬覆盖，不可被高 `ST_cycle` 或宏观强势覆盖 |
| 炸板率 `FR` 升至 60 日 70 分位以上且二板晋级率 `J2` 降至 30 分位以下 | 情绪单减半 |
| 个股封板后炸板且未在当日收复 | 次日开盘卖出 |
| 买入后次日未能高开或未维持在均价上方 | 次日尾盘前退出，不留过夜 |
| 持有达 3 个交易日仍未创新高 | 无条件退出，时间止损优先于价格止损 |
| 触及硬失效位 | 立即退出；若因一字跌停无法成交，次日开盘无条件市价退出 |

情绪单不设移动止盈：达标即分批退出，不试图持有到主升末端。

## 趋势单退出规则

| 条件 | 动作 |
|---|---|
| 收盘跌破 MA20 | 减半 |
| 连续 2 个交易日收盘在 MA20 下方 | 清掉该笔 |
| 收盘跌破 MA60 | 无条件清掉，不等反弹 |
| 所属行业共振分跌出前 5，或行业上涨宽度跌破 50% | 减半并停止加仓 |
| `RPS_120` 跌破 60 | 减半；跌破 40 清掉 |
| 距 60 日高点回撤超过 2.5 × ATR20 | 减半 |
| 宏观状态转为风险收缩 | 全部趋势单减至账户上限，优先减 ATR 最高的 |
| 触及硬失效位 | 立即退出 |

趋势单允许移动止损：创新高后把硬失效位上移至 `max(原失效位, 最高价 − 2 × ATR20)`，且只上移不下移。

## 加仓规则

只允许在盈利后加仓，且加仓后**整笔的合计风险不得超过原始单笔风险预算**：

- 情绪单不加仓；
- 趋势单在首仓浮盈超过 1 × ATR20 且硬失效位已上移至成本上方时，允许加一次，规模不超过首仓；
- 任何情况下不向亏损仓位加仓。

## 每笔计划必须给出

入场区间（不用无统计依据的两位小数）、买点类型（先手/确认）、所属账本（情绪/趋势）、首仓与最大仓位、当日取消条件、次日 T+1 可执行退出条件、硬失效位、盈亏比与主要反向风险。

采用[行动卡布局](action-card-output.md)时再加四项，把「不买」也写成指令：

- **追高禁区**：超过该价禁止买入；
- **机会成本**：量化不买可能错过的空间，以及仍不买的原因；
- **账户状态分叉**：空仓 / 已有仓 / 重仓各自动作，未提供账户时三分叉并列，不猜测持仓；
- **拒绝数据清单**：本页未使用、也不会用估算值填上的字段。

门控未通过时标题必须是「观察，不可执行」，不得改称条件买入。

## 复盘窗口

改造前只复盘"收盘及次日结果"，无法区分"信号无效"与"持有期太短"。现要求每笔记录 **+1 / +5 / +10 / +20 个交易日**的四个结果，均按 T+1 可执行价格评价：

| 窗口 | 用途 |
|---|---|
| +1 日 | 检验买点质量与 T+1 隔夜风险 |
| +5 日 | 检验情绪单的有效持有期 |
| +10 日 | 检验趋势单是否走出 |
| +20 日 | 检验退出规则是否过早——若 +20 日显著优于实际退出价，说明退出规则偏紧 |

同时记录期间**最大有利波动与最大不利波动**，用于分别评价赔率与错误成本。只看 +1 日会系统性偏向情绪单并低估趋势单。
