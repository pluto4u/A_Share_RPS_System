# 次新股池

实现：`scripts/build_new_listing_theme_pool.py`。

## 目标

建立可每日增量更新的当年 A 股上市名单，归入通达信行业。该池是**候选宇宙，不是买入信号**。

## 题材归类已删除

原设计要求同时保存 `industry_name` 与可交易的 `primary_theme`/`secondary_theme`（存储、光通信、先进封装、半导体设备等）。**题材层已整块删除。**

依据[数据可得性矩阵](data-availability.md)：唯一本地概念源 `hq_cache/block_gn.dat` 更新时间为 2025-08-09，落后一年；同花顺概念页无版本化历史成分。归类只能由 LLM 每日临时判断，历史无法重算，任何依赖题材的指标都无法回测。

因此本池**只有行业维度**。不得把行业写成"题材"，也不得在报告中出现"存储主题次新股池"这类表述——那需要已删除的归类能力。

若将来取得**带生效日期的版本化成分数据**，可重新引入，前置条件是能重算至少 250 个交易日的历史归属。

## 入池与日期校验

1. 读取本地 `vipdoc/{sh,sz}/lday/*.day` 首条记录，筛选首日位于指定自然年的 A 股；
2. 用腾讯日 K 首条日期交叉校验；不一致时**保留双日期并标记冲突**，不静默覆盖；
3. 未取得官方日期时写 `listing_date_quality=market_crosscheck`，不得写"交易所已确认"；
4. 名称优先用腾讯最新快照，去除上市前五日的 `N`/`C` 临时前缀后另存 `display_name`，保留原始名称；
5. 覆盖边界为沪深 A 股，不含北交所，不得称为全 A 股完整名单。

## 上市阶段

按**有效交易日数**划分，不用自然日替代：

| 阶段 | 交易日 | 规则 |
|---|---:|---|
| 极端定价期 | 1–5 | 只观察，不追涨 |
| 价格发现期 | 6–20 | `ADV20` 不足，归一化指标停算 |
| 初步稳定期 | 21–60 | `ADV20` 可用；价格类跨日指标仍受复权闸门约束 |
| 结构形成期 | 61–120 | 主线确认后可进入角色比较与条件买入池 |
| 成熟次新 | 121–250 | 按普通股票框架评估，保留供给与解禁风险标签 |

`RPS_120` 需要 120 个交易日、`RPS_250` 需要 250 个交易日历史。上市不足时该字段记 `NA`，**不得用更短窗口的值冒充**，也不得与满窗口样本混排比较。这实际意味着当年新股在 `RPS_250` 维度上不可比。

## 输出与风险

至少输出：代码、名称、市场、上市日期、交叉校验状态、交易日数、上市阶段、通达信行业、`ADV20` 是否可用、数据质量。

- 次新股池先与全市场第一主线比较；**行业不在主线时不因"次新"标签买入**。
- 上市不足 20 日不生成伪造 `ADV20`。
- 未验证前复权时停止 RPS、MA、ATR、跨日收益与日线量价效率。
- 上市日期与数据源需版本化；人工修改保留依据。
- 账户仓位仍由宏观状态与 `ST_cycle` 决定；次新只会**降低**风险预算，不会提高上限。
