# 日内流程与复盘校准

## 交易日历

本技能不依赖外部交易日历接口。**以本地通达信日线中实际存在的交易日为准**：`vipdoc/{sh,sz}/lday/*.day` 中最新日期即最近交易日。

理由：外部日历源在探测中均无法提供可验证的历史版本，而本地日线的日期集合本身就是交易所实际开市日的记录，且与所有价格计算共用同一口径，不会产生日历与数据错位。

节假日安排等前瞻性信息本地无法提供。需要判断"下一个交易日是哪天"时必须明确说明这是推断，不得当作事实。

## 时间流程

### 盘前至 9:25

核对交易日、账户状态、隔夜市场、宏观事件与正式公告。读取盘后生成的 `ST_cycle`、量化仓位状态、数据覆盖率与账户上限。

建立高开、平开、低开三种情景，**不预设第一买入标的**。9:20—9:25 用竞价二次验证：严重弱于预期时降一档，强于预期时**不得升档**。随后冻结候选池与仓位上限。

竞价必查：核心股竞价涨幅、竞价金额、未匹配量与最后五分钟变化；龙头是否高开过度、中军是否合理高开、后排是否一致顶价；昨日涨停股溢价、连板晋级率、跌停反馈；龙头—中军—弹性是否同向；高位股是缩量锁筹、放量换手还是放量滞涨。

### 9:30—10:00

只验证盘前预设，不新增研究对象。不开盘盲追；仅允许候选池内的主线中军在竞价确认后的第一次合理回踩形成先手。最高空间断裂或核心结构分裂时停止新增。

### 10:00—10:30

确认市场状态、第一主线与个股角色是否符合盘前方案。比较同时间成交额与主线内部结构。不提高状态上限，不因信号"更完整"而追入已大幅偏离均价的后排。

### 11:00—12:00

检查早盘高点是换手、滞涨还是派发；检查主线是否从龙头扩散到中军。午间结论不得直接替代尾盘结论。

### 13:15

观察午后第一轮资金选择：回流主线、跨行业轮动或风险收缩。重点验证首次分歧修复。不因单只股票拉升宣告板块轮动；未进入盘前条件式备选的方向不得临时开仓。

### 14:30

刷新量能、指数均价、主线宽度。只保留盘前候选池中的一个标的，或明确零交易。

### 14:50

只输出一个账户级主结论：持有、减仓、执行盘前计划新买一只、或零交易。停止新增故事和临时换逻辑；明确标的、区间、仓位、取消条件与次日退出规则。

## 输出结构

HTML 首屏给结论，第二屏起给证据。字段按数据可得性条件化——依赖数据未取得时写"未覆盖—缺少××"，不得抓取未验证替代口径，也不得删除字段假装不需要。

1. 数据时间与账户状态
2. 市场状态：趋势扩张 / 高位轮动 / 风险收缩，只选一个
3. 量化仓位状态：冰点 / 修复 / 主升 / 高潮 / 退潮；报告 `ST_cycle`、斜率、覆盖率、覆盖规则、账户上限，以及 `st_cycle_formal` 是否为真
4. 盘面过程阶段：启动 / 扩散 / 加速 / 分歧 / 修复 / 退潮
5. 行业排序：第一主线、次主线、防守、伪轮动（**只有行业维度，没有题材维度**）
6. 资金路径：龙头—中军—弹性是否共振
7. 候选池：逐股标注主线地位与是否可执行
8. 唯一主计划：标的、买点类型、所属账本、区间、仓位、三项止损下限中哪一项起作用、失效与 T+1 规则
9. 备选条件：仅说明主计划取消后何种盘面才切换，不得同时下单
10. 风险四项：当前最大风险、失效条件、对应动作、反向风险
11. 置信度：高/中/低，并说明最薄弱的数据或假设
12. 数据来源：来源、代码、截至时间、频率、复权、单位与异常说明

若用户只提供局部主线或少量股票，无法完成全市场排序，则对应字段写"未覆盖—缺少全市场横截面"，不得把局部最强冒充第一主线。

## 复盘成绩单

每次可执行建议保存以下字段：

| 字段 | 要求 |
|---|---|
| 判断时间 | 精确到分钟 |
| 市场状态与情绪阶段 | 当时判定，不得事后改写 |
| `ST_cycle`、斜率、覆盖率、`st_cycle_formal` | 保存原始值、分位值与缺失项 |
| 量化仓位状态与上限 | 记录覆盖规则、宏观上限、最终账户上限、是否受降仓速率限制顺延 |
| 复权闸门结论 | 记录 `price_adjustment`、抽样通过率、检出的除权日 |
| 第一主线 | 只记一个；同时记录候选是否全部落在次主线 |
| 标的与当时价格 | 记录原始建议 |
| 买点类型与所属账本 | 先手/确认；情绪单/趋势单 |
| 计划仓位与风险预算 | 记录公式全部输入，以及三项止损下限中哪一项起作用 |
| 触发与失效 | 是否真实发生 |
| +1 / +5 / +10 / +20 日结果 | 均按 T+1 可执行价格评价 |
| 最大有利/不利波动 | 分别评价赔率与错误成本 |
| 错误类型 | 数据、状态、主线、个股、时点、仓位或执行 |

每累计 20 次，计算方向胜率、触发后胜率、平均盈亏、盈亏比、最大不利波动、空仓机会成本，并与"第一主线 ETF 简单持有"比较。**情绪单与趋势单分别统计**，混合统计会互相掩盖。

胜率不能单独评价系统；优先看期望值与最大回撤。发现连续偏差时先修正规则，不用宏观叙事解释亏损。禁止事后选择性引用成功案例。

## 空仓也要复盘

零交易同样记录：当日第一主线、若执行会得到什么结果、放弃的原因属于哪一道门。这是唯一能发现"门控过紧"的方式——若连续多次零交易而第一主线持续上行，说明候选筛选条件或 `ST_cycle` 阈值偏紧，需要回测校准而不是临时放宽。
