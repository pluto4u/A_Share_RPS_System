# 行动卡输出布局

这是**输出排版**，不是第二套选股逻辑。

## 与思考链的边界

| 层 | 谁说了算 | 不可被本布局改写 |
|---|---|---|
| 思考链 | `SKILL.md` + 六道门控 + 三层状态 | 复权闸门、风险上限、第一主线才可执行、已删除功能不得回潮 |
| 输出层 | 本文件 | 只改变信息出现的顺序和颗粒度 |

本布局来自一份高质量盘中叙事的结构，不是来自新的数据源。采用本布局时：

- 门控结论必须原样出现在首屏。若 G5 判定零交易，行动卡「立即买」必须为「无」，不得为了填表放宽 `RPS_120`、乖离或主线约束。
- 「等待买」是观察清单，不是已授权买单；升级为可执行必须再次通过 G2–G5。
- 不得为了模仿原稿的资金流表、分时均价对照或 13:xx→14:xx 差值，去调用已删除的估算资金流，或用停更两年的本地分钟冒充当日路径。
- 分钟级双时点、板块超大单/大单同向、北向净额、全市场实时涨跌家数：未取得就写入「拒绝使用清单」，不估算。

## 推理顺序（思考仍按此走）

1. 划可信边界，列出**拒绝使用**的数据。
2. 能做双时点就做双时点；没有分钟时，用「上一交易日收盘 → 本交易日收盘」和「当日开盘 → 收盘」代替，并标明这是日线代理，不是分时回流。
3. 第一主线要过多重独立确认：宽度、量能相对 `ADV20`、非单股驱动、角色是否共振。缺哪一条写哪一条。
4. 主线成分股用同一把尺子：是否站上 MA20/MA60、距 MA20 乖离、距当日高点、量比。**点名弱项**，不只列上涨的。
5. 给资金路径一个名字，并说明当前停在哪一段。
6. 次级方向必须逐个给「现在不做」的**分类理由**（位置过高 / 确认不足 / 资金或结构分裂 / 不在第一主线）。三种理由对应三种等待条件，不可写成「都不买」了事。
7. 只留一个可执行计划；其余明确不开新仓。账户未提供时，空仓 / 轻仓 / 重仓三分叉，不猜测持仓。

## 报告骨架

1. **两段结论**：第一段同时写认可与不追价的理由；第二段给账户级指令（按持仓状态分叉）。
2. **数据口径**：交易日、价格复权状态、每个数字的时点与性质、拒绝使用清单。
3. **第一主线内部结构**：中军/龙头/弹性/后排，同一套尺子。
4. **次级方向**：每个附分类理由。
5. **指数与量价**：开盘相对昨收、收盘相对昨收、收盘相对当日高点；量能相对上一交易日。
6. **唯一计划**（可执行时）或**唯一观察标的**（门控未过时）：见下方字段。
7. **隔夜持仓处理**：留 / 减 / 清，每条带价格阈值与动作规模。
8. **仓位三分叉**：空仓 / ≤20% / 重仓。
9. **六列行动卡**：立即买 / 等待买 / 持有 / 减仓 / 清仓 / 禁止追涨。
10. **事实 / 推断 / 交易假设** 三分区 + 风险四项。

## 唯一计划必填字段

在 `exit-rules.md` 原有字段之外，本布局强制多四项：

| 字段 | 作用 |
|---|---|
| 追高禁区 | 超过该价格禁止买入，把「不买」写成指令 |
| 机会成本 | 量化不买可能错过什么、以及为什么仍不买 |
| 账户状态分叉 | 空仓 / 已有仓 / 重仓各自动作 |
| 拒绝数据清单 | 本页没有使用、且不会用估算值填上的字段 |

门控未通过时，这些字段仍然要写，但计划标题必须是「观察，不可执行」，不能叫「条件买入」。
