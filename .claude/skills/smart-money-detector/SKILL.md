# 主力行为识别

## R — 原文 (Reading)

> "熊市：缓跌急涨——主力出货为主，反弹是诱多。主力倾向于'慢慢压价'，在下跌途中边跌边卖。有时故意拉升制造急涨，吸引散户'抄底'，套住追涨资金后再开始新一轮下跌。反弹不是趋势反转，是'出货陷阱'。"
>
> "牛市：缓涨急跌——主力吸筹为主，急跌是洗盘。主力慢慢推高股价吸筹，控制涨速。急跌的目的是洗掉短线投机者，压低成本，让筹码回到自己手中。急跌不是出货，是吸筹伎俩。"
>
> — Mistery, 第一章【主力行为学】

---

## I — 方法论骨架 (Interpretation)

核心洞见: **牛市和熊市中主力行为完全相反**。同样的急跌/急涨, 在不同市况下含义截然不同。

**牛熊不对称模型**:

| 市况 | 日常走势 | 急跌含义 | 急涨含义 | 主力目的 |
|------|---------|---------|---------|---------|
| 牛市 | 缓涨 | 洗盘(机会) | 自然上涨 | 吸筹 |
| 熊市 | 缓跌 | 自然下跌 | 诱多(陷阱) | 出货 |

**主力操作四阶段**:
1. 吸筹: 低位缩量横盘/利空打压/筹码集中 → 逢低吸纳
2. 洗盘: 急跌缩量/不破关键位/快速收回 → 持有不动
3. 拉升: 放量突破/均线多头排列/沿均线上行 → 跟随持有
4. 出货: 高位放量滞涨/利好配合/筹码分散 → 坚决离场

**破相思维**: 不看价格表象(涨/跌), 看筹码流向(谁在买谁在卖)。高位利好+放量不涨=出货; 低位利空+缩量跌不动=吸筹。

## A1 — 书中的应用 (Past Application)

### 案例 1: 牛市急跌=洗盘
- **问题**: 牛市中持仓股突然急跌7%, 该割肉吗?
- **方法论的使用**: 牛市缓涨急跌模型 → 急跌=洗盘非出货 → 看量能(缩量=主力没走)
- **结论**: 不割肉, 等超跌反弹
- **结果**: 急跌后放量反弹, 升势继续

### 案例 2: 熊市急涨=诱多
- **问题**: 熊市中持仓股突然急涨5%, 是反转吗?
- **方法论的使用**: 熊市缓跌急涨模型 → 急涨=诱多非反转 → 反弹中减仓
- **结论**: 不追, 反弹中减仓
- **结果**: 反弹后继续下跌

### 案例 3: 高位放量滞涨=出货
- **问题**: 持仓股高位放巨量但不涨, 怎么办?
- **方法论的使用**: 破相思维 → 放量不涨=主力派发 → 坚决出局
- **结论**: 卖出
- **结果**: 随后大跌

## E — 可执行步骤 (Execution)

1. **判断市况**:
   - 当前是牛市/熊市/震荡? (参考大盘均线+量价)
   - 完成标准: 市况标签

2. **分析事件**:
   - 发生了什么? (急跌/急涨/放量/缩量/利好/利空)
   - 幅度多大? (涨跌幅%)
   - 量能如何? (放量/缩量/正常)
   - 完成标准: 事件描述

3. **匹配主力行为模型**:
   - 牛市+急跌+缩量 → 洗盘(机会)
   - 牛市+急涨+放量 → 自然上涨(正常)
   - 熊市+急跌 → 自然下跌(风险)
   - 熊市+急涨+放量 → 诱多(陷阱)
   - 高位+放量+滞涨 → 出货(危险)
   - 低位+缩量+止跌 → 吸筹(机会)
   - 完成标准: 主力意图判断

4. **破相验证**:
   - 筹码流向: 大单在买还是在卖?
   - 量价关系: 放量方向与价格方向是否一致?
   - 周期一致性: 日线信号与周线趋势是否矛盾?
   - 完成标准: 表象vs本质的验证结论

5. **输出操作建议**:
   - 主力意图: 吸筹/洗盘/拉升/出货
   - 置信度: 高/中/低
   - 操作: 跟随/回避/持有/离场
   - 完成标准: 明确的判断+操作建议

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 低流动性股票(日均成交<5000万): 无主力, 信号无意义
- 政策直接干预(如涨跌停限制变动): 非市场行为
- ETF/指数: 无单一主力

### 作者在书中警告的失败模式

- 把所有急跌都当洗盘: 只有牛市中才成立, 熊市急跌是真跌
- 把所有放量都当买入信号: 高位放量=出货, 是反向信号
- 过度拟人化"主力": 市场无单一主力, 是多方力量合力
- 幸存者偏差: 作者的成功经验可能不代表普遍规律

### 容易混淆的邻近方法论

- 龙虎榜分析: 看游资/机构席位, 本skill看量价行为推断意图
- Level-2盘口分析: 更精细的大单追踪, 本skill用日线级别信号
