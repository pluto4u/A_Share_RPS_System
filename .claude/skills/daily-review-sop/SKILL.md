# 复盘SOP

## R — 原文 (Reading)

> "一、宏观&消息面：三大指数走势、成交量、北向资金、政策新闻。二、板块热点&轮动：最强板块前3-5名、涨停家数/炸板率、板块持续性、龙头动向。三、个股层面：持仓股表现、买卖复盘、观察股池更新。四、技术面：K线形态、均线、量价关系、MACD/KDJ/RSI。五、总结和计划：市场情绪判断、明日策略、重点观察对象。"
>
> — Mistery, 第一章【关于复盘】

---

## I — 方法论骨架 (Interpretation)

每日收盘后按固定五层模板复盘, 目标是: 发现机会/风险 → 制定明日计划。不是流水账, 是结构化分析:

1. **宏观&消息面** — 大环境定调
2. **板块热点** — 资金流向和轮动节奏
3. **个股层面** — 持仓健康度+观察池更新
4. **技术面** — 关键信号扫描
5. **总结计划** — 一句话情绪判断+三条操作计划

每层有明确的检查项和输出标准。复盘的终点不是"总结"而是"明日该干什么"。

## E — 可执行步骤 (Execution)

1. **宏观&消息面**:
   - 三大指数涨跌幅+K线形态+量能变化
   - 成交量: 放量/缩量 vs 均量
   - 北向/主力资金净流入流出
   - 重要政策/数据/会议
   - 完成标准: 一句话宏观定调

2. **板块热点&轮动**:
   - 最强板块Top3-5(涨幅+成交活跃度)
   - 涨停家数/炸板率 → 情绪温度
   - 板块持续性: 主线强化 or 轮动切换?
   - 龙头动向: 涨停/调整/分歧?
   - 完成标准: 板块热力图+情绪判断

3. **个股层面(持仓)**:
   - 每只持仓: 涨跌幅/K线/量能/趋势是否完好
   - 当日交易复盘: 是否符合系统? 有无情绪化操作?
   - 观察股池: 新机会? 前期关注的标的有买点?
   - 完成标准: 持仓健康度红绿灯

4. **技术面扫描**:
   - 大盘+热点板块: 突破/震荡/转折?
   - 均线变化: 多头排列/死叉出现?
   - MACD/KDJ/RSI: 背离/反转信号?
   - 量价关系: 配合 or 背离?
   - 完成标准: 关键技术信号列表

5. **总结计划**:
   - 市场情绪: 强势/震荡/恐慌? → 对应情绪周期阶段
   - 明日策略: 持有/减仓/换股/观望? (最多3条)
   - 重点观察: 3-5只标的+触发条件
   - 反思: 今天有什么值得记录的操作/教训?
   - 完成标准: 一句话情绪判断 + ≤3条操作计划 + 观察名单

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 盘中实时: 本skill是盘后复盘, 盘中用 `intraday-signals`
- 周末/假期: 无当日数据, 改用周复盘模板

### 作者在书中警告的失败模式

- 复盘变流水账: 只记录不分析, 没有输出"明日该干什么"
- 只看个股不看大盘: 个股受大盘影响, 必须先看宏观
- 不更新观察池: 复盘不只是看持仓, 还要发现新机会

### 容易混淆的邻近方法论

- 交易日志: 记录每笔交易, 复盘是每日全景扫描
- 周复盘: 更大周期, 本skill是日级别
