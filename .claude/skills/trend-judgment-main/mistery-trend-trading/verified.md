# 阶段 1.5 — 三重验证筛选结果

> 对每个候选单元执行 V1(跨域) / V2(预测力) / V3(独特性) 三重验证

## 判定标准
- **V1 跨域**: 书中至少2个独立段落有佐证?
- **V2 预测力**: 能用它回答一个书里没明说的新问题吗?
- **V3 独特性**: 不是任何聪明人都会说的常识吗?

---

## 通过验证 (将做成 skill)

### ✅ S1. 趋势判断系统 (← F1)
- V1: ✓ 跨6+章节反复(认清趋势/趋势交易系统/趋势股持股/520战法/顺大势逆小势/个股买卖点)
- V2: ✓ 给定任一个股均线+量价数据, 能输出趋势判断和操作建议
- V3: ✓ 系统化整合了均线/量价/MACD/20日线为统一框架, 非"看均线"常识
- **AI系统适配**: 可直接嵌入股票分析流程, 输出趋势方向+置信度

### ✅ S2. 520战法买卖系统 (← F2)
- V1: ✓ 独立两节(简化版+完整版)+多个实战示例
- V2: ✓ 给定MA5/MA20/成交量, 能输出具体买卖信号
- V3: ✓ 具体到金叉/死叉/回踩/跌破的四象限操作, 非"金叉买入"常识
- **AI系统适配**: 可量化执行, 信号明确

### ✅ S3. 仓位配置框架 (← F3 + F10 合并)
- V1: ✓ 跨两本书多章节(牛市资产配置/仓位管理/复盘合集/金字塔加仓)
- V2: ✓ 给定持仓组合+市况, 能输出仓位调整建议
- V3: ✓ 5+3+2分层+动态降仓+分批建仓节奏, 系统化非"分散投资"常识
- **AI系统适配**: 可嵌入仓位计算和持仓管理
- **合并理由**: F10分批建仓是F3仓位配置的执行细节, 合为1个skill更原子

### ✅ S4. 情绪周期六阶段 (← F4)
- V1: ✓ 独立大章+口诀+实战技巧+与趋势票对比章节
- V2: ✓ 给定涨停家数/炸板率/连板高度, 能判断当前情绪阶段
- V3: ✓ 六阶段模型+口诀+应对策略, 独创性体系非常识
- **AI系统适配**: 可用量化指标(涨停数/炸板率)判断市场温度

### ✅ S5. 情绪票vs趋势票分类操作 (← F5)
- V1: ✓ 多章节(分类/操作方式/筑顶特征/顶部形态/适合人群)
- V2: ✓ 给定个股特征(波动率/换手率/题材属性), 能分类并给操作建议
- V3: ✓ 两种票完全不同的买卖/持有/止损逻辑, 非常识
- **AI系统适配**: 个股分析前置分类器, 决定后续用哪套操作逻辑

### ✅ S6. 主力行为识别 (← F6)
- V1: ✓ 主力行为学大章+坐庄全过程+吸筹/洗盘/出货分章
- V2: ✓ 给定市况+量价模式, 能判断主力意图(吸筹/洗盘/出货)
- V3: ✓ 牛熊不对称模式(缓跌急涨vs缓涨急跌)是核心洞见, 非常识
- **AI系统适配**: 可辅助判断急跌/急涨性质

### ✅ S7. 复盘SOP (← F8)
- V1: ✓ 独立大章五层框架, 复盘合集通篇是复盘实例
- V2: ✓ 给定当日市场数据, 能按五层模板输出复盘报告
- V3: ✓ 五层结构化(宏观→板块→个股→技术→计划)非散乱复盘
- **AI系统适配**: 可直接增强现有daily_review流程

### ✅ S8. 看盘信号体系 (← P7 + P1口诀 + P8止损 合并)
- V1: ✓ 看盘技巧+交易口诀+止损机制多章节
- V2: ✓ 给定盘中数据(量比/委比/涨跌), 能输出信号判断
- V3: ✓ 三时间点+十口诀+三层止损, 系统化信号体系非常识
- **AI系统适配**: 盘中扫描可直接嵌入, 输出预警信号
- **合并理由**: 看盘三时间点+口诀+止损都是"盘中信号判断"的不同维度, 合为1个skill
