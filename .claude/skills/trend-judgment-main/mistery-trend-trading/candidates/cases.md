## Case 1. AI/芯片板块趋势股买入
- **来源**: 趋势交易理论【趋势股的持股方法】
- **背景**: AI技术突破 → 产业链爆发, 芯片全球缺货涨价
- **方法论应用**: F1趋势判断(行业景气度上行) + F7顺大势逆小势(基本面筛→技术面确认→回调买入)
- **决策**: 回调至20日线企稳, MACD金叉 → 买入, 沿5日线持有
- **结果**: 趋势延续, 移动止盈获利
- **示范的方法论**: F1趋势判断系统 / F10分批建仓

## Case 2. 委比+量比买入信号
- **来源**: 趋势交易理论 第二章【委比案例分析】案例1
- **背景**: 某股低位横盘, 委比从+10%→+65%, 量比从1.2→3.0
- **方法论应用**: 委比+量比双信号确认, 判断大量买盘涌入
- **决策**: 突破平台时买入
- **结果**: 突破进入拉升阶段
- **示范的方法论**: P7看盘三时间点(量比信号) / F1趋势判断(量价配合)

## Case 3. 委比+股价滞涨 (诱多陷阱)
- **来源**: 趋势交易理论 第二章【委比案例分析】案例2
- **背景**: 某股快速拉升, 委比+80%, 但未能突破前高
- **方法论应用**: F9破相思维 — 高委比+滞涨=主力制造买盘假象
- **决策**: 不追, 警惕冲高回落
- **结果**: 冲高回落, 追入者被套
- **示范的方法论**: C3高位放量滞涨 / F9破相思维

## Case 4. 庄家坐庄全过程
- **来源**: 趋势交易理论 第四章【庄家坐庄收割全过程】+【主力的吸筹方式】
- **背景**: 描述主力完整操作链: 吸筹→洗盘→拉升→出货
- **方法论应用**: F6主力行为识别
  - 吸筹: 低位缩量横盘, 利空打压, 筹码集中
  - 洗盘: 急跌吓人但缩量, 筹码不松
  - 拉升: 放量突破, 均线多头排列
  - 出货: 高位放量滞涨, 利好配合, 筹码分散
- **决策**: 每个阶段对应不同操作
- **示范的方法论**: F6主力行为识别 / F9破相思维

## Case 5. 牛市急跌=洗盘 (缓涨急跌模式)
- **来源**: 趋势交易理论 第四章【牛市急跌与应对思路】+【认识牛市中的急跌】
- **背景**: 牛市中突然急跌, 市场恐慌
- **方法论应用**: F6主力行为识别 — 牛市缓涨急跌, 急跌=洗盘非出货
- **决策**: 持股者不割肉, 等超跌反弹; 短线可抄底博弈反弹
- **结果**: 急跌后放量反弹, 升势继续
- **示范的方法论**: F6主力行为识别

## Case 6. 熊市急涨=诱多 (缓跌急涨模式)
- **来源**: 趋势交易理论 第一章【主力行为学】熊市部分
- **背景**: 熊市中突然急涨, 看似反弹
- **方法论应用**: F6主力行为识别 — 熊市缓跌急涨, 急涨=诱多出货
- **决策**: 不追涨, 反弹中减仓
- **结果**: 反弹后继续下跌
- **示范的方法论**: F6主力行为识别 / C8死多头

## Case 7. 破五反五 (洗盘确认)
- **来源**: 趋势交易理论 第二章【破五反五】
- **背景**: 某趋势股某日跌破5日线, 次日收回
- **方法论应用**: 放量破5+快速反包=主力洗盘非出货 → 继续持有/小仓跟进
- **决策**: 持仓加固信心; 或反包5日线+放量时小仓跟进
- **结果**: 趋势延续
- **示范的方法论**: P4卖飞好过被套 / F1趋势判断

## Case 8. 仓位管理实战配置
- **来源**: 复盘合集 仓位管理
- **背景**: 牛市环境, 需要配置仓位
- **方法论应用**: F3仓位配置框架 — 5成核心主线+2-3成弹性+2-3成机动
- **决策**: 按操作周期和风险等级分层配置; 大级别顶部接近时主动降仓
- **示范的方法论**: F3仓位配置 / F10分批建仓
