# 候选术语池 — Mistery 趋势交易理论 + 复盘合集

> 阶段 1 产出: 关键概念词典 (作者本人的用法)

| 术语 | 作者的定义 | 出处章节 | 和常识用法的区别 |
|---|---|---|---|
| 趋势 | 价格沿均线系统运行的方向, 非单一K线涨跌 | 认清趋势 | 常识=涨跌; 作者=均线多头排列+量价配合的持续方向 |
| 情绪票 | 题材驱动的短线爆发股, 靠情绪传染, 击鼓传花 | 情绪票VS趋势票 | 常识=热门股; 作者=明确区分其操作逻辑与趋势票 |
| 趋势票 | 基本面支撑的缓涨股, 机构主导, 沿均线慢爬 | 情绪票VS趋势票 | 常识=上涨股; 作者=强调基本面+筹码锁定+慢节奏 |
| 筹码 | 资金在某个价位的持仓分布和成本结构 | 筹码结构/筹码博弈 | 常识=股票; 作者=主力/散户的成本博弈, 决定涨跌空间 |
| 筹码归编 | 筹码从分散(散户持有)向集中(主力收集)转移 | 筹码归编 | 作者特有用法, 指主力吸筹导致筹码集中 |
| 做T | 日内高抛低吸降低成本, 必须等量, 不超3层 | 复盘合集/正T与倒T | 强调纪律约束, 非随意日内交易 |
| 破五反五 | 跌破5日线后迅速收回, 洗盘信号 | 破五反五 | 作者特指: 放量破+快速反包=主力洗盘非出货 |
| 中枢 | 多空力量暂时均衡的价格区间 | 相对顶与相对底 | 借自缠论, 作者用于解释相对顶/底的博弈平衡 |
| 顺大势逆小势 | 大周期看涨, 小周期找回调买点 | 顺大势逆小势 | 月线看周期, 周线看趋势, 日线找机会, 分时找买卖点 |
| 空中加油 | 强势上涨后高位横盘整固再突破 | 空中加油 | 非顶部, 是中继形态, 加仓信号 |
| 机构生命线 | 20日均线 | 什么是20日线 | 机构控盘的心理防线, 有效失守=机构松手 |
| 缓跌急涨 | 熊市主力行为模式 — 缓慢下跌出货, 急涨诱多 | 主力行为学 | 熊市特征, 急涨≠反转而是出货陷阱 |
| 缓涨急跌 | 牛市主力行为模式 — 缓慢推升吸筹, 急跌洗盘 | 主力行为学 | 牛市特征, 急跌≠崩盘而是洗盘机会 |
| 诱多 | 主力制造上涨假象吸引散户接盘 | 高位诱多 | 表面利好+放量, 实际是出货 |
| 诱空 | 主力制造下跌假象恐吓散户交出筹码 | 低位诱空 | 表面利空+破位, 实际是吸筹 |
| 破相 | 看穿主力制造的表相, 还原筹码流向真相 | 破相思维 | 不看价格/新闻表象, 只看资金行为本质 |
| 斜率 | 均线或趋势线的倾斜角度, 判断行情力度 | 什么是斜率 | 斜率大=强趋势; 斜率走平=趋势衰竭 |
| 盈亏比 | 潜在盈利与潜在亏损的比值 | 什么是盈亏比 | >2:1才值得出手; 不看胜率只看赔率会亏 |
| 三级共振 | 大盘+板块+个股三个级别同时走强 | 三级共振 | 三个级别共振=最强信号 |
| 情绪周期 | 短线资金情绪的周期性波动(六阶段) | 情绪周期 | 潜伏→启动→加速→高潮→分化→冰点 |
| 移动止盈 | 随趋势推移动态上移止盈线 | 趋势股持股方法 | 5日线/ATR下轨/前期支撑位, 非固定目标 |
| 保险式投资 | 像保险公司精算风险, 追求长期稳定回报 | 复盘合集 | 赚得慢走得稳, 极少犯致命错误 |
| 金字塔加仓 | 底部重仓, 越往上加仓越少 | 金字塔式加仓法 | 降低平均成本的同时控制追高风险 |
| 半仓滚动 | 保持约半仓, 反复高抛低吸 | 半仓滚动交易 | 既不满仓也不空仓, 通过滚动降成本锁利润 |
| 红三兵 | 连续三根小阳线, 上涨信号 | 放量红三兵 | 放量红三兵=更强信号; 高悬带量=接近顶部 |
| 旗形整理 | 上涨途中的旗面状横盘整理, 中继形态 | 空中加油 | 类似空中加油, 整理后继续上涨 |
