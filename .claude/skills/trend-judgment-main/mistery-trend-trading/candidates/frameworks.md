## F1. 趋势判断系统
- **来源**: 趋势交易理论 第一章【认清趋势】+【趋势交易的交易系统】
- **核心逻辑**: 均线排列状态 + 量价关系 + 20日线 → 判断当前趋势方向(上升/下降/震荡) → 决定操作方向(做多/做空/观望)
- **关键步骤**:
  1. 看均线: 5/10/20/60日是否多头排列(5>20>60), 价格是否站上250日线
  2. 看量价: 上涨放量、下跌缩量=健康; 放量滞涨=危险
  3. 看20日线: 站上=趋势良好; 有效跌破=趋势破坏
  4. 看MACD: 零轴上方金叉=趋势延续; 零轴下方死叉=弱势
  5. 综合: 多信号共振 → 高置信趋势判断
- **适用场景**: 任何需要判断个股/大盘趋势方向的时刻
- **预估skill化潜力**: **高** — 系统核心, 最有复用价值

## F2. 520战法 (MA5×MA20 交叉买卖系统)
- **来源**: 趋势交易理论 第三章【520战法】
- **核心逻辑**: MA5与MA20的交叉关系 + 价格与MA20的相对位置 → 买卖信号
- **关键步骤**:
  1. 金叉买入: MA5上穿MA20 + 放量 → 进场
  2. 回踩MA20支撑买入: 上涨中回调至MA20不破 + MA5向上拐头 → 低吸
  3. 死叉卖出: MA5下穿MA20 → 卖出
  4. 跌破MA20卖出: 价格+MA5同步向下 → 止损
  5. 信号增强: 叠加MACD金叉/ KDJ低位金叉/ 成交量配合
- **适用场景**: 波段交易, 持股数天到数周
- **预估skill化潜力**: **高** — 最实操的买卖系统, 规则明确可量化

## F3. 仓位配置框架 (5+3+2分层)
- **来源**: 复盘合集 仓位管理 + 趋势交易理论【牛市资产配置】【牛市中的仓位管理】
- **核心逻辑**: 按操作周期和风险等级分配资金 → 核心仓吃趋势 + 弹性仓赚轮动 + 机动仓防意外
- **关键步骤**:
  1. 核心仓(50-60%): 中长线, 行业龙头/基本面优秀, 趋势持有
  2. 弹性仓(30-40%): 波段操作, 技术面+消息面高抛低吸
  3. 机动仓(10-20%): 短线/应急, 快进快出
  4. 动态调整: 大级别顶部接近时主动降仓; 单只仓位不超20-30%
  5. 最多3-5只标的分散风险
- **适用场景**: 构建和维护持仓组合
- **预估skill化潜力**: **高** — AI系统可直接嵌入仓位计算

## F4. 情绪周期六阶段
- **来源**: 趋势交易理论 第一章【短线选手必须要会看的情绪周期】
- **核心逻辑**: 市场情绪像潮汐有周期 → 识别当前所处阶段 → 对应操作策略
- **关键步骤**:
  1. 潜伏期(冰点末期): 极度冷清 → 观察, 轻仓守底部趋势票
  2. 启动期(试探): 首板出现, 量能放大 → 识别题材, 小仓试水
  3. 加速期(高潮前夕): 龙头2-3连板, 赚钱效应 → 果断上核心龙头
  4. 情绪高潮(顶部): 涨停批量出现, 散户蜂拥 → 快进快出, 开始减仓
  5. 分化期(退潮): 龙头见顶大阴杀跌 → 坚决离场, 空仓等待
  6. 冰点期(杀跌到底): 跌停频现, 无人敢买 → 轻仓观察, 准备捡便宜
- **口诀**: 冰点不动, 启动试水, 加速重仓, 高潮减仓, 退潮空仓
- **适用场景**: 短线择时, 判断市场情绪温度
- **预估skill化潜力**: **高** — 可量化(涨停家数/炸板率/连板高度)

## F5. 情绪票 vs 趋势票分类操作
- **来源**: 趋势交易理论 第一章【情绪票VS趋势票】+【技术票与情绪票操作方式】+ 筑顶特征对比
- **核心逻辑**: 先识别标的类型(情绪票/趋势票) → 套用对应的操作逻辑
- **关键步骤**:
  1. 分类: 情绪票=题材驱动/短线爆发/击鼓传花; 趋势票=基本面支撑/缓涨/机构主导
  2. 情绪票操作: 买主升龙头/追涨/不做回调反弹/快进快出/严守纪律
  3. 趋势票操作: 买回调支撑位/持有不动/容忍短期回调/移动止盈
  4. 筑顶识别: 情绪票顶部=快/猛/突变(天地板/炸板); 趋势票顶部=慢/稳/结构性转弱(横盘阴跌/跌破均线)
- **适用场景**: 任何个股操作前, 先判断类型
- **预估skill化潜力**: **高** — 分类器可直接嵌入分析流程

## F6. 主力行为识别 (牛熊不对称)
- **来源**: 趋势交易理论 第一章【主力行为学】+ 第四章【庄家坐庄收割全过程】
- **核心逻辑**: 牛市和熊市中主力行为模式完全相反 → 识别模式 → 判断主力意图
- **关键步骤**:
  1. 判断市况: 当前是牛市/熊市/结构性行情
  2. 牛市模式: 缓涨急跌 → 主力吸筹, 急跌=洗盘非出货 → 急跌后逢低吸纳
  3. 熊市模式: 缓跌急涨 → 主力出货, 急涨=诱多非反转 → 急涨后逢高减仓
  4. 验证信号: 量能(高位放量=出货/低位缩量=吸筹)、均线、筹码分布
- **适用场景**: 判断急跌/急涨的性质, 决定抄底还是逃顶
- **预估skill化潜力**: **中** — 概念清晰但量化困难

## F7. 顺大势逆小势 (多周期共振)
- **来源**: 趋势交易理论 第一章【顺大势逆小势】+【三周期选股】
- **核心逻辑**: 大周期看方向, 小周期找买点 → 大小周期共振时入场
- **关键步骤**:
  1. 月线看周期: 是否处于上升周期
  2. 周线看趋势: 60周线之上, 上升趋势
  3. 日线找机会: 大趋势中找小级别回调段
  4. 分时找买卖点: 60分金叉买入, 30分死叉卖出
  5. 多周期一致=高置信; 周期矛盾=观望
- **适用场景**: 选股和择时入场
- **预估skill化潜力**: **中** — 可量化但与趋势判断系统有重叠

## F8. 复盘SOP (五层复盘)
- **来源**: 趋势交易理论 第一章【关于复盘】
- **核心逻辑**: 每日按固定模板复盘5个维度 → 发现机会/风险 → 制定明日计划
- **关键步骤**:
  1. 宏观&消息面: 三大指数/成交量/北向资金/政策新闻
  2. 板块热点&轮动: 最强板块Top3-5/涨停家数/炸板率/龙头动向/板块持续性
  3. 个股层面: 持仓表现/买卖复盘/观察股池更新
  4. 技术面: K线形态/均线/量价/MACD-KDJ-RSI
  5. 总结计划: 情绪判断/明日策略/重点观察
- **适用场景**: 每日盘后复盘
- **预估skill化潜力**: **高** — AI系统已有daily_review流程, 可直接增强

## F9. 破相思维 (识别主力陷阱)
- **来源**: 趋势交易理论 第四章【破相思维在交易中的应用】+【高位诱多】+【低位诱空】
- **核心逻辑**: 主力制造假象(诱多/诱空) → 用"破相"还原真相 → 避免被骗
- **关键步骤**:
  1. 高位诱多识别: 利好消息+放量但价格不涨=派发; 技术形态好看但量价背离
  2. 低位诱空识别: 利空消息+缩量下跌=恐吓吸筹; 破位后快速收回
  3. 破相工具: 看筹码(谁在买谁在卖)、看量能(放量=真/缩量=假)、看周期(大周期方向)
  4. 核心: 不看表象看筹码流向, 不听故事看资金行为
- **适用场景**: 判断信号真伪, 防被骗
- **预估skill化潜力**: **中** — 概念框架好但量化难

## F10. 分批建仓节奏
- **来源**: 复盘合集 仓位管理 + 趋势交易理论【金字塔式加仓法】
- **核心逻辑**: 建仓不是一把梭, 按确认信号递增加仓 → 降低择时压力
- **关键步骤**:
  1. 初始极轻仓(0.5-1成): 试错, 缠论一买, 核心是"试"
  2. 确认后加仓: 趋势确认(突破/回踩不破) → 加到3-5成
  3. 回踩中枢不破: 三买结构, 逐步递增加仓
  4. 建立在"确认"上而非"预测"上
  5. 金字塔式: 底部重仓, 越往上加越少
- **适用场景**: 任何建仓决策
- **预估skill化潜力**: **高** — 可直接嵌入仓位计算逻辑
