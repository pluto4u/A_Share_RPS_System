# 情绪周期六阶段

## R — 原文 (Reading)

> "情绪周期的六个阶段：①潜伏期（冰点末期）—极度冷清，无人看盘；②启动期—首板出现，量能放大；③加速期—龙头2-3连板，赚钱效应明显；④情绪高潮—涨停批量出现，散户蜂拥；⑤分化期—龙头见顶大阴杀跌；⑥冰点期—跌停频现，无人敢买。"
>
> "口诀：冰点不动，启动试水，加速重仓，高潮减仓，退潮空仓。"
>
> — Mistery, 第一章【情绪周期】

---

## I — 方法论骨架 (Interpretation)

市场短线情绪像潮汐, 有六个阶段的周期律动。每个阶段有明确的量化特征和应对策略:

| 阶段 | 量化特征 | 操作策略 |
|------|---------|---------|
| ① 潜伏期 | 涨停<10家, 无连板, 成交萎缩 | 观察不动, 轻仓守趋势票 |
| ② 启动期 | 首板出现, 量能开始放大 | 识别题材, 小仓试水 |
| ③ 加速期 | 龙头2-3连板, 高低切涌现 | 果断上核心龙头 |
| ④ 高潮期 | 涨停批量, 连板5+, 散户进场 | 快进快出, 开始减仓 |
| ⑤ 分化期 | 龙头大阴杀跌, 炸板潮 | 坚决离场, 空仓 |
| ⑥ 冰点期 | 跌停频现, 无热点 | 轻仓观察, 等下个周期 |

量化指标: 涨停家数 / 跌停家数 / 炸板率 / 连板高度 / 成交量变化。

核心: 情绪高潮=风险, 冰点=机会。大部分人反着做(高潮追, 冰点割)。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 高潮期见好就收
- **问题**: 龙头打到5板, 市场亢奋, 要不要追?
- **方法论的使用**: 涨停批量+散户蜂拥 = ④高潮期 → 高潮=风险
- **结论**: 不追, 已持有者开始减仓
- **结果**: 炸板后跌停, 追入者被套

### 案例 2: 冰点期埋伏新周期
- **问题**: 市场极度冷清, 还有机会吗?
- **方法论的使用**: 跌停频现+无热点 = ⑥冰点期 → 冰点是希望的开始
- **结论**: 轻仓观察新题材首板
- **结果**: 下个周期的龙头就在冰点期萌芽

## E — 可执行步骤 (Execution)

1. **收集市场情绪数据**:
   - 今日涨停家数 / 跌停家数
   - 连板高度(最高几连板)
   - 炸板率(涨停打开/总涨停尝试)
   - 成交量 vs 均量
   - 完成标准: 四项核心数据齐备

2. **判断当前阶段**:
   - 按六阶段特征表匹配
   - 优先看连板高度和炸板率: 连板高+炸板率低=加速/高潮; 连板断+炸板率高=分化
   - 完成标准: 明确当前处于哪个阶段

3. **输出操作策略**:
   - ①潜伏: 观察不动
   - ②启动: 小仓试水新题材
   - ③加速: 重仓核心龙头
   - ④高潮: 减仓, 快进快出
   - ⑤分化: 空仓
   - ⑥冰点: 轻仓观察
   - 完成标准: 明确的操作建议 + 仓位指导

4. **识别转折信号**:
   - 高潮→分化: 龙头首次炸板/大阴线
   - 冰点→启动: 新题材首板+量能放大
   - 完成标准: 下一阶段转折的预警条件

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 中长线投资: 情绪周期是短线工具, 中长线看趋势和基本面
- 趋势票持仓: 趋势票不受短线情绪波动影响, 不用情绪周期决定买卖
- 无涨跌停制度的市场: 模型基于A股涨跌停机制

### 作者在书中警告的失败模式

- 高潮期追涨: "散户蜂拥而上"时是风险最大的时候
- 冰点期割肉: "冰点是希望的开始", 恐慌卖出是反向操作
- 不识别分化信号: 龙头首次炸板就该警惕, 不能恋战

### 容易混淆的邻近方法论

- 市场情绪指数(恐慌贪婪指数): 类似概念但更量化, 本skill用涨停/炸板等A股特有指标
- 波浪理论: 波浪看价格结构, 情绪周期看资金情绪
