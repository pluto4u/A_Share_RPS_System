# 趋势判断系统

## R — 原文 (Reading)

> "认清趋势，是每个新股民入门的第一课。趋势不对，努力白费。在市场中，方向永远大于技巧。你可以短期看错，但不能长期逆势。顺势而为，哪怕方法粗糙，也往往能有所斩获；逆势而动，再多的分析与信心，也可能事倍功半。"
>
> "价格上穿60日均线，形成多头排列（5MA > 20MA > 60MA），成交量放大，MACD金叉柱状图翻红。回踩20日线不破，并重新放量上攻——买入。跌破趋势线或关键均线，并放量——卖出。"
>
> — Mistery, 第一章【认清趋势】+第三章【趋势交易的交易系统】

---

## I — 方法论骨架 (Interpretation)

趋势判断是多信号共振系统, 不是看单一指标:

1. **均线排列** — 5/10/20/60日均线是否多头顺次排列(短期>长期), 价格是否站上250日线
2. **量价关系** — 上涨放量+下跌缩量=健康趋势; 放量滞涨=危险信号
3. **20日线(机构生命线)** — 站上=趋势良好; 有效跌破=趋势破坏, 是最重要的单一分水岭
4. **MACD状态** — 零轴上方金叉=趋势延续; 零轴下方死叉=弱势; 柱状图缩小说明动能减弱
5. **综合置信度** — 多信号一致=高置信; 信号矛盾=低置信/观望

趋势分为三级: 上升(做多)/下降(做空或观望)/震荡(不操作或区间交易)。

## A1 — 书中的应用 (Past Application)

### 案例 1: AI/芯片板块趋势股
- **问题**: 判断AI板块某龙头股是否值得买入
- **方法论的使用**: 行业景气度上行(基本面) + 均线多头排列(技术面) + 上涨放量(量价) → 三信号共振
- **结论**: 上升趋势确认, 回调至20日线企稳时买入
- **结果**: 趋势延续, 沿5日线持有获利

### 案例 2: 破五反五(洗盘确认)
- **问题**: 某趋势股某日跌破5日线, 是否该卖?
- **方法论的使用**: 放量破5日线但次日快速收回(破五反五) → 主力洗盘非出货 → 趋势未破坏
- **结论**: 继续持有, 不卖出
- **结果**: 趋势延续

## E — 可执行步骤 (Execution)

1. **收集数据**: 获取标的的日K线数据(至少250个交易日), 包含 close/open/high/low/volume
   - 完成标准: 有足够数据计算MA5/10/20/60/250和MACD

2. **计算均线状态**:
   - MA5, MA10, MA20, MA60, MA250
   - 判断排列: 多头(5>10>20>60且价格>250) / 空头(反向) / 混乱
   - 完成标准: 输出排列状态

3. **判断量价关系**:
   - 近5-10日: 上涨日是否放量? 下跌日是否缩量?
   - 是否放量滞涨(量放大但价格不涨)?
   - 完成标准: 量价配合度(健康/背离/危险)

4. **检查20日线**:
   - 价格在20日线上方还是下方?
   - 距离20日线多远(偏离度)?
   - 是否有效跌破(连续2-3日收盘在下方)?
   - 完成标准: 20日线状态(上方/下方/刚跌破)

5. **MACD状态**:
   - DIF/DEA位置(零轴上/下), 金叉/死叉, 柱状图放大/缩小
   - 是否背离(价格新高但MACD不新高)?
   - 完成标准: MACD信号(多/空/中性)

6. **综合输出**:
   - 趋势方向: 上升/下降/震荡
   - 置信度: 高(4-5信号一致)/中(3信号)/低(≤2信号)
   - 操作建议: 做多/观望/做空
   - 关键位: 支撑位(20日线/60日线), 压力位(前高/平台)
   - 判停条件: 数据不足(上市<250日) → 标注"数据不足, 降级判断"

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 妖股/情绪票: 均线系统失真, 趋势判断无效。改用 `sentiment-cycle`
- 上市不足60个交易日的新股: 均线数据不充分
- 停牌复牌首日: 缺口导致均线断裂, 信号不可靠
- 极端行情(跌停/涨停锁死): 价格被锁定, 技术分析失效

### 作者在书中警告的失败模式

- MACD在震荡市频繁金叉/死叉, 信号失效 → 需要结合均线+量价过滤
- 均线有滞后性, 突破时可能已经涨了一段 → 回踩确认更安全
- 技术分析有效性假设未获学术证实(Fama 1970), 不可全信

### 容易混淆的邻近方法论

- 缠论中枢/背驰: 不同体系, 本skill用均线系统而非缠论结构
- 波浪理论: 波浪判断大级别位置, 本skill判断当前趋势方向
