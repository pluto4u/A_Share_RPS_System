## 核心理念: 一句话

**以趋势为核心, 用情绪+筹码+时间三要素构建交易系统: 顺势而为、纪律执行、控制风险、持续进化。**

## 八大技能体系

### 1. 趋势判断 — 一切的基础

趋势不对, 努力白费。判断趋势用多信号共振:

- **均线**: 5/10/20/60日多头排列(5>20>60), 价格站上250日线
- **量价**: 上涨放量+下跌缩量=健康; 放量滞涨=危险
- **20日线(机构生命线)**: 站上=趋势良好; 有效跌破=趋势破坏
- **MACD**: 零轴上方金叉=趋势延续

4-5个信号一致 = 高置信。矛盾 = 观望。

> "你可以短期看错, 但不能长期逆势。" — Mistery

### 2. 520战法 — 最实操的买卖系统

MA5 × MA20 两条线, 四个象限:

- **金叉买入**: MA5上穿MA20 + 放量 → 进场
- **回踩低吸**: 回调至MA20不破 + MA5拐头 → 加仓
- **死叉卖出**: MA5下穿MA20 → 离场
- **跌破止损**: 价格+MA5同步跌破MA20 → 止损

信号增强器: MACD同步金叉、KDJ低位金叉、成交量配合。

### 3. 仓位管理 — 活下去才能赚钱

**5+3+2分层**:
- 核心仓 50-60%: 中长线趋势龙头, 买入持有
- 弹性仓 30-40%: 波段高抛低吸
- 机动仓 10-20%: 短线/应急

**分批建仓节奏**:
1. 极轻仓(0.5-1成)试错
2. 趋势确认后加到3-5成
3. 每次回踩不破递增加仓
4. 金字塔原则: 底部重, 越往上加越少

**铁律**: 单只≤30%、最多3-5只、亏损不加仓、满仓=危险。

> "决定长期成败的不是抓住多少次暴涨, 而是是否始终站在不被一击击倒的位置上。"

### 4. 情绪周期 — 市场温度计

短线资金情绪有六阶段周期:

```
潜伏 → 启动 → 加速 → 高潮 → 分化 → 冰点 → (循环)
不动   试水   重仓   减仓   空仓   观察
```

量化指标: 涨停家数、炸板率、连板高度。

**核心反直觉**: 高潮=最大风险(散户蜂拥时), 冰点=最大机会(无人敢买时)。

### 5. 个股分类 — 先分类再操作

| | 情绪票 | 趋势票 |
|---|---|---|
| 买入 | 追龙头做主升 | 买回调支撑 |
| 持有 | 快进快出 | 拿着不动 |
| 回调 | 不参与(接飞刀) | 是买入机会 |
| 顶部 | 快/猛(天地板) | 慢/稳(阴跌) |

**最大错误**: 用趋势思路做情绪票(等回调=接飞刀), 用情绪思路做趋势票(追涨=被洗盘)。

### 6. 主力行为 — 牛熊不对称

同样的急跌/急涨, 不同市况含义相反:

| 市况 | 日常 | 急跌 | 急涨 |
|------|------|------|------|
| **牛市** | 缓涨 | **洗盘(机会)** | 自然上涨 |
| **熊市** | 缓跌 | 自然下跌 | **诱多(陷阱)** |

四阶段: 吸筹(低位缩量) → 洗盘(急跌缩量收回) → 拉升(放量突破) → 出货(高位放量滞涨)。

**破相思维**: 不看价格看筹码, 不听故事看资金。

### 7. 复盘SOP — 五层模板

1. **宏观**: 三大指数/量能/北向/政策
2. **板块**: 最强Top3-5/涨停家数/炸板率/龙头动向
3. **个股**: 持仓健康度/交易复盘/观察池更新
4. **技术**: K线/均线/量价/MACD信号
5. **计划**: 情绪判断+≤3条操作计划

复盘的终点不是"总结", 是"明天该干什么"。

### 8. 盘中信号 — 三时间点

| 时间 | 看什么 | 预警 |
|------|--------|------|
| 9:45 | 量比 | >5=出货警惕 |
| 13:15 | 首波拉升量 | 不带量=假拉升 |
| 14:50 | 尾盘急拉 | >3%=次日低开 |

口诀: 不冲高不卖, 不跳水不买, 横盘不交易。

## 推荐调用流程

```
分析个股:  分类 → 趋势 → 520买卖点 → 仓位
盘中看盘:  信号扫描 → 主力意图 → 仓位调整
盘后复盘:  五层模板 → 情绪阶段 → 趋势确认 → 仓位计划
```

## 底层哲学

1. **交易是概率博弈不是预测** — 管理概率和盈亏比, 不追求必胜
2. **经验可能沦为陷阱** — 市场唯一不变是变化, 要持续进化
3. **知行合一最难** — 大多数人败在执行, 不是败在不懂
4. **从复杂到简单** — 终极修炼是把一切化为本能反应
5. **像保险公司一样投资** — 赚得慢走得稳, 极少犯致命错误
