# 520战法买卖系统

## R — 原文 (Reading)

> "520战法是基于5日均线（MA5）和20日均线（MA20）的短中线交易策略。MA5上穿MA20→短线买入信号（多头趋势启动）。MA5下穿MA20→短线卖出信号（空头趋势启动）。股价在MA20上方，MA5向上拐头→短线低吸。股价跌破MA20，MA5向下拐头→风险加大。"
>
> — Mistery, 第三章【520战法】

---

## I — 方法论骨架 (Interpretation)

520战法用两条均线(MA5/MA20)构建四象限买卖系统:

| 状态 | MA5 vs MA20 | 价格 vs MA20 | 信号 |
|------|------------|-------------|------|
| 金叉买入 | MA5上穿MA20 | 站上MA20 | **买入** |
| 回踩低吸 | MA5向上拐头 | 回踩MA20不破 | **加仓** |
| 死叉卖出 | MA5下穿MA20 | 跌破MA20 | **卖出** |
| 趋势走坏 | MA5向下 | 持续在MA20下方 | **止损** |

信号增强器: 成交量(放量金叉>缩量金叉)、MACD(同步金叉)、KDJ(低位金叉)。

止损位: 金叉后跌破MA20或无力上攻 → 止损。跌破后反抽MA20未站稳 → 止损。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 回踩MA20支撑买入
- **问题**: 趋势股上涨后回调, 何时低吸?
- **方法论的使用**: 回调至MA20附近, MA5开始向上拐头, 成交量不萎缩 → 回踩支撑有效
- **结论**: 企稳后买入, 若放量上涨则加仓
- **结果**: 再次拉升获利

### 案例 2: 死叉+跌破MA20卖出
- **问题**: 持仓股走弱, 是否该卖?
- **方法论的使用**: MA5下穿MA20(死叉) + 跌破MA20 + 放量下跌 → 趋势走坏
- **结论**: 果断卖出, 反抽MA20未站稳则止损
- **结果**: 避免后续深跌

## E — 可执行步骤 (Execution)

1. **确认趋势前提**: 先用 `trend-judgment` 确认大趋势(必须非下降趋势)
   - 完成标准: 趋势=上升或震荡
   - 判停条件: 趋势=下降 → 不适用520, 输出"趋势向下, 不建议操作"

2. **计算MA5和MA20**: 取最近30个交易日收盘价
   - 完成标准: MA5, MA20值 + 昨日值(判断拐头方向)

3. **判断四象限状态**:
   - MA5 vs MA20: 上穿(金叉) / 下穿(死叉) / 上方 / 下方
   - 价格 vs MA20: 上方 / 下方 / 回踩中 / 跌破
   - 输出当前象限
   - 完成标准: 明确当前是哪个信号状态

4. **检查信号增强器**:
   - 成交量: 金叉/回踩时是否放量?
   - MACD: 是否同步金叉?
   - KDJ: 是否低位金叉?
   - 完成标准: 信号强度评级(强/中/弱)

5. **输出操作建议**:
   - 买入信号: 金叉+放量 → 买入; 回踩MA20不破+MA5拐头 → 低吸
   - 卖出信号: 死叉 → 卖出; 跌破MA20+放量 → 止损
   - 止损位: MA20下方 / 前低
   - 完成标准: 明确的买/卖/持有 + 价格区间 + 止损位

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 妖股/题材股: 连板涨停时均线失真, MA5和MA20没有参考意义
- 长期下跌趋势: "避免在长期下跌趋势中使用"(原文)
- T+0日内交易: 均线有滞后性, 不适合超短线
- 剧烈波动股: 均线反复缠绕, 信号频繁失效

### 作者在书中警告的失败模式

- 震荡市中频繁金叉/死叉, 信号失效 → 需要成交量配合确认
- 假突破: 金叉后无力上攻, 跌回均线下方 → 必须设止损
- 520是趋势确认后的执行工具, 不是趋势判断工具 → 先判断趋势再用520

### 容易混淆的邻近方法论

- 均线系统一般用法: 520是特定两条均线(MA5/MA20)的固定组合, 非任意均线
- MACD金叉: MACD是动量指标金叉, 520是均线交叉, 可同时出现增强信号
