# GLOSSARY — Mistery 交易技能共享术语词典

> 所有 skill 共享的概念词典。术语定义基于作者 Mistery 的特定用法, 非字典定义。

| 术语 | 定义 | 使用此术语的 skill |
|---|---|---|
| **趋势** | 价格沿均线系统运行的持续方向, 非单一K线涨跌 | trend-judgment, warrior-520, daily-review-sop |
| **多头排列** | MA5 > MA10 > MA20 > MA60, 短期均线在上长期在下 | trend-judgment, warrior-520 |
| **20日线(机构生命线)** | 过去20个交易日平均收盘价, 机构控盘心理防线, 有效跌破=趋势破坏 | trend-judgment, warrior-520, position-management |
| **情绪票** | 题材驱动的短线爆发股, 靠情绪传染, 高换高大波动, 击鼓传花式接力 | stock-type-classifier, sentiment-cycle |
| **趋势票** | 基本面支撑的缓涨股, 机构主导, 筹码锁定好, 沿均线慢爬 | stock-type-classifier, trend-judgment |
| **筹码** | 资金在某个价位的持仓分布和成本结构, 决定涨跌空间 | smart-money-detector, position-management |
| **缓跌急涨** | 熊市主力模式: 缓慢下跌出货, 偶尔急涨诱多 | smart-money-detector |
| **缓涨急跌** | 牛市主力模式: 缓慢推升吸筹, 偶尔急跌洗盘 | smart-money-detector |
| **洗盘** | 主力制造下跌清洗浮筹, 缩量急跌后快速收回, 筹码不松 | smart-money-detector |
| **出货** | 主力高位派发筹码, 放量滞涨或利好配合, 筹码分散 | smart-money-detector, intraday-signals |
| **诱多** | 制造上涨假象吸引散户接盘, 实为出货 | smart-money-detector |
| **诱空** | 制造下跌假象恐吓散户交出筹码, 实为吸筹 | smart-money-detector |
| **破相** | 看穿主力制造的表相, 还原筹码流向真相; 不看价格看资金 | smart-money-detector |
| **破五反五** | 跌破5日线后迅速收回, 放量破+快速反包=洗盘信号 | trend-judgment, warrior-520 |
| **空中加油** | 强势上涨后高位横盘整固再突破, 中继形态非顶部 | trend-judgment |
| **中枢** | 多空力量暂时均衡的价格区间, 相对顶/底在此博弈 | trend-judgment |
| **金叉/死叉** | 短期均线上穿/下穿长期均线, 买入/卖出信号 | warrior-520, trend-judgment |
| **量比** | 当前成交量与过去5日同时段均量之比, >5=异常活跃 | intraday-signals |
| **委比** | 买卖盘委托量之差/总和, 正=买盘强, 负=卖盘强 | intraday-signals |
| **移动止盈** | 随趋势推移动态上移止盈线(5日线/ATR/前低) | warrior-520, position-management |
| **金字塔加仓** | 底部重仓, 越往上加仓越少, 降低追高风险 | position-management |
| **半仓滚动** | 保持约半仓反复高抛低吸, 既不满仓也不空仓 | position-management |
| **三级共振** | 大盘+板块+个股三个级别同时走强, 最强信号 | trend-judgment, daily-review-sop |
| **情绪周期** | 短线资金情绪的周期性波动: 潜伏→启动→加速→高潮→分化→冰点 | sentiment-cycle |
| **炸板率** | 涨停打开次数/总涨停尝试, 高=情绪退潮 | sentiment-cycle, daily-review-sop |
| **保险式投资** | 像保险公司精算风险, 追求长期稳定回报, 极少犯致命错误 | position-management |
