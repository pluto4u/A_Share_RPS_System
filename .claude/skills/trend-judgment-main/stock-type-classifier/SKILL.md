# 情绪票vs趋势票分类操作

## R — 原文 (Reading)

> "情绪票通常围绕热点题材快速炒作，一两天内爆发，三五天内见顶。强调'接力'逻辑，高频涨停，没有持续性基本面支撑。趋势票走的是'慢牛'路线，背后有清晰的基本面或产业逻辑支撑，K线结构清晰，多为缓涨少回。"
>
> "机构票，主力进场后都会洗盘，不会持续大涨，追涨买入必定吃套。一定要买在回调支撑位，然后就拿着别动。情绪票短线，击鼓传花，一定要买主升龙头，追涨买，不建议参与回调后的反弹。"
>
> — Mistery, 第一章

---

## I — 方法论骨架 (Interpretation)

个股分两大类型, 操作逻辑完全相反:

| 维度 | 情绪票 | 趋势票 |
|------|--------|--------|
| 驱动力 | 题材/情绪传染 | 基本面/产业逻辑 |
| 节奏 | 快(1-5天见顶) | 慢(数周到数月) |
| 买入方式 | 追涨龙头, 做第一段主升 | 买回调支撑位 |
| 持有方式 | 快进快出 | 拿着不动 |
| 回调处理 | 不参与回调后反弹 | 回调是买入机会 |
| 顶部特征 | 快/猛/突变(天地板/炸板) | 慢/稳/结构转弱(横盘阴跌) |
| 适合人群 | 手速快/心态稳/有盘感 | 偏好逻辑/风险中等/看基本面 |

分类指标: 换手率(高=情绪)、波动率(大=情绪)、题材属性(有=情绪)、机构持仓(高=趋势)、均线斜率(陡=情绪/缓=趋势)。

核心错误: 用趋势思路做情绪票(等回调=接飞刀), 或用情绪思路做趋势票(追涨=被洗盘震出)。

## A1 — 书中的应用 (Past Application)

### 案例 1: 情绪票追龙头
- **问题**: 某题材股3连板, 能不能买?
- **方法论的使用**: 分类=情绪票 → 买龙头做第一段主升, 追涨买, 不等回调
- **结论**: 果断追入龙头, 但严守纪律, 不恋战
- **结果**: 第4-5板卖出获利

### 案例 2: 趋势票买回调
- **问题**: 某机构重仓股连涨后回调, 能不能买?
- **方法论的使用**: 分类=趋势票 → 买回调支撑位(20日线), 然后拿着不动
- **结论**: 回调至20日线企稳买入, 持有
- **结果**: 趋势延续, 慢慢获利

## E — 可执行步骤 (Execution)

1. **收集分类特征**:
   - 换手率: 近5日均换手率(>15% = 情绪倾向)
   - 波动率: 近5日日均振幅(>5% = 情绪倾向)
   - 题材属性: 是否有明确题材/概念催化
   - 机构持仓: 前十大流通股东中机构比例
   - 均线斜率: MA20斜率(陡峭=情绪/平缓=趋势)
   - 市值: 流通市值(<100亿 = 情绪倾向)
   - 完成标准: 6维特征向量

2. **分类判断**:
   - 情绪票: 高换手+大波动+有题材+低机构持仓+小市值
   - 趋势票: 中换手+中等波动+基本面驱动+机构持仓+中大市值
   - 混合型: 部分特征重叠 → 标注"偏情绪/偏趋势"
   - 完成标准: 明确分类 + 置信度

3. **输出操作策略**:
   - 情绪票: 追龙头/做主升/快进快出/不参与回调/严守止损(3-5%)
   - 趋势票: 买回调支撑/持有不动/容忍波动/移动止盈(20日线)
   - 筑顶监控: 情绪票看炸板/天地板; 趋势票看横盘阴跌/跌破均线
   - 完成标准: 分类+操作策略+止损方式+顶部预警信号

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- ETF/指数基金: 不是个股, 无情绪/趋势之分
- 上市新股: 缺乏历史数据无法分类
- 停牌复牌: 特殊情况, 分类暂时失效

### 作者在书中警告的失败模式

- 用趋势思路做情绪票: "不建议参与任何回调后的反弹" — 情绪票回调=退潮, 不是买入机会
- 用情绪思路做趋势票: "追涨买入必定吃套" — 趋势票主力会洗盘, 追涨被套
- 不分类就操作: 一套方法打天下是最大的错误

### 容易混淆的邻近方法论

- 价值股/成长股分类: 按基本面分, 本skill按交易行为分
- 大盘股/小盘股分类: 按市值分, 本skill按资金行为分
