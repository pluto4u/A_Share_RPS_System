# 仓位配置+建仓节奏

## R — 原文 (Reading)

> "牛市环境中，原则上不空仓，但一定要有结构。5成左右配置在核心主线，承担趋势收益；2-3成用于短线或弹性机会，提高资金效率；2-3成作为机动仓，应对突发事件或极端波动。"
>
> "抄底建仓阶段要讲究节奏：初始极轻仓，大概0.5-1成即可，核心目的是试错；确认趋势后再进行加仓；此后每一次回踩中枢但不破位，都可以视为三买结构，逐步递增加仓，把仓位建立在'确认'上。"
>
> — Mistery, 复盘合集【仓位管理】

---

## I — 方法论骨架 (Interpretation)

仓位管理分三层:

**层1 — 资金分配(静态结构)**:
- 核心仓 50-60%: 中长线趋势股, 行业龙头, 买入持有
- 弹性仓 30-40%: 波段操作, 高抛低吸
- 机动仓 10-20%: 短线/应急/打新
- 约束: 单只≤20-30%, 最多3-5只

**层2 — 建仓节奏(动态执行)**:
- 第1笔: 极轻仓(0.5-1成)试错
- 第2笔: 趋势确认后(突破/回踩不破)加仓到3-5成
- 第3笔+: 每次回踩中枢不破, 递增加仓
- 金字塔原则: 底部重仓, 越往上加越少
- 核心: 建立在"确认"上, 非建立在"预测"上

**层3 — 动态调整**:
- 大级别顶部接近 → 主动降仓
- 牛市急跌(洗盘) → 不割肉, 可抄底
- 熊市急涨(诱多) → 反弹中减仓
- 趋势破坏 → 止损减仓

## A1 — 书中的应用 (Past Application)

### 案例 1: 牛市标准配置
- **问题**: 牛市如何配置仓位?
- **方法论的使用**: 5+3+2分层 + 按行业景气度选标的
- **结论**: 核心仓放科技/消费龙头, 弹性仓做周期轮动, 机动仓追热点
- **结果**: 结构化持仓, 不因单一标的大幅波动影响整体

### 案例 2: 分批建仓降低择时压力
- **问题**: 看好一只股但不确定买点
- **方法论的使用**: 0.5成试错 → 突破确认后加到3成 → 回踩不破再加 → 逐步建仓
- **结论**: 不幻想抄到最低点, 分批买入降低压力
- **结果**: 平均成本合理, 持仓舒适度高

## E — 可执行步骤 (Execution)

1. **评估当前持仓状态**:
   - 总仓位(已投/总资金)
   - 各标的仓位占比
   - 盈亏状态
   - 完成标准: 持仓全景表

2. **检查仓位结构**:
   - 核心/弹性/机动比例是否符合5+3+2?
   - 单只仓位是否超30%?
   - 持仓数量是否超5只?
   - 完成标准: 结构健康度评估

3. **评估市况调整系数**:
   - 牛市主升期: 维持或加仓
   - 顶部区域: 主动降仓(减弹性仓和机动仓)
   - 熊市/SEVERE: 核心仓也降, 保留现金
   - 完成标准: 市况调整系数(0.5x ~ 1.2x)

4. **输出仓位建议**:
   - 新建仓: 建议初始仓位(0.5-1成试错) + 后续加仓条件
   - 已持仓: 加仓/减仓/持有 + 目标仓位
   - 止损位: 硬止损(跌破支撑5-8%) / 软止损(趋势破坏)
   - 完成标准: 具体到百分比和金额的仓位建议

5. **风控检查**:
   - 总仓位是否超限?(满仓=危险)
   - 亏损加仓?(禁止 — 四不做之一)
   - 单一板块过度集中?
   - 完成标准: 风控红绿灯

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 极端行情(连续跌停): 无法加减仓, 执行优先
- 单只标的仓位已达30%上限: 不再加仓, 只减不加
- SEVERE/熔断 regime: 停新仓, 只减, 本skill的牛市配置不适用

### 作者在书中警告的失败模式

- 亏损加仓: "解析一下散户最喜欢的两个字'补仓'" — 下跌中乱补仓是小亏变大亏的主因
- 满仓单只: 风险集中, 一旦出错无回旋余地
- 一把梭: 不分批, 择时压力全部压在一个点上
- 做T变加仓: 本想日内降成本, 结果越做仓位越重

### 容易混淆的邻近方法论

- 凯利公式: 数学最优仓位, 但依赖准确胜率估计, Mistery的框架更保守实操
- 均值-方差优化: 学术组合管理, 本skill是经验法则
