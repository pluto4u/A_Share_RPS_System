# 看盘信号体系

## R — 原文 (Reading)

> "炒股每天三个重点时间点：1、早上9:45看量比，量比大于5，警惕主力出货。2、下午1:15看拉升量，首波拉升不带量，必回落。3、下午2:50看急拉，尾盘急拉超3%，次日低开概率高。"
>
> "高位放量滞涨，坚决出局观望。不冲高不卖，不跳水不买，横盘不交易。"
>
> — Mistery, 第二章【看盘技巧】+ 第一章【交易口诀】

---

## I — 方法论骨架 (Interpretation)

盘中信号体系整合三个维度:

**维度1 — 三时间点扫描**:
| 时间 | 看什么 | 信号 |
|------|--------|------|
| 9:45 | 量比 | >5=警惕出货; <0.5=无人关注 |
| 13:15 | 首波拉升量能 | 不带量=必回落 |
| 14:50 | 尾盘急拉 | >3%=次日低开概率高 |

**维度2 — 十大口诀信号**:
- 买横买坑不买竖 / 下跌不言底 / 高位放量滞涨出
- 不冲高不卖 / 不跳水不买 / 横盘不交易
- 涨时重势跌时重质 / 短线看量长线看势

**维度3 — 止损触发监控**:
- 硬止损: 跌破支撑/20日线5-8%
- 软止损: 均线死叉/放量破位
- 时间止损: 入场5-7日无明显上涨

集合竞价信号: 高开幅度(温和1-3%=正常; 大幅>5%=警惕高开低走), 封单稳定性, 竞价量价配合。

## A1 — 书中的应用 (Past Application)

### 案例 1: 9:45量比预警出货
- **问题**: 某股早盘强势, 能不能追?
- **方法论的使用**: 9:45看量比 → 量比>5 + 高位 → 主力出货信号
- **结论**: 不追, 已持有者考虑减仓
- **结果**: 高开低走

### 案例 2: 尾盘急拉陷阱
- **问题**: 某股14:50突然急拉5%, 是机会吗?
- **方法论的使用**: 尾盘急拉>3% → 次日低开概率高
- **结论**: 不追, 等次日低开再看
- **结果**: 次日低开2%

## E — 可执行步骤 (Execution)

1. **集合竞价分析(9:15-9:25)**:
   - 高开/低开幅度: 温和(1-3%)正常; 大幅(>5%)警惕
   - 封单情况: 大单稳定=强; 不断撤单=诱多
   - 竞价成交量: 放大=资金活跃; 萎缩=冷淡
   - 完成标准: 开盘强弱判断

2. **三时间点扫描**:
   - 9:45: 量比>5 → 出货预警; 量比<0.5 → 无关注
   - 13:15: 首波拉升是否带量 → 无量=假拉升
   - 14:50: 尾盘急拉>3% → 次日低开预警
   - 完成标准: 三个时间点的信号状态

3. **口诀信号检查**:
   - 当前是否"高位放量滞涨"? → 卖出信号
   - 当前是否"横盘"? → 不交易
   - 当前是否"急跌跳水"? → 不买(等反弹)
   - 完成标准: 口诀匹配结果

4. **止损监控**:
   - 硬止损: 持仓股是否跌破支撑5-8%?
   - 软止损: 是否出现均线死叉/放量破位?
   - 时间止损: 入场后是否5-7日无上涨?
   - 完成标准: 止损触发状态(安全/预警/触发)

5. **输出预警**:
   - 红灯: 高位放量滞涨/量比异常/止损触发 → 立即行动
   - 黄灯: 信号矛盾/趋势不明 → 谨慎观望
   - 绿灯: 量价配合/趋势完好 → 正常持有
   - 完成标准: 红黄绿灯状态+具体建议

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- 盘后: 无实时数据, 用 `daily-review-sop`
- 非A股: 三时间点和集合竞价规则不同
- 停牌: 无数据

### 作者在书中警告的失败模式

- 量比单一信号不靠谱: 必须结合价格趋势和K线形态
- 委比可造假: 大单挂单可撤, 需看实际成交
- 追涨杀跌: "不冲高不卖，不跳水不买，横盘不交易" — 大部分人的本能是反的

### 容易混淆的邻近方法论

- Level-2盘口: 更精细的逐笔数据, 本skill用公开行情数据
- 程序化交易信号: 自动执行, 本skill是辅助人工判断
